# 第一章基础算法

## 1、快速排序

### 是什么：

在数组中找寻一个基准值key，然后将数组元素分为两类：一类是大于基准值的放在它的右边，一类是小于基准值的放在它的左边（要想实现这个过程最直接的就是利用插入元素的方式，但是插入元素的工作量太大，得移动好多元素来为插入的元素腾出位置来，所以最好的还是利用两个元素交换位置的方式因为这样只涉及到两个位置的元素进行操作），这样最后可以找到基准值在数组中的位置，接下来就是对于基准值左边和右边的子数组按照同样的方式继续进行上述过程。

这个过程的平均时间复杂度为O(nlogn)（每次选取的基准值都能刚好将数组元素对半分），最差时间复杂度为O(n^2)（每次选取的基准值都是在最边上的）

基本思想就是如上所示，但是具体实现方式有如下几种：

（1）双指针法，同时用左右两个指针分别从前往后寻找元素以及从后往前寻找元素并且交换元素位置

（2）单指针法，只用一个指针寻找元素并且交换元素位置（只用一个指针该指针用于寻找元素了，那么即使找到了又和谁交换位置呢？这里专门还有一个位置用来从数组的最左边依次向右遍历，就是和这个位置的元素交换位置）



### 怎么办：

### （1）如何实现快速排序算法？

#### 方式一：双指针法（用的最多）

##### ①普通的双指针快速排序算法（这个算法模板不好，不要用这个）：

首先选定数组中的一个元素作为基准元素key把它放到一边（**一般选最左边(或最右边)的元素，为什么要选取最左边(或最右边)的元素作为基准元素呢？因为这里的思想就是以基准元素作为标准然后将剩余元素分为两类，一类是大于基准的一类是小于基准的，所以最好的办法就是先将基准元素放到一边这样不影响剩余元素分类，否则的话如果以中间某个元素作为基准然后后续遍历的时候又碰到了该基准元素不知道将该元素放到哪一类就很麻烦，可能会造成该元素既放在了左半部又放在了右半部**），然后设立一前一后两个指针left,right遍历数组，其中left从前往后遍历寻找比基准值key大的元素，right从后往前遍历寻找比基准值key小的元素，然后交换它们二者的位置，重复上述过程直到最后左指针left越过了右指针right，此时再将先前放到一边的基准值key和右指针right指向的元素交换位置（为什么是越过了右指针而不是刚好二者碰头？因为这里的目的是要遍历数组中的所有元素最终找到基准值在数组中应该摆放的位置，当碰头后的那个元素也是需要遍历的即循环条件是：while(left<=right)而不是while(left<right) ）。

==注意：这里的快排算法中每一次遍历都能找到基准值key最终在数组中的位置==

这里还得注意一个重要的点那就是最后基准元素key到底是和左右指针的哪一个进行位置交换呢？

这里记住一个点：左指针left从前往后遍历寻找比基准值key大的元素找到了就停止，右指针right从后往前遍历寻找比基准值key小的元素找到了就停止，然后交换左右指针的元素，==也就是说在最后循环结束之前：left指针左边的元素都是比基准值key小的，right指针右边的元素都是比基准值key大的==；此时进行最后一次指针的移动（当进行过这次指针移动以后左指针就越过了右指针，循环结束了），分为如下几种情况：

==①left指针右移，right指针不动==：此时left指针指向的元素比基准值key要小，right指针指向的元素要比基准值key要小，所以left指针得右移、right指针不动，当进行过这次移动以后left指针越过了right指针循环结束（此时"right指针右边的元素都是比基准值key大的"这个属性依然满足，此时left指针位于right指针右边，所以left指针指向的元素要比基准值key要大了），所以此时基准值key要和right指针指向的元素交换位置

==②left指针不动，right指针左移==：此时left指针指向的元素比基准值key要大，right指针指向的元素要比基准值key要大，所以left指针不动、right指针左移，当进行过这次移动以后left指针越过了right指针循环结束（此时"left指针左边的元素都是比基准值key小的"这个属性依然满足，此时right指针位于left指针左边，所以right指针指向的元素要比基准值key要小了），所以此时基准值key要和right指针指向的元素交换位置

==③left指针右移，right指针左移==：此时left指针指向的元素比基准值key要小，right指针指向的元素要比基准值key要大，所以left指针右移、right指针左移，当进行过这次移动以后left指针越过了right指针循环结束（此时"left指针左边的元素都是比基准值key小的，right指针右边的元素都是比基准值key大的"这个属性依然满足，此时right指针位于left指针左边，所以right指针指向的元素要比基准值key要小了），所以此时基准值key要和right指针指向的元素交换位置

综上：当循环结束后，基准值key都是和右指针right指向的元素交换位置

```Java
//普通的快速排序的双指针法：
//（1）双指针，先移动左指针的方式
class Solution{
    public void quickSort(int[] nums,int left,int right){
        if(left<right){
            //这里的index为基准值最后在数组中的位置，由此将数组分为两部分
         	int index=partition(nums,left,right);
            
        	quickSort(nums,left,index-1);
        	quickSort(nums,index+1,right);   
        }
        return;
    }
    
    //定义一个用于找寻基准值最后在数组中的位置的方法
    public int partition(int[] nums,int left,int right){
        int key=left;//首先确定取数组最左边的元素作为基准值
        int i=left,j=right;//设立一前一后的两个指针
        while(i<=j){
            /*
            注意这里的循环结束条件是i<=j，为什么？
            因为这里的while循环要做的事是遍历数组中所有元素以此来寻找基准元素最终的位置，
            当i=j时此时依然需要遍历该位置的元素看看它是不是基准的最终位置
            */
            while(i<=j && nums[i]<=nums[key]){//先移动左指针
                i++;
            }
            while(i<=j && nums[j]>=nums[key]){//后移动右指针
                j--;
            }
            if(i<j){
                //这里为什么要加这个条件？因为当结束上述两个while循环以后此时i指针越过了j指针，
                //这时候是不应该交换两个元素位置的
                swap(nums,i,j);
            }
        }
        swap(nums,key,i-1);
        /*
        这里是将i-1位置作为最后基准元素的位置
        swap(nums,key,j);二者是等效的，因为此时i-1位置就是j位置
        */
    }
    //定义交换数组中两个元素位置的方法
    public void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
}




//（2）双指针，先移动右指针的方式
class Solution{

        if(left<right){
            //这里的index为基准值最后在数组中的位置，由此将数组分为两部分
         	int index=partition(nums,left,right);
            
        	quickSort(nums,left,index-1);
        	quickSort(nums,index+1,right);   
        }
        return;
    }
    
    //定义一个用于找寻基准值最后在数组中的位置的方法
    public int partition(int[] nums,int left,int right){
        int key=left;//首先确定取数组最左边的元素作为基准值
        int i=left,j=right;//设立一前一后的两个指针
        while(i<=j){//注意这里的循环结束条件
            while(i<=j && nums[j]>=nums[key]){//先移动右指针
                j--;
            }
            while(i<=j && nums[i]<=nums[key]){//后移动左指针

            } 
            if(i<j){
                swap(nums,i,j);
            }
        }
        swap(nums,key,j);//这里是将j位置作为最后基准元素的位置
    }
    //定义交换数组中两个元素位置的方法

    }
```

###### notes：随机选取基准值的快速排序算法（还是麻烦）

由上述过程我们可以知道每次都取数组的第一个元素作为基准值这种方式的确可行但是不一定好，比如说现在数组是逆序的，然后我们每次取数组第一个元素作为基准值这样每次划分的时候都会将剩余数组元素全部分到一边，这样的话时间复杂度为O(n^2)，所以这里我们随机取数组中的一个元素作为基准值然后执行上述过程，**但是不对啊，前面我们说过了基准值得放到一边这样不耽误别的元素分类但是现在随机选取的基准值就不是在数组的最边上了，那也没问题只要我们选定了随机的元素作为基准以后接着将该元素与数组最边上的元素交换位置不就行了嘛**

这里会用到一个产生随机整数的方法Random.nextInt(k)：会产生一个[0，k)的随机整数，不包括k（其中nextInt()为动态方法，所以首先还得创建一个Random类的对象）

```Java
//双指针，随机取基准值
class Solution{
    public void quickSort(int[] nums,int left,int right){
        if(left<right){
            //这里的index为基准值最后在数组中的位置，由此将数组分为两部分
         	int index=partition(nums,left,right);
            
        	quickSort(nums,left,index-1);
        	quickSort(nums,index+1,right);   
        }
        return;
    }
    
    //定义一个用于找寻基准值最后在数组中的位置的方法
    public int partition(int[] nums,int left,int right){
        Random rand=new Random();
        int key=rand.nextInt(right-left+1)+left;//随机取一个元素作为基准值
        swap(nums,left,key);//将随机取的基准值放到数组的最边上，这样不耽误剩余元素分类
        int i=left,j=right;//设立一前一后的两个指针
        while(i<=j){//注意这里的循环结束条件
            while(i<=j && nums[i]<=nums[key]){//先移动左指针
                i++;
            }
            while(i<=j && nums[j]>=nums[key]){//后移动右指针
                j--;
            }
            if(i<j){
                swap(nums,i,j);
            }
        }
        swap(nums,key,i-1);//这里是将i-1位置作为最后基准元素的位置
        //swap(nums,key,j);二者是等效的，因为此时i-1位置就是j位置
    }
    //定义交换数组中两个元素位置的方法
    public void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
}
```





##### ②改进的双指针快速排序算法（这个算法模板好，以后就用这个）

和上述普通的双指针快排算法不同，在改进的快排算法中每次我们依然是选取一个基准值key（不过不同的是在这里每一次我们不用纠结该基准值到底应该放在数组中的哪一个位置处），然后设立一前一后两个指针left,right遍历数组，其中left从前往后遍历寻找比基准值key大的元素，right从后往前遍历寻找比基准值key小的元素，然后交换它们二者的位置，重复上述过程直到最后左指针left和右指针right碰头（while(left<right)），为什么这里的循环结束条件是左右指针碰头而不是前面提到的左指针越过了右指针？

因为这里我们的目的不是遍历整个数组寻找基准值key最终在数组中的位置，而是仅仅将数组变得局部有序：数组的左半部都是小于等于基准值key的，数组的右半部都是大于等于基准值key的。我们是利用左右指针交换来实现这一过程的，当左右指针碰头以后此时左右指针相等（left=right）也就无所谓交换位置了。

此时数组被划分为了左右两部分：一类大于等于基准值的元素放到数组右半部，一类小于等于基准值的元素放到数组左半部（当然这里在右半部内部数组元素不一定是有序的，左半部也是同理，只是借助这个操作让数组先变得局部有序）。然后再利用递归操作对数组左半部和右半部进行上述操作，直到最后将数组划分为了区间长度为1的子数组自然就有序了。后续对局部有序的数组分别再进行递归操作，直到最后将数组划分为区间长度为1的子数组自然就有序了。

==注意：这里的快排算法，每一轮递归的时候都没法确定也不用确定基准值key最终在数组中的下标，每一轮都是将数组变得局部有序就可以了，后续再对局部有序的数组再分别进行递归操作即可，每一轮递归的时候都得将所有的数组元素进行一次操作。而上述普通的快排算法每一轮都可以确定一个基准值key在数组中的最终下标index，后续对子数组进行递归的时候就可以排除index这个下标位置了（因为该位置的元素已经找到了最终下标了）==

```Java
static void quickSort(int[] nums,int left,int right){
    if(left<right){
        int mid=nums[(left+right)/2];//选取中间位置的元素作为基准（作用相当于上述随机选取基准）
        int i=left-1;
        /*
        i作为左指针，为什么要令i=left-1，而不是i=left?
        因为这里我们的操作是每次交换完左右指针的位置之后都要进行一次左指针右移以及右指针左移的
        操作（不管每次的情况如何都要进行这些移动操作），所以我们想到利用do-while循环不管怎样
        先进行一次指针移动操作再说，但是如果仅仅这样移动的话又会带来问题，那就是当左指针i=left
        时，先进行一次左指针右移操作这样就会越过数组的第一个元素，这样显然不对，所以我们令
        i=left-1
        */
        int j=right+1;//j作为右指针，令j=right+1也是和上述同理
        while(i<j){
            /*
            为什么这里的循环条件是i<j和上述一般的快排算法的循环条件为i<=j不同？
            因为这里的while循环做的事是交换i,j下标处的元素位置来使得数组变得局部有序，
            所以当i=j时说明此时数组中只有一个元素自然是有序的不需要再处理；
            而上述一般的快排算法的while循环做的事是遍历数组所有元素以此来找到基准值所在的最终
            位置，当i=j时依然需要遍历该位置的元素看看它是否是基准值最终的位置。
            */
            do{i++;}while(nums[i]<mid);//这里为什么要用do-while循环下面也有解释
            do{j--;}while(nums[j]>mid);
            if(i<j){
                swap(nums,i,j);
            }
        }
        quickSort(nums,left,j);
        quickSort(nums,j+1,right);
    }
    return;
}

static void swap(int[] nums,int i,int j){
    int temp=nums[i];
    nums[i]=nums[j];
    nums[j]=temp;
}
```

==上述改进的快排算法与一般的快排算法的区别在哪？==

**一般的快排算法**是首先找到基准元素（不管是取最左边的元素作为基准还是随机选取基准）然后遍历数组，将数组中小于基准元素的放到数组前半部分，将数组中大于基准元素的放到数组后半部分，**每一轮循环都可以确定该基准元素最后的位置下标index，然后再对该数组的左半部1~ (index-1)位置、右半部(index+1)~n位置分别进行递归快排（这时候就可以将index位置排除在外了，因为它已经找到了它最终的位置）**。

而**改进的快排算法**首先也是找到基准元素然后遍历数组，将数组中小于基准元素的放到数组前半部分，将数组中大于基准元素的放到数组后半部分，不过不同的是这里的**每一轮循环都没有确定该基准元素最后的位置，这里的每一轮循环都只能保证该数组是局部有序的（即该数组的前半部元素都是小于该数组的后半部元素的，不过前半部内部元素之间不是有序的，后半部也是同理），所以需要接着给前半部、后半部的子数组继续进行递归快排（这里就不能将哪个位置的元素给排除出去了，每一轮循环都要对所有的元素进行排序，讲究一个不重不漏）**

==为什么改进的快排算法的循环结束条件是i<j而不是i<=j?==

注意改进的快排算法的while循环中做的是什么事，是交换i,j下标处的元素来使得数组变得局部有序，当i=j的时候说明此时的数组中只有一个元素了自然是有序的不需要处理，此时就可以结束循环了。

而普通的快排算法的while循环中做的是什么事，是遍历数组中所有元素以此来找到该基准的最终的位置，当i=j的时候此时依然需要遍历该位置的元素看看它是不是基准的最终位置。

==这里当while循环结束以后一定是i=j吗？不会是i>j吗？==

这里当while循环结束以后可能是i=j也可能是i>j，取决于具体的数据，图示如下：

这里当while循环结束以后可能是i=j也可能是i>j，不过这些都不重要，只要保证了数组是局部有序的，然后对子数组进行递归快排的时候注意子区间的划分一定得是正确的，还要注意不重不漏即可

首先看左边这幅图，当i,j相邻且进行最后一次元素交换位置以后（这个最后一次交换不一定发生，具体是否发生取决于当前i,j指向元素的大小），一定可以保证数组左半部的元素小于等于基准值mid，数组右半部的元素大于等于基准值mid，所以该数组是局部有序的；**同时还得注意这里的while循环里面有一层do-while循环，所以不管怎样都会执行一次i++，j--操作**，所以当while循环结束以后的指针位置如图中红线所示，此时该数组局部有序的分界线就是此时的 j，j+1（意思就是说1~ j这部分是数组的左半部分，(j+1)~n这部分是数组的右半部分）；如果以 i，i+1（这里的 i 已经是while循环结束时的位置 i 了）作为分界线虽然可以保证子数组划分的不重不漏但是却不对，因为此时的数组只是局部有序，在局部的内部是无序的，假如我们将i所指向的元素划到左半部可以保证此时右半部的元素（此时的右半部指代(i+1)~n这些元素）全部都大于i所指向的元素吗？答案是不行的，因为在局部的内部元素是无序的。所以必须得用j，j+1作为数组局部有序的分界线，有一种更好的理解方式：**在上述while循环内部，首先我们会对指针 i 进行do-while循环直到指针 i 指向的元素大于等于基准值mid，接着会对指针 j 进行do-while循环直到指针 j 指向的元素小于等于基准值mid，所以当上述的while循环结束以后此时指针 i 指向的元素一定是大于等于基准值mid的，此时指针 j 指向的元素一定是小于等于基准值mid的，而我们将数组划分成左右部分的时候其中左半部的元素一定得是小于等于基准值mid的，右半部的元素一定得是大于等于基准值mid的，所以我们必须得将指针 j 划分给左半部，将指针 j+1 划分给右半部（或者说将指针 i-1 划分给左半部，将指针 i 划分给右半部，二者是一个道理）**。

再来看右边这幅图，i,j中间隔了一个位置，当i,j此时进行最后一次元素交换位置以后（这个最后一次交换不一定发生，具体是否发生取决于当前i,j指向元素的大小），一定可以保证数组左半部的元素小于等于基准值mid，数组右半部的元素大于等于基准值mid，所以该数组是局部有序的；接着继续进行while循环，同时还得注意这里的while循环里面有一层do-while循环，所以不管怎样都会执行一次i++，j--操作，**然后i,j指针都停止在中间那个位置了吗？当然不是，这里取决于中间位置的元素值到底是多少，反正不管怎样当最后结束while循环时此时指针 i 指向的元素一定是大于等于基准值mid的，此时指针 j 指向的元素一定是小于等于基准值mid的，而我们将数组划分成左右部分的时候其中左半部的元素一定得是小于等于基准值mid的，右半部的元素一定得是大于等于基准值mid的，所以我们必须得将指针 j 划分给左半部，将指针 j+1 划分给右半部（或者说将指针 i-1 划分给左半部，将指针 i 划分给右半部，二者是一个道理）**。

==上述为什么要用do-while循环，就用普通的while循环不行吗？==

用普通的while循环不行，具体原因见下分析：

```Java
while(i<j){
    //do{i++;}while(nums[i]<mid);
    //do{j--;}while(nums[j]>mid);
    while(nums[i]<mid){
        i++;
    }
    while(nums[j]>mid){
        j--;
    }
    if(i<j){
        swap(nums,i,j);
    }
}
```

假设我们将上述的do-while循环改成了while循环，假设快排进行到后面碰到i,j指针指向两个元素值相等都等于基准值的情况（当数组元素中有很多重复值的时候这种情况还是很常见的），那么此时内部的while循环就会进入死循环永远走不出来，而do-while循环就可以避免这种情况。



#### 方式二：单指针法（用的少）

是什么：

和上述双指针法的过程差不多还是选取数组最左边的元素作为基准，就是这里仅仅只用一个指针从前往后遍历，当遍历到数组最后一个元素的时候代表遍历完成，那么仅仅只用一个指针那如何实现交换位置呢又和谁交换位置呢？这里我们用那个单指针去寻找比基准小的元素，然后用一个指针index去指向最左边的基准元素后面一个位置，当单指针找到了比基准小的元素就将它与index指针指向的元素交换位置，然后index指针后移一位，重复上述过程，这样当遍历完数组以后比基准小的元素都集中在了数组的前半部分，接着将基准元素与index指针前一个位置的元素进行交换位置即可（为什么是index指针前一个位置？因为当单指针找到比基准值小的元素以后就会和index指针的元素交换位置然后index指针接着就会后移一位，此时index指针就会指向比基准值大的元素）

**单指针法相对双指针法的好处就是更清楚数组遍历的过程什么时候结束，以及最后当结束遍历的时候基准到底是和谁交换位置**

```Java
//快速排序的单指针法：
public class Solution{
    public void quickSort(int[] nums,int left,int right){
        if(left<right){
            //这里的index作为基准元素的最后在数组中的位置下标
        	int index=partition(nums,left,right);
        	quickSort(nums,left,index-1);
        	quickSort(nums,index+1,right); 
        }
        return;
    }
    public int partition(int[] nums,int left,int right){
        int key=left;//选取数组最左边的元素作为基准元素
        int i=left;
        int index=left+1;//用于接收比基准值小的数组元素
        while(i<=right){
            while(nums[i]<=nums[key]){
                i++;
            }
            swap(nums,index,i);
            index++;
        }
        return index-1;
    }
    public void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
}
```







### （785）快速排序

解题思路：

利用快速排序算法将数组进行重排，但是一般的快排算法需要利用partition()函数找到基准元素最后在数组中的位置的方法最后会造成超时，所以这里利用了改进的快排算法，不用纠结每一次基准最后所在的位置

##### 一般的快排算法（不要这样做，麻烦）

```java
import java.util.Scanner;
import java.util.Random;
public class Main{
    private static final int N=100010;
    public static void main(String[] args){

        int n;
        n=sc.nextInt();
        int[] nums=new int[N];

            nums[i]=sc.nextInt();

    public static void quickSort(int[] nums,int left,int right){
        if(left<right){
            int index=partition(nums,left,right);
            quickSort(nums,left,index-1);
            quickSort(nums,index+1,right);
        }
        return;
    }
    public static int partition(int[] nums,int left,int right){
        // Random rand=new Random();
        // //随机选取一个基准元素
        // int key=rand.nextInt(right-left+1)+left;
        
        int key=(left+right)/2;//选取数组中间一个元素作为基准
        //将基准元素换到数组最左边，这样不妨碍其他元素
        swap(nums,left,key);
        key=left;//将基准元素换到最左边以后基准元素对应的下标也得更换
        int i=left,j=right;
        while(i<=j){
            while(i<=j && nums[i]<=nums[key]){
                i++;
            }
            while(i<=j && nums[j]>=nums[key]){
                j--;
            }
            if(i<j){
                swap(nums,i,j);
            }
        }
        swap(nums,key,j);
        return j;
    }
    public static void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
```

```Java
//改进的快排算法：不用纠结每一次基准的最终位置
import java.util.Scanner;
import java.util.Random;
public class Main{
    private static final int N=100010;
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        int[] nums=new int[N];
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        quickSort(nums,1,n);
        for(int i=1;i<=n;i++){
            System.out.print(nums[i]+" ");
        }
    }
    
    public static void quickSort(int[] nums,int left,int right){
        if(left<right){
            //选取数组中间的元素作为基准
            int mid=nums[(left+right)/2];
            int i=left-1,j=right+1;
            while(i<j){
                do{i++;}while(nums[i]<mid);
                do{j--;}while(nums[j]>mid);
                if(i<j){
                    swap(nums,i,j);
                }
            }
            quickSort(nums,left,j);
            quickSort(nums,j+1,right);
        }
        return;
    }
    
    public static void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
}
```

### notes：快速选择算法的时间复杂度（平均时间复杂度为O(n)）

快速选择算法是基于快速排序算法的，它的平均时间复杂度就为O(n)（具体证明见上图）。具体来说它是这样做的，首先还是和快排一样找到基准元素，然后找到它在数组中的最后的位置（==也不一定就非得是找到基准最后在数组中的位置，像改进的快排算法中找到左右堆的分界线 j 也可以，这样就能够确定我们要找的第k个元素到底是在左右堆中的哪一堆了==），假如最后基准元素在数组中的位置对应的就是我们要找的数组中的第k个最大的数那么我们直接返回该元素值就好，如果最后基准元素在数组中的位置比我们要找的第k个最大的数要小那么我们直接去该基准元素右半边数组中再去进行递归寻找第k个最大元素否则就去该基准元素左半边数组中去寻找第k个最大元素

##### 传统的快速选择算法（基于传统的快排算法，不要用这种算法）

```Java
import java.util.Scanner;
public class Main{
    private static final int N=100010;
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n,k;
        n=sc.nextInt();
        k=sc.nextInt();
        int[] nums=new int[N];
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        System.out.println(quickSelect(nums,1,n,k));
    }
    public static int quickSelect(int[] nums,int left,int right,int k){
        if(left<=right){
            int index=partition(nums,left,right);
            if(index==k){
                return nums[index];
            }else if(index<k){
                return quickSelect(nums,index+1,right,k);
            }else{
                return quickSelect(nums,left,index-1,k);
            }
        }
        return 0;
    }
    public static int partition(int[] nums,int left,int right){
        //选取数组中间元素作为基准
        int key=(left+right)/2;
        //将基准换到数组最左边
        swap(nums,left,key);
        key=left;
        
        int i=left,j=right;
        while(i<=j){
            while(i<=j && nums[i]<=nums[key]){
                i++;
            }
            while(i<=j && nums[j]>=nums[key]){
                j--;
            }
            if(i<j){
                swap(nums,i,j);
            }
        }
        swap(nums,key,j);
        return j;
    }
    public static void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
```

```Java
import java.util.*;
public class Main{
    static int N=100010;
    static int[] nums=new int[N];
    
    static int quickSelect(int[] nums,int left,int right,int k){
        if(left==right){
            /*
            当数组最后被筛选的只剩最后一个元素的时候那么就是我们要找的那个
            元素，为什么？
            因为首先数组中的第k个数肯定存在，其次当我们从大的数组中筛取元素
            的时候始终保证该元素在所筛取后的区间中，那么当最后区间被筛的越来
            越小以后该元素依然在筛取的区间中，最后当数组中只有一个元素时那么
            就得到该元素就是我们要寻找的那个元素
            */
            return nums[left];
        }
        int mid=nums[(left+right)/2];
        int i=left-1;
        int j=right+1;
        while(i<j){
            do{i++;}while(nums[i]<mid);
            do{j--;}while(nums[j]>mid);
            if(i<j){
                swap(nums,i,j);
            }
        }
        if((j-left+1)>=k){//注意这里直接使用下标来表示元素个数
            return quickSelect(nums,left,j,k);
        }else{
            return quickSelect(nums,j+1,right,k-(j-left+1));
        }
    }
    
    static void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int k=sc.nextInt();
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        System.out.println(quickSelect(nums,1,n,k));
    }
}
```

### （力扣215）数组中的第k个最大元素

![1707126789235](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1707126789235.png)

解题思路：

这题和上一题的第K个数本质上差不多，但是上一题是寻找数组中从小到大的第K个数而本题是寻找数组中从大到小的第k个数，注意不要将元素个数和元素下标混合起来使用否则很容易出错

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        return quickSelect(nums,0,nums.length-1,k);
    }

    public int quickSelect(int[] nums,int l,int r,int k){
        if(l==r){
            return nums[l];
        }
        int mid=nums[(l+r)/2];
        int i=l-1,j=r+1;
        while(i<j){
            do{i++;}while(nums[i]<mid);
            do{j--;}while(nums[j]>mid);
            if(i<j){
                swap(nums,i,j);
            }
        }
        /*
        下述过程中犯了一个很明显的错误：那就是将数组元素个数和数组下标混合起来使用了。
        举个例子，长度为len的数组经过快速排序算法（快速选择）以后数组中第k个最大元素的
        下标将始终是len-k，这一点是不会改变的，而这里我们将每次更新len为子数组的长度，
        这样是不对的
        
        int len=r-l+1;
        //这里的的len是子数组中元素个数（每次迭代的时候会更新l和r为子数组的左右下标，
        //所以顺带着len也更新为了子数组的长度）
        
        if(j<(len-k)){
        //此时说明数组中第K大的元素在数组右半部
        //这里的j和len-k是数组中的下标
            return quickSelect(nums,j+1,r,k);
        }else{
            return quickSelect(nums,l,j,k-((len-1)-(j+1)+1));
        }
        */
        
        //注意下述中是如何完全用下标来表示元素个数的
        if(r-j+1>k){
            return quickSelect(nums,j+1,r,k);
        }else{
            return quickSelect(nums,l,j,k-(r-(j+1)+1));
        }
    }
    public void swap(int[] nums,int i,int j){
        int t=nums[i];
        nums[i]=nums[j];
        nums[j]=t;
    }
}
```





## notes：关于Scanner的next()、nextLine()方法的区别

- 相同点：

  ​	都是用于输入字符串变量

- 不同点：

  ​	（1）next()方法遇到空格就终止当前输入，比如输入"hello world"当遇到"hello"后面的空格时就终止了当前的输入，所以当前输入的字符串中是不包含空格和"world"字符串的

  ​	（2）nextLine()方法遇到空格不会终止当前输入，而是将空格作为字符串的一个内容进行输入，比如输入"hello world"时当遇到"hello"后面的空格时就将它作为字符串的一部分继续进行输入，所以当前输入的字符串为"hello world"。只要输入的内容在同一行当中，nextLine()方法都能捕获到它们，当nextLine()方法遇到enter键进行换行时才终止当前输入。

## 2、归并排序

### 是什么：

归并排序是一种基于分治思想的高效排序算法，其核心思想是将待排序的序列拆分成两个子序列，对每个子序列再进行拆分直至不可拆分然后对相邻的子序列进行排序合并，然后再将排好序的子序列合并成一个有序的整体序列。归并排序的时间复杂度为O(nlogn)，是一种稳定的排序算法。 

![1681628832224](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681628832224.png)



### 怎么办：

先取中间位置的元素将数组一分为二，然后对两个子数组继续取它们各自中间位置的元素将子数组继续一分为二，重复上述步骤，直至子数组中只含有一个元素，然后就可以合并相邻的子数组了，先设置一个临时数组暂时存放合并后的相邻的子数组，然后将临时数组的元素值赋值给原数组，重复上述步骤直到整个数组有序

```Java
    public static void merge_sort(int[] nums,int l,int r){
        if(l>=r){
            return;
        }
        int mid=l+r>>1;
        merge_sort(nums,l,mid);

            if(nums[i]<nums[j]){

            }else{
                temp[k++]=nums[j++];
            }

            temp[k++]=nums[i++];
        }
```

### （788）逆序对的数量

![1681652345121](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681652345121.png)

解题思路：

在将有序的左右子数组合并成一个新的有序子数组的过程中，我们是利用双指针的不断移动实现元素数值比较的，要想实现逆序对，则要找出在右子数组中的数值比左子数组中的数值小的数值对（比如在右子数组中选定数值2以后，可以在左子数组中选定数值3、5、7、9构成（3，2）、（5，2）、（7，2）、（9，2）四个逆序对，**那么子数组本身的逆序对不考虑了吗？当然不考虑，因为子数组已经排过序了啊，所以子数组本身不存在逆序对，而且在子数组的构成过程中也是由子数组的子数组构成的，在子数组的子数组的合并过程中已经计算过了逆序对啊）**，综上只要我们在合并两个有序子数组的过程中注意统计右数组的j指针指向的元素比左数组的i指针指向的元素小的情况就能够统计出来总共有多少个逆序对了

还有一个注意点就是，这里总共有n个数（n最大为10^ 5），这n个数最多可以构成多少个逆序对呢？当它们逆序排列的时候构成的逆序对数目最多，为（n-1）+（n-2）+（n-3）+...+1=n*（n-1）/2，为O(n^ 2)数量级，而这里的n=10^5，所以 n^ 2=10^10，所以最多有 10^10个逆序对，已经超过了int型的表示范围，所以如果你想用int型数据来记录总共有多少个逆序对的话是行不通的，这里得用long型数据

![1681654014019](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681654014019.png)

```Java
public class Main{

    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        int[] nums=new int[N];
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        // int count=merge_sort(nums,1,n);
        //这里为什么不用int型数据记录总共有多少个逆序对？
        //因为数据超出int型的表示范围
        long count=merge_sort(nums,1,n);
        System.out.println(count);
        return;
    }
    
    public static long merge_sort(int[] nums,int l,int r){
        if(l>=r){
            return 0;
        }
        int mid=l+r>>1;
        // int count=merge_sort(nums,l,mid)+merge_sort(nums,mid+1,r);
        long count=merge_sort(nums,l,mid)+merge_sort(nums,mid+1,r);
        int[] temp=new int[r-l+1];
        int i=l,j=mid+1;
        int k=0;
        while(i<=mid && j<=r){
            if(nums[i]<=nums[j]){
                temp[k++]=nums[i++];
            }else{
                /*
                当右数组指针j指向的元素比左数组指针i指向的元素小的时候，那么在右数组中取出
                指针j指向的元素可以构成多少个逆序对呢？
                答案就是mid-i+1
                */
                temp[k++]=nums[j++];
                count+=mid-i+1;
            }
        }
        while(i<=mid){
            temp[k++]=nums[i++];
        }
        while(j<=r){
            temp[k++]=nums[j++];
        }
        for(i=l,j=0;i<=r;i++,j++){
            nums[i]=temp[j];
        }
        return count;
    }
}
```

```Java
                l1=l1.next;
```

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode sortList(ListNode head) {
        if(head==null){
            return head;
        }
        //这里创建的tail指针指向链表最后一个节点
        ListNode tail=head;
        while(tail.next!=null){
            tail=tail.next;
        }
        return merge_Sort(head,tail);
    }

    
    public ListNode merge_Sort(ListNode head,ListNode tail){
        if(head==null || head==tail){//当链表中没有元素或者只有一个元素的话直接返回不需要再排序
            return head;
        }
        ListNode slow=head,fast=head,pre=head;
        //这里的slow、fast代表快慢指针，那么pre指针指向的是什么呢？

        while(fast!=null && fast.next!=null){
            //为什么循环条件这样写呢？具体见下述快慢指针这一节的内容
            pre=slow;
            slow=slow.next;
            fast=fast.next.next;
        }
        /*
        观察上述while循环我们发现，每次循环时都是先给pre指针赋值：pre=slow，接着slow指针进行
        移动，fast指针进行移动，最后循环结束时fast指针指向链表末尾，slow指针指向链表中间
        节点（如果只有一个中间节点的话则slow指针指向该节点，如果有两个中间节点的话则slow指针
        指向两个中间节点中的后一个），而pre指针则指向中间节点的前一个节点
        */
        
        
        pre.next=null;
        ListNode l=merge_Sort(head,pre);
        ListNode r=merge_Sort(slow,tail);
        /*
        前面我们已经知道了slow指针指向链表的中间节点，而pre指针指向中间节点的前一个节点，
        我们根据pre指针将链表一分为二，前半部分为(head,pre)段，后半部分为(slow,tail)段，
        接着对这两段子链表继续进行递归的操作。
        这里有两个问题：（1）为什么令pre.next=null?（2）为什么要根据pre指针进行链表的划分，
        根据slow指针进行划分不行吗？
        （1）我们将链表划分为了两部分，(head,pre)段和(slow,tail)段，然后对这两段分别进行
        排序，如果不令pre.next=null的话那么pre.next本身应该是slow，这样在给链表前半部分
        (head,pre)段进行排序的时候指针会顺着一直延伸到(slow,tail)段，这样就不是单独给
        (head,pre)段进行排序了。
        （2）其实不论根据哪个指针进行链表的划分，只要划分以后问题的规模变小了就是可以的（反映在
        本题中就是子链表的数目相较于原链表变少了则该划分结果就是可行的），所以理论上只要是链表
        中间的某个节点进行划分都可以，那这里就有一个问题：slow指针始终指向链表中间的某个节点吗，
        它不会指向链表的尾节点吗？
        答案是slow指针不是始终指向链表的中间节点它也会指向链表的尾节点，当不断进行链表的划分
        以后最后链表被划分成了只包含两个节点的小链表，对于这个小链表再进行划分的时候初始时
        slow指针、fast指针都指向链表的头节点，循环结束后fast指针指向了尾节点后面的null节点，
        而slow指针指向了尾节点，所以此时如果再根据slow指针进行划分的话问题规模完全没有变小（原先
        链表中就有两个节点，然后划分以后链表中还有两个节点，接着一直划分，就在这里陷入了死循环）
        */
        return merge(l,r);
    }

        ListNode head=new ListNode();
        ListNode p=head;
        while(l1!=null && l2!=null){
            if(l1.val<=l2.val){
                p.next=l1;
                p=p.next;
                l1=l1.next;

                p.next=l2;
                p=p.next;
                l2=l2.next;
            }
        }
        if(l1!=null){
            p.next=l1;
        }
        if(l2!=null){
            p.next=l2;
        }
        return head.next;
    }
}
```

```java
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode sortList(ListNode head) {
        if(head==null){
            return head;
        }
        //这里创建的tail指针指向链表最后一个节点
        ListNode tail=head;
        while(tail.next!=null){
            tail=tail.next;
        }
        return merge_Sort(head,tail);
    }

    
    public ListNode merge_Sort(ListNode head,ListNode tail){
        if(head==null || head==tail){//当链表中没有元素或者只有一个元素的话直接返回不需要再排序
            return head;
        }
        ListNode slow=head,fast=head;

        
        //这里又为什么出错了？
        while(fast!=null && fast.next!=null){
            slow=slow.next;
            fast=fast.next.next;
        }
        ListNode mid1=slow,mid2=slow.next;
        mid1.next=null;//这里进行了左右两个子链表的断链
        
        
        ListNode l=merge_Sort(head,mid1);
        ListNode r=merge_Sort(mid2,tail);
        //这里的mid1就是原来的slow指针，根据slow指针进行划分会导致死循环
        
        return merge(l,r);
    }
    
    public ListNode merge(ListNode l1,ListNode l2){
        ListNode head=new ListNode();
        ListNode p=head;
        while(l1!=null && l2!=null){
            if(l1.val<=l2.val){
                p.next=l1;
                p=p.next;
                l1=l1.next;
            }else{
                p.next=l2;
                p=p.next;
                l2=l2.next;
            }
        }
        if(l1!=null){
            p.next=l1;
        }
        if(l2!=null){
            p.next=l2;
        }
        return head.next;
    }
}
```

## 3、二分

### 是什么：

二分是一种常用的算法思想，也称为二分查找。在有序数组中二分通过每次查找数组中间位置的元素并比较该元素与待查找元素之间的大小关系每次都可以将搜索范围缩小一半，将O(n)的查找时间复杂度降低到O(log n)级别，具有高效、简单、易实现等特点。

二分查找的**本质说到底还是寻找子区间的边界：**

**（1）首先我们将要寻找的目标元素target划分成左右子区间的边界（具体是将目标元素划分成左子区间的边界还是右子区间的边界这都随意）**

**（2）比如原本的数组下标范围为[l,r]，我们现在将目标元素target划分成左子区间的边界，为了寻找到左子区间的边界，每次通过数组中间位置的元素mid将数组进行一分为二，然后看mid是否在左子区间的范围内：如果在的话则可以将查找范围限定在[mid,r]范围内，如果不在的话则可以将查找范围限定在[l,mid-1]范围内，重复上述过程直至最后找到左子区间的边界**

即使是在nums[]数组中寻找一个目标值target的过程也不例外，此时可以看成区间长度为1的子区间的端点问题

 二分查找算法的前提条件是：数组必须是有序的，否则无法通过比较查找值与数组中的元素大小来确定查找方向。 



#### notes：二分法一定得注意边界条件

二分查找数组区间问题是什么？

意思就是说一个**有序数组，里面的元素可能是重复的**，现在让你来求元素值target在数组中第一次出现以及最后一次出现时的下标（**注意这里的target也有可能不在数组中，即最后找不到的情况**），首先这里需要明确的一点是假如数组中存在目标元素target的话则无论是左边界还是右边界一定都是可以求出来的；假如数组中不存在目标元素的话则求不出来，但是**不论是求出来该目标元素还是没求出来最后当结束循环时都是指针left>right，根本就没法通过此来判断是否找到了边界，所以当结束循环的时候我们还得判断一下是否找到了左边界或者右边界**（找到了左边界就不用再判断右边界是否存在了，因为一定存在，我们判断左边界是否存在的原因是为了判断该目标元素是否在数组中，如果在的话则返回它的左边界下标，不能当循环结束后直接返回下标，因为可能该目标元素根本不在数组中，你都不存在还返回个毛线）

### （力扣4）寻找两个正序数组的中位数

![1707527709857](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1707527709857.png)

解题思路：

==这里要求时间复杂度为O(log(m+n))，所以很显然想到二分查找==，但是二分查找只适合有序数组，这里的两个数组虽然各自有序但是整体是无序的，没法对于整体利用二分查找啊。

对于一个有序数组a[]的中位数我们直接返回中间下标处的元素即可，那么对于两个有序数组a[]、b[]整体构成的中位数呢？先求出a[]数组的中位数，再求出b[]数组的中位数，然后二者求平均数吗？

当然不对，因为两个数组构成的整体而言它的中位数不一定就是a[]数组的中位数和b[]数组的中位数，举例：a[]数组很长但是里面的元素都很小，b[]数组很短但是里面的元素都很大，所以对于a[]数组、b[]数组整体而言b[]数组就相当于是直接放在a[]数组元素后面的，此时的中位数一定来自于a[]数组（和b[]数组没有关系）。

这里提供一个==可以用于求解两个有序数组中第k小数的二分查找算法==：

（1）首先我们来思考一下这样一个问题：对于两个有序数组如何通过暴力算法找到第k小数呢？

我们想到用双指针，一个指针left指向a[]数组开头元素，另一个指针right指向b[]数组开头元素，再用一个数count记录当前是第几小的数，然后进行比较并不断移动指针，如果a[left]>b[right]并且count<k则移动right指针，然后进行下一轮比较，这样当最后count=k时a[left]和b[right]两个元素中较小者一定就是第k小数。

上述算法时间复杂度为O(m+n)（假设两个数组a[]，b[]长度分别为m,n），因为这里两个指针每次都是移动一位，所以时间复杂度就是这么多。

（2）考虑改进算法。

分析一下上述算法，发现思路是对的，但是有点慢这个慢主要是指针移动慢导致的（指针每次移动一位），那么有没有办法让指针每次多移动几位呢？当然是可以的，具体介绍如下：

假设要找两个有序数组a[]、b[]中的第k小数，则每次我们让两个指针各自移动k/2位即代表每次从两个数组中各自取出==第 k/2 个数即a[k/2]和b[k/2]==，如果a[k/2]<b[k/2]则a[k/2]一定不会是两个有序数组中的第k小的数，为什么？

因为首先a[1]、a[2]、、、a[k/2]和b[1]、b[2]、、、b[k/2]这里就有k个元素了，在这些元素当中a[k/2]都没法排到第k位（因为a[k/2]<b[k/2]），更不用说对于全部a[]数组和b[]数组整体而言了；同理a[1]、a[2]、、、a[k/2-1]都不可能是两个有序数组中的第k小的数，所以我们可以直接将a[1]、a[2]、、、a[k/2]这k/2个数扔了，在剩下来的数组a[k/2+1]、a[k/2+2]、、、、和b[1]、b[2]、、、中继续寻找第k-(k/2)小的数，为什么这里是寻找第k-(k/2)小的数呢？

因为刚刚已经删去了a[1]、a[2]、、、a[k/2]这k/2个数，这些数也是占位置的。

这里还得注意一个问题，就是每次都能从数组中找到第k/2个元素吗？

当然不是，可能数组很短根本就没有第k/2个元素，此时我们就取该数组的最后一个元素即可。

分析上述改进算法：因为是寻找两个有序数组中的第k个数，每次从两个有序数组中寻找第k/2个数，然后抛弃其中的k/2个数，接着更新k=k-(k/2)，然后重复上述过程直到其中一个数组为空或者是k=1，时间复杂度为：O(logk)，这里的k因为是两个数组的中位数，所以k=(m+n)/2，所以时间复杂度为O(log(m+n)/2)即O(log(m+n))

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int len1=nums1.length;
        int len2=nums2.length;
        int totalLen=len1+len2;
        /*
        这里要注意数组的中位数可能有两个，当数组元素为偶数个时此时的中位数有两个，
        我们要返回的结果就是这两个中位数的平均值
        */
        if((totalLen&1)==1){//此时两个数组中总共有奇数个元素，此时的中位数只有一个
            return 1.0*findKth(nums1,0,len1-1,nums2,0,len2-1,totalLen/2+1);
        }else{
            int res1=findKth(nums1,0,len1-1,nums2,0,len2-1,totalLen/2);
            int res2=findKth(nums1,0,len1-1,nums2,0,len2-1,totalLen/2+1);
            return 1.0*(res1+res2)/2;
        }
    }

    //寻找两个有序数组a[l1~r1]、b[l2~r2]整体构成的第k小的数
    public int findKth(int[] a,int l1,int r1,int[] b,int l2,int r2,int k){
        int len1=r1-l1+1;
        int len2=r2-l2+1;
        if(len1>len2){
            return findKth(b,l2,r2,a,l1,r1,k);//确保先处理较短的数组
        }
        
        //这里的递归终止条件是其中一个数组为空或者是k=1
        if(len1==0){
            return b[l2+k-1];
        }
        if(k==1){
            return Math.min(a[l1],b[l2]);
        }

        /*
        当要找到两个数组整体构成的第k小的数时，每次从两个数组中分别取出第(k/2)个元素
        进行比较，这里要注意可能会遇到数组中没有第k/2个元素的情况，此时就取该数组的最后
        一个元素即可
        */
        int i=l1+Math.min(k/2,len1)-1;
        int j=l2+Math.min(k/2,len2)-1;
        
        if(a[i]<b[j]){
            return findKth(a,i+1,r1,b,l2,r2,k-(i-l1+1));
        }else{
            return findKth(a,l1,r1,b,j+1,r2,k-(j-l2+1));
        }
    }
}
```

### （力扣33）搜索旋转排序数组

![1707485748268](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1707485748268.png)

解题思路：

我们可以对有序数组进行二分查找，但是对于==旋转之后的数组已经不是有序的了，这时候该怎么办呢？==

可以==将数组一分为二，其中一定有一半数组是有序的，另一半数组可能有序也可能无序==（具体取决于当初旋转的那个位置是不是数组中点），==假如另一半数组无序的话该怎么处理呢？对另一半无序数组继续进行一分为二的操作，则又可以找到一半有序、一半无序的数组，重复上述过程直到将数组划分成只有一个元素==

```java
class Solution {
    /*
    这里得明确一个思想：那就是将数组进行旋转以后再一分为二之后，其中一定有一半数组是有序的，
    另一半数组可能有序也可能无序（这具体取决于当初旋转的位置，如果当初是在数组中点进行旋转
    的话则另一半数组也是有序的否则另一半数组无序），我们对于有序数组利用二分查找，对于无序
    数组继续进行上述一分为二的操作然后又可以找到一半有序数组一半无序数组，然后重复上述过程，
    直到最后数组被分割成了只有一个元素
    */
    public int search(int[] nums, int target) {
        int res=search2(nums,0,nums.length-1,target);
        if(nums[res]==target){
            return res;
        }else{
            return -1;
        }
    }

    public int search2(int[] nums,int l,int r,int k){
        if(l==r){
            return l;
        }
        int mid=l+r>>1;
        if(nums[l]<nums[mid]){//说明数组中[l,mid]这一段是有序的
            int index=binary_Search(nums,l,mid,k);
            if(nums[index]==k){//说明要找的目标值k就在[l,mid]这一段内
                return index;
            }else{
                //说明要找的目标值k不在[l,mid]这一段内，所以接下来要去[mid+1,r]这一段
                //无序数组中继续寻找目标值k
                return search2(nums,mid+1,r,k);
            }
        }else{//说明数组中[l,mid]这一段是无序的，那么[mid+1,r]这一段就是有序的
            int index=binary_Search(nums,mid+1,r,k);
            if(nums[index]==k){
                return index;
            }else{
                return search2(nums,l,mid,k);
            }
        }
    }
    public int binary_Search(int[] nums,int l,int r,int k){
        while(l<r){
            int mid=l+r+1>>1;
            if(nums[mid]<=k){
                l=mid;
            }else{
                r=mid-1;
            }
        }
        return l; 
    }
}
```

```java
class Solution {
```

## 4、高精度计算

### 是什么：

高精度计算也被称作大整数计算，当数据的范围（或者是数据运算的结果）超过了int型表示范围的时候也就没法用int类型表示了，但是我们又有这种运算的需求所以就创建了高精度计算



### 怎么办：

首先需要解决的就是大整数如何输入的问题，因为大整数已经超过了int型表示范围所以我们是没法创建一个int型数据然后输入数值的，所以这里我们利用的是输入一个字符串的方式（该字符串就是大整数的数值）；还有就是解决大整数如何存储的问题，一个整数但是它已经超过了int型数据的表示范围那么我们该如何存储呢？这里想到就是用int型数组来挨个存储大整数的每一位，但是还有一个问题那就是用数组存储的话首先得确定数组的长度，而数组的长度得取决于实际的大整数，这就很不方便，所以我们换个办法改用集合来存储大整数的每一位，这里指定集合的泛型为Integer类型；**这里还得注意一个问题，因为这里涉及高精度的计算加减乘除等，很多运算会产生进位而如果我们利用集合顺序的存储大整数的每一位（即从左到右依次存储百位、十位、个位）这样后续计算结果产生了进位我们没法在集合的首元素位置给它添加一个数，所以这里我们利用集合逆序的存储大整数的每一位（即从左到右依次存储个位、十位、百位），这样即使最后的运算结果产生了进位我们也只要在集合的末尾添加元素就好**



#### 常见的高精度计算类型：（A、B：代表高精度数（大整数）；a、b：代表单精度数（普通int型整数））

#### 一、高精度加法：A+B

#### （791）高精度加法

![1680962493145](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1680962493145.png)

解题思路：

这里首先利用字符串读入两个高精度数，然后分别再用两个集合存储这两个高精度数，最后让这两个集合的对应位分别相加即可，要注意的是两个集合的低位数字相加可能会产生进位，还得注意两个集合可能不一样长，最后还有一点那就是假如两个集合一样长的话最后的高位相加也可能产生进位别忘了这一点

```java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        //利用字符串的方式输入两个高精度数
        String A=sc.next();
        String B=sc.next();
        //利用集合的方式存储高精度数，这里注意要逆序存储，方便后续计算
        List<Integer> list1=new ArrayList<>();
        for(int i=A.length()-1;i>=0;i--){
            list1.add(A.charAt(i)-'0');
        }
        List<Integer> list2=new ArrayList<>();
        for(int i=B.length()-1;i>=0;i--){
            list2.add(B.charAt(i)-'0');
        }
        
        //用于存储两个高精度数相加的结果的集合
        List<Integer> list3=add(list1,list2);
        for(int i=list3.size()-1;i>=0;i--){
            System.out.print(list3.get(i));
        }
        return;
    }
    
    //定义两个高精度数的加法方法
    public static List<Integer> add(List<Integer> list1,List<Integer> list2){
        List<Integer> list3=new ArrayList<>();
        int t=0;//用于表示两个数组低位相加产生的进位，初始化为0
        for(int i=0; i<list1.size() || i<list2.size(); i++){
            /*
            这里本来是想用t来表示两个数组低位相加的结果，
            即t=t+list1.get(i)+list2.get(i)，但是两个集合可能不一样长那么对于短的
            集合来说当i大于它的集合长度时就会产生下标越界异常，所以这里得分类讨论
            */
            if(i<list1.size()){
                t+=list1.get(i);
            }
            if(i<list2.size()){
                t+=list2.get(i);
            }
            list3.add(t%10);
            t/=10;//别忘了数组低位相加可能会产生进位
        }
        /*
        别忘了这里，在两个数组的最高位相加也可能产生进位，这时候它的长度就已经超过
        了集合的长度了，所以也就不会再进入上述的循环，但是我们还得将进位的结果加入
        到结果集合中
        */
        if(t>0){
            list3.add(t);
        }
        return list3;
    }
}
```

#### 二、高精度减法：A-B

#### （792）高精度减法

![1680963777115](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1680963777115.png)

解题思路：

高精度减法大部分和高精度加法类似，但是也有一些特殊点，比如这里就有一个顺序关系：大的数减去小的数可以直接减，但是小的数如何减去大的数呢？

如果是int型数据的话我们可以直接减它会自动帮我们计算，但是这里的是大整数，超过了int型表示范围所以需要我们自己定义如何做减法，**回顾一下实际中我们是怎么做的？小的数减去大的数我们是不是还是把转换成大的数减去小的数，然后最后的结果再补上一个负号"-"，这里也是如此，将小的数减去大的数转化成大的数减去小的数，所以我们得首先判断两个大整数的大小（这里没法直接比较两个大整数谁比较大，因为都已经超出int型范围了，所以需要我们从集合中挨个选取元素进行比较）**；

第二个特殊点就是加法我们只需要关注低位是否会产生进位就好，但是减法我们得关注当前位置的低位是否够减是否需要借位以及当前位置借了一位以后自己是否够减是否需要像高位借位（**但是总的来说这里其实我们只需要关注当前位置是否给低位借位即可，如果当前位置不够减的话那么最后当前位置相减的结果就是负数，这时候再向高位借1位也是不迟的**）；

最后还有一个问题，那就是两数相减可能会产生前导0，比如123-121=002，这里的结果应该是2，它前面的0就是前导0，我们得删去前导0

```Java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String A=sc.next();
        String B=sc.next();
        //创建两个集合用来存储大整数
        List<Integer> list1=new ArrayList<>();
        for(int i=A.length()-1;i>=0;i--){
            list1.add(A.charAt(i)-'0');
        }
        List<Integer> list2=new ArrayList<>();
        for(int i=B.length()-1;i>=0;i--){
            list2.add(B.charAt(i)-'0');
        }
        
        /*
        存储好了两个大整数A,B接下来就是计算它们的差，这里可能为负数，如果A<B的话
        我们没法计算还是得把转换为B-A然后再结果前面添上负号，所以始终是大的数减去小的数
        所以我们在做减法之前得判断两个大整数的大小关系
        */
        List<Integer> ans=sub(list1,list2);
        for(int i=ans.size()-1;i>=0;i--){
            System.out.print(ans.get(i));
        }
    }
    
    //定义比较两个大整数之间大小的方法
    public static boolean cmp(List<Integer> list1,List<Integer> list2){
        if(list1.size()>list2.size()){
            return true;
        }else if(list1.size()<list2.size()){
            return false;
        }else{
            for(int i=list1.size()-1;i>=0;i--){
                if(list1.get(i)>list2.get(i)){
                    return true;
                }else if(list1.get(i)<list2.get(i)){
                    return false;
                }
            }
            return true;
        }
    }
    
    //定义两个大整数的减法
    public static List<Integer> sub(List<Integer> list1, List<Integer> list2){
        if(!cmp(list1,list2)){
            //如果大整数A<B的话，则我们反过来计算B-A同时在最后结果前输出一个负号"-"
            System.out.print("-");
            return sub(list2,list1);
        }
        List<Integer> list3=new ArrayList<>();
        /*
        这里两数相减很麻烦，因为你不仅得判断当前位置是否需要给低位借1，还得判断给低位借了1以后当前
        位置是否够大是否还需要向高位再借1（但是总的来说我们只要关注当前位置是否给低位借了1位即可，
        因为即使当前位置不够减的话最后当前位置相减的结果为负数这时候我们再向高位借1位也是不迟的）
        */
        int t=0;//这里的t表示被减数当前位置是否给低位借了1
        for(int i=0;i<list1.size();i++){
            /*
            这里本来应该是用t来表示两个数组当前位置相减的结果，
            即t=list1.get(i)-t-list2.get(i)，但是因为假如list2很短则可能越界，
            所以得判断一下
            */
            t=list1.get(i)-t;
            if(i<list2.size()){
                t-=list2.get(i);
                /*
                这里就表示两数当前位置上相减的结果了，如果不够的话则这里相减
                的结果就是负数，这时候再向高位借1位也不迟（向高位借1反映在
                低位就是加10）
                */
            }
            list3.add((t+10)%10);
            /*
            如果两个数相减为正数则加10后再余10就是本身，如果两个数相减后为负数
            则加10后余10就是向高位借1以后计算的结果
            */
            if(t<0){
                t=1;//如果当前位置的数相减小于0则代表需要向高位借1
            }else{
                t=0;
            }
        }
        
        //去除结果中的前导0
        for(int i=list3.size()-1;i>0;i--){
            /*
            为什么这里的循环结束条件是i>0而不是i>=0?
            注意这里我们是要做什么，是为了消除运算结果中的前导0，比如结果002则我们就要消除2前面的
            那两个0，但是假如结果就是000则最后一位0也要消除吗？当然不要，最后的结果就是0，我们只要
            消除结果0前面的那两个前导0就可以了
            */
            if(list3.get(i)==0){
                list3.remove(list3.size()-1);
            }else{
                break;
            }
        }
        return list3;
    }
}
```



#### 三、高精度乘法：A*b

#### （793）高精度乘法

![1680965459063](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1680965459063.png)

解题思路：

注意这里的高精度乘法指的是一个大整数A和一个小整数b的相乘（如果是两个大整数A*B，暂时还不知道如何处理），**注意这里是将小整数b看作是一个整体和大整数A进行相乘的，比如说b=15我们也是将15看作是一个整体依次去和大整数A的每一位进行相乘，而不是将15分开看待（将15分开看待的意思就是先计算5和大整数A的每一位进行相乘，再计算1和大整数A的每一位相乘），所以说这里乘法会产生进位而且进位可能不止一位（就比如说b=15，A的当前位置的数是7，则二者当前相乘的结果为105，所以得到当前位置的结果就是5而产生了两位进位）**

```java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String A=sc.next();
        List<Integer> list1=new ArrayList<>();
        for(int i=A.length()-1;i>=0;i--){
            list1.add(A.charAt(i)-'0');
        }
        int b=sc.nextInt();
        List<Integer> ans=mul(list1,b);
        for(int i=ans.size()-1;i>=0;i--){
            System.out.print(ans.get(i));
        }
    }
    
    //定义大整数的乘法
    public static List<Integer> mul(List<Integer> list1,int b){
        List<Integer> list2=new ArrayList<>();//用来存储大整数相乘后的结果
        int t=0;//表示两个低位数相乘的进位
        for(int i=0; i<list1.size() || t!=0; i++){
            //这里也许当最高位相乘会产生进位，这时候就超过list1.size()-1了
            if(i<list1.size()){               
                t+=list1.get(i)*b;//这里用t表示低位相乘的结果
            }
            list2.add(t%10);
            t/=10;
        }
        //去除结果中前导0的操作，这里的b可能为0所以可能会产生前导0
        while(list2.size()>1 && list2.get(list2.size()-1)==0){
            list2.remove(list2.size()-1);
        }
        return list2;
    }
}
```

#### 四、高精度除法：A/b

#### （794）高精度除法

![1680965829758](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1680965829758.png)

解题思路：

大部分和高精度乘法差不多，不过也有一些**除法特有的问题：首先不论是加法、减法还是乘法统统是先从低位开始运算的，但是到了除法就不同了，除法是先从高位开始运算的**；还有就是除法运算的结果我们用一个集合去存储这个结果，该结果是正序的（因为是从高位开始算起的，所以首先得到的是高位的数据），但是为了和前面的加法、减法、乘法运算匹配，这里我们需要将集合中的元素翻转一下（可以利用工具类Collections类中的reverse()方法）；最后还得注意一个点需要将余数加入到集合中，所以集合中的最后一个元素是余数，那么当要输出商的时候是从集合中的倒数第二个元素开始输出的

```Java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
import java.util.Collections;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String A=sc.next();
        List<Integer> list1=new ArrayList<>();
        for(int i=A.length()-1;i>=0;i--){
            list1.add(A.charAt(i)-'0');
        }
        int b=sc.nextInt();
        List<Integer> ans=div(list1,b);
        for(int i=ans.size()-2;i>=0;i--){
            //这里为什么是从集合中的倒数第二个元素开始输出？
            //因为集合中的最后一个元素是余数，当要输出商的时候是从倒数第二位开始输出的
            System.out.print(ans.get(i));
        }
        System.out.println();
        System.out.println(ans.get(ans.size()-1));
    }
    
    //定义大整数的除法（除法和前面的运算不同，因为它是从高位开始算起的）
    public static List<Integer> div(List<Integer> list1,int b){
        List<Integer> list2=new ArrayList<>();//用来存储大整数除法的结果
        int r=0;//用来存储高位相除的余数
        for(int i=list1.size()-1;i>=0;i--){
            r=r*10+list1.get(i);
            list2.add(r/b);//可能会产生前导0
            r%=b;
        }
        //直到这里List2集合中存储的元素都是正序的，得将它翻转过来，因为前面的加法、减法、乘法运算中
        //集合中的结果都是逆序的
        Collections.reverse(list2);//将集合list2翻转
        //去除前导0的操作
        while(list2.size()>1 && list2.get(list2.size()-1)==0){
            list2.remove(list2.size()-1);
        }
        list2.add(r);//将余数加入到集合中
        return list2;
    }
}
```

## 5、前缀和与差分

### 是什么：

（1）前缀和指的是数组某下标之前的所有元素的和（包括该元素本身），类似于数组的前n项和，比如说现在有一个数组a[n]，则对应的前缀和数组为s[n]，其中s[i]=a[0]+a[1]+a[2]+...+a[i]

（2）类似于求导与积分，差分与前缀和也是一组逆运算，比如说现在有一个数组a[n]，则它对应的差分数组为b[n]，其中a[i]=b[0]+b[1]+b[2]+...+b[i]，这里我们称b[n]数组是a[n]数组对应的差分数组，同时也可以称a[n]数组是b[n]数组的前缀和数组



### 为什么：

（1）为什么要专门创建前缀和这个概念呢？因为在实际应用中我们会遇到让我们求数组i下标到j下标的所有元素之和，这时候我们当然可以利用循环来求解，但是如果遇到让我们求解多组i下标到j下标的元素之和那我们就得利用多次循环了时间复杂度太高了，有没有什么更简单的办法呢？所以就提出了前缀和的概念，现在我们有前缀和数组s[n]（其中s[i]=a[0]+a[1]+a[2]+...+a[i]），所以要求数组i下标到j下标的所有元素之和只要求s[j]-s[i-1]即可，时间复杂度降低到了O(1)

（2）为什么要专门创建差分这个概念呢？因为在实际应用中我们会遇到数组的某一个子区间内的数值都加上c1，然后另一个子区间的数值都加上c2，，，等这些情况，然后问你最后数组的数值都是多少，这种情况我们当然可以利用循环一个个求解，但是同样的时间复杂度太高了，利用差分数组的概念我们可以快速解决这类问题，

比如有这么一个问题：

给定区间[l，r]，让我们把a数组中的[ l, r]区间中的每一个数都加上c,即 a[l] + c , a[l+1] + c , a[l+2] + c ,,,,,, a[r] + c;

暴力做法是for循环l到r区间，时间复杂度O(n)，如果我们需要对原数组执行m次这样的操作，时间复杂度就会变成O(n*m)。 考虑差分做法，(差分数组派上用场了)。

始终要记得，a数组是b数组的前缀和数组，比如对b数组的b[i]的修改，会影响到a数组中从a[i]及往后的每一个数。

首先让差分b数组中的 b[l] + c ,则a数组中位置l包括后面所有位置的元素都会受到影响 即：变成 a[l] + c , a[l+1] + c ,,,+a[r]+c, a[r+1]+c,,,,, a[n] + c;

但是我们只需要在[l，r]这个区间的数值加上c啊，后面[r，n]区间的数值不用给它加上c啊，没关系我们接着在差分数组b[n]中给b[r+1]减去c 即：b[r+1]-c，这样a[n]数组中r+1位置包括后面位置的数都会受到影响数值会减去c，这样两者结合起来自然就只有[l，r]区间的数值被加上了c，这样原先需要在原数组中利用循环来完成的操作在这里我们只需要在差分数组中修改一个数值就可以了时间复杂度降低到了O(1)，最后还有一个问题，那就是这里我们最后得到的依然是差分数组那么该如何得到最后的原数组呢？你忘了啊，原数组就是差分数组的前缀和数组啊，所以我们只要对着差分数组求前缀和自然就能得到原数组中的每一位



### 怎么办：

#### 如何创建前缀和数组呢？

经过上面的介绍我们知道由前缀和数组来求数组子区间的求和十分方便，那么该如何求解前缀和数组呢？对于一维数组直接进行前n项求和就好；对于二维数组前缀和首先我们得了解它代表什么，这里现在有一个普通的二维数组a[i] [j]，则从数组左上角（1，1）位置到数组右下角（i，j）位置的所有元素求和就作为前缀和数组s[i] [j]的数值，我们想要直接利用循环来求解这个前缀和数组显然不可能（时间复杂度太高了），所以得找到它的递推关系，如下图所示：这里我们要求红色部分所有元素求和的结果s[i] [j]，它等于黄色部分所有元素求和的结果s[i-1] [j]，加上蓝色部分所有元素求和的结果s[i] [j-1]，发现紫色部分被算了两次所以我们还得再减去一次s[i-1] [j-1]，最后再加上原数组(i，j)位置处的数值a[i] [j]就得到红色部分所有元素求和的结果，

即：s[i] [j]=s[i-1] [j]+s[i] [j-1]-s[i-1] [j-1]+a[i] [j]

下图代表普通的二维数组a[i] [j]（从左上角(1,1)到右下角(i,j)的所有元素求和即为前缀和数组s[n] [m]中(i，j)位置处的元素值s[i] [j]，这里的n和m分别代表二维数组的行数和列数）

#### 如何创建差分数组呢？

##### （1）创建一维差分数组

我们知道给定一个普通的数组a[n]，则它对应的差分数组b[n]的前缀和就是数组a[n]中的项即a[i]=b[0]+b[1]+...+b[i]，这样的差分数组是肯定存在的，但是该如何构建呢？这里我们首先假定原数组的元素都是0则对应的差分数组是多少？也全是0，这点很容易看出来，**现在原数组第i个位置添加了元素c，则因为原数组是差分数组的前缀和数组有此概念我们得出差分数组的第i个位置得加上c并且差分数组的第i+1个位置得减去c**（差分数组第i个位置加c会影响到原数组第i个位置包括后面位置的元素都加上c，然后又给差分数组第i+1个位置减去c会影响到原数组第i+1个位置包括后面位置的元素都减去c，这样二者一综合就得到原数组第i个位置加上c）

##### （2）创建二维差分数组

这里要想创建二维差分数组首先我们得知道二维差分数组代表的意义，因为差分数组的前缀和就代表原数组，所以对于原数组中的a[i] [j]这个元素它对应的就是差分数组中从左上角(1，1)位置一直到(i，j)位置处的范围内的所有元素的和

![1681030389828](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681030389828.png)

我们知道对于差分数组中修改一个位置的元素数值会影响到原数组中该位置后面的所有元素包括该位置处的元素，对于二维差分数组也是同理，当我们修改b[i] [j]的数值后会影响到所有需要用到b[i] [j]这个元素的位置，即图中的蓝色区域（因为这个区域的元素进行前缀和计算的时候会不可避免的用到b[i] [j]这个元素），所以我们得出当修改二维差分数组某一个位置的元素的时候它会影响到所有以它作为左上角的矩形区域内的元素的前缀和计算

![1681030828764](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681030828764.png)

那么该如何求二维差分数组呢？

假设现在原数组是个全为0的二维数组，那么它对应的差分数组也全是0这点很好理解；然后现在给原数组的

（i，j）位置添上c即a[i] [j]+c反映在差分数组中是什么样的？我们给差分数组b[i] [j]+c则对应红色部分的所有元素都会加上c，所以我们还得给所有黄色部分的元素减去c，所有蓝色部分也得减去c，发现紫色部分被减了两次，所以我们还得加回来一次，即：

b[i] [j]=b[i] [j]+c;

b[i+1] [j]=b[i+1] [j]-c;

b[i] [j+1]=b[i] [j+1]-c;

b[i+1] [j+1]=b[i+1] [j+1]+c;

经过上述操作可以实现对原数组的（i，j）位置的元素加c的操作。

### （798）差分矩阵（二维差分数组）

![1680966689824](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1680966689824.png)

解题思路：

由上述我们已经可以得到二维差分数组了，现在是给定子区间的范围，然后让这个子区间内所有元素的数值加上c该如何操作呢？关键就是找到如何构建这个子区间的问题。

现在我们选定子区间的范围，（x1，y1）作为子区间的左上角、（x2，y2）作为子区间的右下角，将这个范围内的所有元素都加上c那么该如何操作？由前面我们已经知道修改差分数组（i，j）位置处的元素值会影响到以它作为左上角的所有元素的求和情况（即会影响到所有求前缀和的情况），所以这里我们在差分数组的（i，j）位置加上c会影响到所有黄色区域的数组数值都加上c，然后我们再得给蓝色区域的数值都减去c，再将紫色区域的数值都减去c，发现绿色区域被减了两次，所以我们还得再加一次回来，即：

b[x1] [y1]=b[x1] [y1]+c; //所有黄色区域内的元素加上c

b[x2+1] [y1]=b[x2+1] [y1]-c; //所有蓝色区域内的元素减去c

b[x1] [y2+1]=b[x1] [y2+1]-c; //所有紫色区域内的元素减去c

b[x2+1] [y2+1]=b[x2+1] [y2+1]+c; //所有绿色区域内的元素再加上c

这四个操作总和下来就是将所有红色区域内的元素加上了c。

另外还需要注意的是这里得到的是二维差分数组还不是原数组，如果想要得到原数组的话还需要进行差分数组的前缀和计算

![1681031473321](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681031473321.png)



```Java
import java.util.Scanner;
public class Main{
    private static final int N=1010;
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n,m,q;
        n=sc.nextInt();
        m=sc.nextInt();
        q=sc.nextInt();
        
        //输入原矩阵
        int[][] nums=new int[N][N];
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                nums[i][j]=sc.nextInt();
            }
        }
    
        //先通过将原矩阵全部置0然后依次插入元素的方式来创建它对应的差分矩阵
        int[][] b=new int[N][N];
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                insert(b,i,j,i,j,nums[i][j]);
            }
        }
        
        //对原数组的子区间内的数值进行加c操作反映在差分矩阵上的修改
        while(q>0){
            int x1,y1,x2,y2,c;
            x1=sc.nextInt();
            y1=sc.nextInt();
            x2=sc.nextInt();
            y2=sc.nextInt();
            c=sc.nextInt();
            insert(b,x1,y1,x2,y2,c);
            q--;
        }
        
        //输出经过多次修改后的新的原矩阵（即差分矩阵进行前缀和计算）
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                //这里的原数组nums[i][j]就相当于差分数组b[i][j]的前缀和数组
                nums[i][j]= nums[i][j-1]+nums[i-1][j]-nums[i-1][j-1]+b[i][j]; 
                System.out.print(nums[i][j]+" ");
            }
            System.out.println();
        }
    }
    
    //对原数组的给定子区间内的所有数值进行加c的操作反映在差分数组中是什么样
    public static void insert(int[][] arr,int x1,int y1,int x2,int y2,int c){
        arr[x1][y1]+=c;
        arr[x1][y2+1]-=c;
        arr[x2+1][y1]-=c;
        arr[x2+1][y2+1]+=c;
    }
}
```

## 6、双指针算法

### 是什么：

双指针算法是一种常见的算法，核心理念是使用两个指针，分别指向不同的元素，通过对比指向的元素来协同完成任务。 双指针算法最核心的用途就是优化时间复杂度。

双指针技巧主要分为两类：左右指针和快慢指针

其中左右指针又可根据移动方向分为左右同向指针和左右反向指针

其中

**（1）快慢指针是用移动速度一快一慢的两个指针来解决问题，主要针对链表环路问题，和原地修改数组问题**

**（2）左右同向指针指代左右两个指针移动方向相同（其中如果两个指针永远不会相交的话又可以称作为滑动窗口），可以用于解决字符串匹配问题**

**（3）左右反向指针指代左右两个指针的移动方向相反（一个从左往右移动，另一个从右往左移动），可以用来搜索有序数组（数组需要提前排好序）**



### notes：不是说用到了两个指针就是双指针算法而是两个指针同时移动降低算法的时间复杂度这才是双指针算法

==典型的例子，在暴力做法中先固定左指针然后不断移动右指针遍历整个数组，接着移动左指针到下一个位置接着进行固定然后不断移动右指针遍历整个数组，，，这样的过程不是双指针算法==



### 为什么：

双指针算法常用来降低算法的时间复杂度，因为使用两个指针可以避免多层循环。它可以大大降低时间复杂度，可用在数组，单链表等数据结构中。这样，我们就可以更快地解决问题。 

### 怎么办：

#### 一、快慢指针

#### 是什么：

快慢指针是一种常用于解决链表和数组问题的技巧。它们是两个指针，**一个速度快另一个速度慢（比如一个指针每次移动两格，另一个指针每次移动一格）**，通常用于寻找链表中的环、查找链表中的中间节点或解决一些特定的问题。

#### 为什么：

快慢指针主要适用于以下一些问题：

1. **寻找链表中的环**：快慢指针可以用来检测链表是否有环。慢指针每次移动一个节点，快指针每次移动两个节点。如果链表中有环，快指针最终会追上慢指针，从而检测到环的存在。
2. **查找链表的中间节点**：使用快慢指针可以在一次遍历中找到链表的中间节点。慢指针每次移动一个节点，快指针每次移动两个节点，当快指针到达链表的末尾时，慢指针指向的节点就是链表的中间节点。
3. **解决特定问题**：快慢指针还可以用于解决其他一些与距离或位置有关的问题。例如，在链表中查找倒数第k个节点，可以使用快指针先移动k步，然后快慢指针一起移动，直到快指针到达链表末尾，慢指针就会指向倒数第k个节点。



##### notes：如何理解这里的寻找链表中间节点的操作？

我们创建快慢指针，初始时快慢指针都指向链表头节点（==这里的头节点就是实际的头节点，并不是创建的虚拟头节点，即使是虚拟的头节点也没有关系==），

（1）从感性上认识：快指针每次移动两步，慢指针每次移动一步，那么当最后快指针到达链表末尾的时候此时慢指针指向的一定是链表的中间节点。

（2）从理性上认识：什么叫做链表的末尾呢？是链表的尾节点吗，还是尾节点的next指针指向的null节点呢？以及说了快指针每次移动两步那么当最后结束的时候快指针移动的路程一定是偶数步不会是奇数步，如果链表中有偶数个节点的话那么从头节点到尾节点的路程可就只有奇数步了，这又该如何处理呢？接下来就由图示好好分析：

### （力扣876）链表的中间节点

![1707315287161](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1707315287161.png)

解题思路：

上述图示中我们已经分析过了，当采用快慢指针的时候如果链表中存在奇数个节点则当快指针到达链表末尾时慢指针刚好到达中间的节点，如果链表中存在偶数个节点则当快指针到达链表末尾时慢指针到达中间两个节点中的后一个

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow=head,fast=head;
        while(fast!=null && fast.next!=null){
            /*
            这里的循环条件为什么是while(fast!=null && fast.next!=null)?
            不能单单是while(fast!=null)或者是while(fast.next!=null)吗？
            不能，因为
            （1）如果单单是while(fast!=null)的话此时确实可以保证fast指针指向的节点
            不是null节点（即当进入循环时fast!=null），但是不能保证fast.next!=null，
            后面在循环中会调用fast.next.next，这里就会出现空指针异常；
            （2）如果单单是while(fast.next!=null)的话此时确实可以保证fast指针指向的节点
            不是链表的尾节点（即当进入循环时fast.next!=null），但是假如本轮循环fast指针指向
            链表的尾节点的前一个节点，在本轮循环中会进行fast=fast.next.next操作，此时
            fast指针指向的就是null节点了，接着进行下一轮循环，在循环前会先判断
            while(fast.next!=null)但是此时fast指针已经指向了null节点所以这里又会发生
            空指针异常
            所以我们将循环条件定义为：while(fast!=null && fast.next!=null)
            它对应的意思是fast指针指向的节点不是尾节点后面的null节点也不是尾节点，而fast指针
            指向尾节点或者是尾节点后面的null节点刚好对应快指针到达链表末尾的两种状态（这两种
            状态究竟是哪一种取决于链表中的节点数目到底是奇数还是偶数）
            */
            slow=slow.next;
            fast=fast.next.next;
        }
        return slow;
    }
}
```





### （力扣2095）删除链表的中间节点

![1707315059098](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1707315059098.png)

解题思路：

这题就是典型的快慢指针的题，要我们删除的节点就是最后slow指针指向的节点。

==注意这里的pre指针的作用==

```java 
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode deleteMiddle(ListNode head) {
        if(head.next==null){
            //如果链表中只有一个节点的话则要删除链表中的这个节点，所以最后返回null就好
            return null;
        }
        ListNode slow=head,fast=head,pre=head;//这里为什么要弄一个pre指针呢？
        while(fast!=null && fast.next!=null){
            pre=slow;
            slow=slow.next;
            fast=fast.next.next;
        }
        /*
        观察上述while循环发现这里的pre指针的作用了吗？
        每次进行while循环时都会先对pre指针进行赋值：pre=slow，接着slow指针会进行移动，
        fast指针也会进行移动，直到最后fast指针到达链表末尾，此时的slow指针指向的是链表
        的中间节点（如果中间节点只有一个的话则指向该中间节点，如果中间节点有两个的话则指向
        两个中的后一个），那么此时pre指针指向什么呢？
        指向的是链表中间节点的前一个节点啊！
        */
        
        pre.next=pre.next.next;
        return head;
    }
}
```

```Java

 * Definition for singly-linked list.

 *     }

 */

    public boolean hasCycle(ListNode head) {

        ListNode slow=head;
        ListNode fast=head;

            }
        }
```

#### 是什么：

左右同向指针通常是指两个指针在数组或字符串中向同一方向（例如，从左到右）移动，通常用于解决一些问题，如查找和问题、子数组问题等。左右同向指针可以指向同一方向的不同位置，以帮助解决问题。

### （799）最长连续不重复子序列

![1681200398028](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681200398028.png)

解题思路：

### notes：子数组和子序列的区别

子数组（Subarray）和子序列（Subsequence）是两个在数组/序列上定义的概念，它们之间有一些关键的区别：

1. **子数组（Subarray）**:
   - 子数组是数组中连续的一部分。
   - 例如，对于数组 [1, 2, 3, 4]，[2, 3] 是一个子数组，而 [1, 3] 则不是，因为它们不是连续的。
   - 子数组的元素在原数组中的位置是连续的。
2. **子序列（Subsequence）**:
   - 子序列是从数组中选取元素（保持原有顺序）形成的序列，元素之间不必连续。
   - 例如，对于相同的数组 [1, 2, 3, 4]，[1, 3] 是一个子序列，因为即使它们在原数组中不是连续的，我们也保持了元素的原始顺序。
   - 子序列的元素在原数组中的位置可以不连续。

简单来说，子数组的元素必须在原数组中连续，而子序列的元素在原数组中则可以是不连续的，只要保持原有的顺序即可。



==暴力做法：==

初始时设定左右指针都指向数组首元素下标1，然后固定左指针i，然后移动右指针j，判断数组[i~ j]范围内是否有重复的元素，

（1）如果有重复元素的话则重新固定左指针为i+1然后重复上述过程，

（2）如果没有重复元素的话则左指针不变移动右指针接着判断数组[i~ (j+1)]范围内是否有重复元素，

该做法的时间复杂度为O(n^2)

```java
import java.util.Scanner;
public class Main{
    public static final int N=100010;
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        
        //手动输入n个数的数组
        int[] nums=new int[N];
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        
        
        int maxlen=0;//用于记录最长连续不重复子序列的长度
        for(int i=1;i<=n;i++){
            HashMap<Integer,Integer> map=new HashMap<>();
        	//用于记录在数组nums[n]中某个元素nums[i]出现了几次的哈希表
            for(int j=i;j<=n;j++){
                if(map.containsKey(nums[j])){
                    break;
                }
                map.put(nums[j],1);
                maxlen=Math.max(maxlen,(j-i+1));
            }
        }
        System.out.println(maxlen);
    }
}
```



==双指针做法：==

仔细观察上述暴力做法的过程，看看有没有什么可以改进的地方？

我们发现当采用左右两个指针i，j的时候，如果数组[i~ j]范围内的元素没有重复的话则继续移动右指针j，这都没有问题，当右指针向右移动一位来到j+1的位置后此时产生了元素重复即数组[i~ (j+1)]范围内产生了重复，这时候的暴力做法的思路是什么呢？

因为数组[i~ j]范围内没有产生重复，但是数组[i~ (j+1)]范围内产生了重复，所以更新左指针的位置为i+1，然后右指针再次从j=i+1的位置开始移动。这种思路是对的，但是太麻烦了，而且因为前面提到数组[i~ j]范围内没有产生重复，但是数组[i~(j+1)]范围内产生了重复，所以造成重复的一定是nums[j+1]这个元素，而上述暴力做法并没有利用到这个性质，我们来想办法看看如何利用这个性质：

采用左右同向指针（滑动窗口）的思路，**我们首先将左右指针i,j都置于数组首元素下标0处，保持左指针i不动，然后让右指针j先走，同时记录它当前遍历的元素出现的次数，如果当遍历到一个元素nums[j]时发现它重复了，那么肯定是nums[j]和子数组nums[i~j]中前面的某个元素nums[k]重复了，这时候我们要做的就是不断移动左指针i直到将那个造成重复的元素nums[k]从当前子序列中排除出去，接着继续保持左指针不动移动右指针**；重复上述步骤直到右指针到达数组末尾。       

上述过程中我们会去记录子数组nums[i~ j]范围内每个元素出现的次数，可以利用现成的哈希表结构也可以另外自己用一个数组记录，因为给定数组nums[n]中每个元素nums[i]的范围都在0~10^ 5范围内，所以我们可以另外用一个10^5+5大小的数组s[n]来记录这些元素出现了多少次，其中数组s[n]中的下标 i 就是数组nums[n]中的一个元素值nums[j] （即这里i=nums[j]），数组s[n]的元素值s[nums[i]]就代表了 nums[i] 这个元素在数组nums[n]中出现了多少次（这个功能完全可以用HashMap结构来代替，用HashMap的话最后当排除集合中的元素的时候可以用remove(key)方法删除集合中指定key值对应的键值对）   

算法图示如下：                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       

首先一图中右指针遍历过的元素没有重复的，接着到二图中当遍历到后一个元素的时候发生了重复，造成重复的就是当前右指针指向的元素，这就意味着当前的子序列中前面肯定有一个元素值和当前元素相同，我们要做的就是像三图中那样不断移动左指针将子序列中那个重复的元素排除出去，接着继续移动右指针向后延伸重复上述过程（别忘了在上述过程中要不断更新不重复的子序列的长度，找到最大值）

![1681546286372](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681546286372.png)

==该算法的时间复杂度为：O(n)，因为两个指针只会从头到尾遍历一次==

```Java
//前面已经试过了暴力做法（就是用两层for循环），现在来想想双指针优化算法
import java.util.Scanner;
public class Main{
    public static final int N=100010;
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        
        //手动输入n个数的数组
        int[] nums=new int[N];
        for(int i=1;i<=n;i++){
            nums[i]=sc.nextInt();
        }
        
        int[] s=new int[N];
        /*
        用来记录当前遍历的子数组中每个元素出现的次数，那么是如何记录的呢？
        这里我们以nums[n]数组中的元素值nums[i]作为s[n]数组中的下标值，如果在遍历的子数组
        中nums[i]这个元素出现了两次，则它在s[n]数组中对应的值s[nums[i]]就等于2
        即s[nums[i]]=2（其实这里可以用HashMap结构来实现此功能而且更加方便，那时候
        就是数组nums[n]中的数值对应HashMap中的key,该元素出现的次数对应的就是value。
        不过和这里的s[n]数组的功能都是一样的反正都是记录子数组中每个元素出现的次数）
        */
        
        //用双指针的算法来优化求解过程
        int maxLen=0;//记录不重复的子数组的最大长度
        for(int i=1,j=1;j<=n;j++){//注意这里的i指针是左指针，j指针是右指针
            s[nums[j]]++;
            while(i<j && s[nums[j]]>1){
                s[nums[i]]--;
                i++;
            }
            maxLen=Math.max(maxLen,(j-i+1));
        }
        System.out.println(maxLen);
        return;
    }
}
```

### （力扣19）删除链表的倒数第N个节点

![1708052477582](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1708052477582.png)

解题思路：

本题就是利用左右同向指针的典型题目，首先我们将左右指针指向链表的头节点，然后让右指针先跑n步接着左右指针一起移动这样当最后右指针为空时此时的左指针指向的就是链表中倒数第n个节点，因为要删除链表中倒数第n个节点所以我们还得另外弄一个指针pre指向链表中倒数第n个节点前面的一个节点，然后执行pre.next=pre.next.next操作以此将链表中倒数第n个节点删除。

==不过需要注意的是这里当n等于链表长度的时候会删除链表的头节点，而删除链表头节点的操作和上述删除中间节点的操作有些不同所以我们需要特判一下看看n是否等于链表长度，如果不想要特判的话则我们给链表加上一个虚拟头节点dummyhead，并且dummyhead.next=head，==由此链表的头节点就变成了一个链表中一个普通的中间节点，要删除头节点的话就可以当成一个普通的中间节点来删。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    //注意当n等于链表长度的时候这里会删除链表的头节点
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummyhead=new ListNode();
        dummyhead.next=head;
        //设置虚拟头节点指向链表的头节点，这样可以解决当要删除链表头节点的情况

        ListNode l=head;
        ListNode r=head;
        ListNode pre=dummyhead;
        while(n!=0){
            n--;
            r=r.next;
        }
        while(r!=null){
            pre=l;
            r=r.next;
            l=l.next;
        }
        pre.next=pre.next.next;
        return dummyhead.next;
    }
}
```

涉及到原地修改数组自然想到双指针算法，然后通过不断交换左右指针的元素完成原地修改数组的任务。具体实现的过程中涉及如下几个问题：

- （1）如何删除有序数组中的重复项，使得重复多次的元素只保留一次？

  ​	既然是有序数组，那么重复项一定是连在一起的，我们从左到右维护不含重复项的子数组，一开始这个子数组大小为1（就是数组的首元素），后续不断扩大这个子数组，关键在于如何扩大这个子数组？

- （2）如何扩大子数组？

  ​	我们令左右指针l和r，其中l指针指向维护好的子数组后面一个元素（==也就是说此时的l指针位于维护好的子数组外面==，后续要进行元素位置交换的时候直接在l的位置进行交换），r指针用于从左往右遍历数组元素，初始时l=r=1（==这里的1是数组下标1，标志着数组中的第二个元素==），然后不断移动r指针，

  - 如果nums[l-1]==nums[r]，那么就说明在数组nums中[(l-1)~r]这一段都是重复的，而且我们已经将nums[l-1]这个元素加入到了维护好的子数组中所以就不用再把nums[r]这个元素继续加到维护好的子数组当中了，所以继续移动r指针去寻找新的元素
  - 如果nums[l-1]!=nums[r]，那么就说明nums[r]是一个新出现的元素，所以我们就将它数组中l和r下标的元素交换位置以此将原本的元素nums[r]（现在在下标l位置上）加入到维护好的子数组中，接着将左指针l向右移动一位将右指针r向右移动一位，然后重复上述过程

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int l=1;
        for(int r=1;r<nums.length;r++){
            if(nums[l-1]!=nums[r]){
                int tmp=nums[l];
                nums[l]=nums[r];
                nums[r]=tmp;
                l++;
            }
        }
        return l;
    }
}
```

### （力扣80）删除有序数组中的重复项2（重复多次的元素最多保留两次）

![1709177783361](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1709177783361.png)

解题思路：

本题就是在上面一题的基础上进行的扩展，上面一题是说重复多次的元素只保留一次而本题是说重复多次的元素最多保留两次，这里可以继续扩展一下重复多次的元素最多保留k次。具体实现的过程中涉及如下几个问题：

- （1）如何删除有序数组中的重复项，使得重复多次的元素最多保留k次？

  ​	既然是有序数组，那么重复项一定是连在一起的，我们从左到右维护不含重复项的子数组，一开始这个子数组大小为k（就是数组首部的k个元素，不管这k个元素是否重复都可以加入到这个子数组中），后续不断扩大这个子数组，关键在于如何扩大这个子数组？

- （2）如何扩大子数组？

  ​	我们令左右指针l和r，其中l指针指向维护好的子数组后面一个元素（==也就是说此时的l指针位于维护好的子数组外面==，后续要进行元素位置交换的时候直接在l的位置进行交换），r指针用于从左往右遍历数组元素，初始时l=r=k（==这里的下标k表示是数组中的第k+1个数==），然后不断移动r指针，

    - 如果nums[l-k]==nums[r]，那么就说明在数组nums中[(l-k) ~ r]这一段都是重复的，而且 (l-k) ~ r 这一段的长度至少为k，同时我们也将nums[l-k]、nums[l-k+1]、nums[l-k+2]、、、nums[l-1]这样的k个元素已经加入到了维护好的子数组当中了，所以就不用再将nums[r]这个元素再加入到维护好的子数组当中去，所以继续移动r指针去寻找新的元素
    - 如果nums[l-k]!=nums[r]，那么就说明nums[r]是一个新出现的元素或者nums[r]这个元素并没有重复k次，所以我们就将它加入到维护好的子数组中，接着将左指针l向右移动一位再将右指针r向右移动一位，然后重复上述过程

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if(nums.length<=2){
            return nums.length;
        }
        int l=2;
        for(int r=2;r<nums.length;r++){
            if(nums[l-2]!=nums[r]){
```

### （力扣83）删除排序链表中的重复元素（重复多次的元素只保留一次）

![1709278586981](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1709278586981.png)

解题思路：

本题与上面的力扣26题 ”删除有序数组中的重复项使得重复多次的元素只保留一次“ 特别像，可以把这两题放在一起进行比较，这两题有很多相似之处不过也有一些区别那就是：

 - 在数组中我们令左指针l指向维护好的子数组后面一个位置处（==此时的左指针l位于子数组外面==），后续通过移动右指针去遍历数组元素，
   	- 如果nums[l-1]==nums[r]，说明在数组nums中[(l-1) ~ r]这一段是重复的，并且我们已经将nums[l-1]加入到了维护好的子数组当中了，所以就不用再将nums[r]这个元素加入到维护好的子数组当中去
   - 如果nums[l-1]!=nums[r]，说明此时的nums[r]这个元素是一个新出现的元素，不管nums[r]这个元素后面会不会重复（即是否会存在nums[r] == nums[r+1] == nums[r+2] ==...的情况存在），我们都要将这个新出现的元素加入到维护好的子数组当中去
 - 在链表中我们令左指针l指向维护好的子链表中的最后一个位置处（==此时的左指针位于子链表里面==），后续通过右指针去遍历链表元素，

  - 如果l.val==r.val，说明r.val这个值已经被加入到了子链表当中去了，所以我们继续移动右指针去遍历新的链表元素
  - 如果l.val!=r.val，说明r.val这个值是新出现的元素还没有被加入到子链表当中去，所以我们就将该元素加入到子链表当中

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if(head==null || head.next==null){
            return head;
        }
        ListNode l=head;
        for(ListNode r=head.next;r!=null;r=r.next){
            if(l.val!=r.val){
                l.next=r;
                l=l.next;
            }
        }
        l.next=null;
        /*
        别忘了这一步！
        上述过程中我们会将每个元素加入子链表中一次，左指针l始终指向子链表中最后一个元素，
        假如遇到原始链表中最后的几个元素都是重复的话，我们会将这些重复元素中的第一个加入
        到子链表当中即此时l指向该元素，但此时l指针的next指针依然是指向后面的那些重复元素的，
        所以我们得进行l.next=null操作
        */
        
        return head;
    }
}
```

```java
        int n=nums.length;
        int l=0,r=n-1;
        for(int k=l;k<=r;){
            if(nums[k]==0){
                int tmp=nums[l];
                nums[l]=nums[k];
                nums[k]=tmp;
                l++;
                k++;
                /*
                为什么在nums[k]==0这个分支中，当交换数组nums中l和k下标处的元素以后，要进行
                k++的操作？

            }else if(nums[k]==2){

                与此同时数组下标r处的元素也被交换过来了，我们还没有遍历这个被交换过来的元素就
                进行k++操作的话则会有问题
                */
            }else{
                k++;
            }
        }
```

#### 三、左右反向指针

#### 是什么：

左右反向指针是指在解决问题时，两个指针分别从数组或字符串的两端开始，然后朝着相反的方向移动，通常用于查找或比较两侧的元素或区间。

#### 为什么：

左右反向指针主要适用于以下问题：

1. **回文字符串判断**：在字符串中判断是否是回文字符串时，左指针从字符串的开头向右移动，右指针从字符串的末尾向左移动，然后比较它们指向的字符是否相等。
2. **查找特定元素**：在有序数组中查找特定元素时，左指针从数组的开头向右移动，右指针从数组的末尾向左移动，根据元素值与目标值的大小关系来决定哪个指针移动，以逼近目标值。
3. **求两数之和问题**：在有序数组中查找两个元素的和等于目标值的情况时，左指针从数组的开头向右移动，右指针从数组的末尾向左移动，根据和与目标值的大小关系来决定哪个指针移动，以逼近目标值。

#### 怎么办：

### （800）数组元素的目标和

![1681200495958](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681200495958.png)

解题思路：

这题暗示的已经很明显了，两个都是升序数组，所以我们想到左右反向指针，首先左指针指向A数组中的最小值，右指针指向B数组中的最大值，然后计算它们二者的和，如果和比目标值大则我们往前移动右指针缩小和值，如果和比目标值小则我们往后移动左指针增大和值，这样就将原本需要两次循环的操作改成了只要遍历一次两个数组就行了

```Java
        Scanner sc=new Scanner(System.in);
        int n,m,x;
        n=sc.nextInt();
        m=sc.nextInt();
        x=sc.nextInt();
        int[] A=new int[n];
        for(int i=0;i<n;i++){
            A[i]=sc.nextInt();
        }
        int[] B=new int[m];
        for(int i=0;i<m;i++){
```

### （力扣11）盛最多水的容器

![1708000987139](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1708000987139.png)

解题思路：

==暴力做法：==

用两层for循环，其中外层for循环用于遍历容器的左边界，内层for循环用于遍历容器的右边界，时间复杂度O(n^2)

```java
class Solution {
    public int maxArea(int[] height) {
        int max=0;
        for(int i=0;i<height.length;i++){
            for(int j=i+1;j<height.length;j++){
                int h=Math.min(height[i],height[j]);
                max=Math.max(max,h*(j-i));
            }
        }
        return max;
    }
}
```



==双指针做法：==

仔细观察上述暴力做法看看是否有可以改进的地方，在上述暴力算法中当考虑容器的左边界的时候我们会考虑每一块板，当考虑容器的右边界的时候我们也会考虑每一块板，但其实这大可不必，因为目的是使得容器的面积最大，而怎么做可以使得容器的面积最大呢？

那就是整个容器尽可能又宽又高这样的面积才是最大的，所以我们一开始固定容器的左右边界就是数组的两边，这样的容器是最宽的但是不一定是面积最大的（因为此时的高度不一定是最大的），所以我们该如何找面积最大的容器呢？依然是遍历所有可能的情况吗（用两层for循环，其中外层for循环用于遍历左边界的所有可能情况，内层for循环用于遍历右边界的所有可能情况），这种遍历所有可能情况的做法也太麻烦了，时间复杂度依然为O(n^2)丝毫没有改善。那么我们这时候该如何移动指针呢，此时到底应该是移动左边界还是右边界呢？

这就要看限制此时容器面积的是什么因素了：此时的宽度一定是最大的，那么限制容器面积的只可能是容器高度了，具体点就是左右边界高度二者中的最小值，具体分析见下图：

![1708001078977](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1708001078977.png)

```java
class Solution {
    public int maxArea(int[] height) {
        int l=0,r=height.length-1;
        int max=0;
        while(l<r){
            int h1=height[l],h2=height[r];
            if(h1<=h2){
                max=Math.max(max,h1*(r-l));
                l++;
            }else{
                max=Math.max(max,h2*(r-l));
                r--;
            }
        }
        return max;
    }
}
```

### （力扣15）三数之和

![1708003478876](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1708003478876.png)

解题思路：

==暴力做法：==

首先我们将数组进行排序，然后利用三层for循环，其中最外层for循环用于遍历下标i，中间层for循环用于遍历下标j，最内层for循环用于遍历下标k，然后看看nums[i]+nums[j]+nums[k]是否等于0，同时还要注意[nums[i],nums[j],nums[k]]这个三元组不能重复，该算法的时间复杂度为O(n^3)，那既然是用三层for循环遍历所有可能情况的话为什么之前还要对数组进行排序呢？排序的目的是为了保证三元组不能重复的时候方便进行排除，比如nums[i]+nums[j]+nums[k]=0，接着遍历k=k+1的情况，如果此时nums[k+1]=nums[k]则我们直接跳过后续对于k的遍历



==双指针做法：==

观察上述暴力做法看看是否有可以改进的地方，我们发现当对数组进行排序以后再进行三重for循环就显得冗余，想想办法怎么可以改进，我们知道对于有序数组求和问题可以利用双指针同时遍历来降低时间复杂度，这里也是如此，我们可以利用一层for循环用来遍历k的情况，然后for循环内部用左右反向指针来遍历数组的所有元素，当然这里得排除重复元素的情况，该算法的时间复杂度为：先固定k然后左右指针遍历数组的所有元素，左右指针遍历数组的时间复杂度为O(n)；对于每一个k的时间复杂度都是O(n)，遍历k的所有可能情况，这里k的取值为O(n)级别，所以该算法的时间复杂度为O(n^2)

![1708050533149](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1708050533149.png)

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> ans=new ArrayList<>();
        Arrays.sort(nums);
        int len=nums.length;
        for(int k=0;k<len;k++){
            if(nums[k]>0){
                return ans;
            }
            if(k>=1 && nums[k]==nums[k-1]){
                continue;
            }
            int i=k+1,j=len-1;
            while(i<j){
                int sum=nums[k]+nums[i]+nums[j];
                if(sum==0){
                    List<Integer> list=new ArrayList<>();
                    list.add(nums[k]);
                    list.add(nums[i]);
                    list.add(nums[j]);
                    ans.add(list);
                    i++;
                    j--;
                    while(i<len && nums[i]==nums[i-1]){
                        i++;
                    }
                    while(j>=0 && nums[j]==nums[j+1]){
                        j--;
                    }
                }else if(sum<0){
                    i++;
                }else{
                    j--;
                }
            }
        }
        return ans;
    }
}
```

```java
class Solution {
    //双指针算法
    public int trap(int[] height) {
        int leftMax=0;//用于记录数组中左指针左边的最大值(包括nums[left])
        int rightMax=0;//用于记录数组中右指针右边的最大值(包括nums[right])
        int left=0,right=height.length-1;
        int sum=0;//用于记录接雨水的总数
        while(left<right){
            leftMax=Math.max(leftMax,height[left]);
            rightMax=Math.max(rightMax,height[right]);
            if(height[left]<height[right]){
                sum+=leftMax-height[left];
                left++;
            }else{
                sum+=rightMax-height[right];
                right--;
            }
        }
        return sum;
    }
}
```

## 7、位运算

### 是什么：

所有的数字在计算机内存中都是以二进制的形式储存的，位运算就是直接对整数在内存中的二进制位进行运算；

主要有以下几种：这里的a、b都是int型数据

（1）按位与（&）：a&b

（2）按位或（|）：a|b

（3）按位异或（ ^ ）：a^b



### 怎么办：

这里介绍一下lowbit(int x)方法，它的作用是找到并返回整数x的二进制表示中的最后一个1连同它后面的0一起返回，举个例子数字10的二进制表示为(1010)~2~，调用该方法后返回的即是(10)~2~（返回的是右边的那个1连同它后面的0，注意这里返回的是二进制的一零，而不是十进制下的十）。那么该方法是如何做到的呢？该方法的方法体就是：x & -x，二者进行相与操作最后得到的就是蓝色的部分，即最后一个1连同它后面的0都被返回了

### （801）二进制中1的个数

![1681200640268](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681200640268.png)

解题思路：

由上述介绍的lowbit(int x)方法我们可以得到一个整数x它的二进制表示中的最后的一个1连同他后面的0，所以每次我们调用一次lowbit(x)方法，然后让x减去这个值就相当于将x中最后的一个1给减去了，然后看看减多少次它会变成0就意味着它的二进制表示中有多少个1

举例：

15的二进制表示为(1111)~2~，lowbit(15)=(1)~2~（二进制），15-lowbit(15)=(1110)~2~=(14)~10~；

14的二进制表示为(1110)~2~，lowbit(14)=(10)~2~（二进制），14-lowbit(14)=(1100)~2~=(12)~10~；

12的二进制表示为(1100)~2~，lowbit(12)=(100)~2~（二进制），12-lowbit(12)=(1000)~2~=(8)~10~;

8的二进制表示为(1000)~2~，lowbit(8)=(1000)~2~（二进制），8-lowbit(8)=(0000)~2~=(0)~10~.

```Java
import java.util.Scanner;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        int[] nums=new int[n];
        for(int i=0;i<n;i++){
            nums[i]=sc.nextInt();
        }
        for(int i=0;i<n;i++){
            int count=0;
            while(nums[i]!=0){
                nums[i]=nums[i]-lowbit(nums[i]);
                count++;
            }
            System.out.print(count+" ");
        }
    }
    
    //lowbit()方法可以返回二进制数字中的最后一个1包括后面的数位0
    public static int lowbit(int x){
        return x & -x;
    }
}
```

## 8、离散化

### 是什么：

离散化，把无限空间中有限的个体映射到有限的空间中去，以此提高算法的时空效率。

通俗的说，离散化是在不改变数据相对大小的条件下，对数据进行相应的缩小。例如：

原数据：1,999,100000,15；处理后：1,3,4,2；

原数据：{100,200}，{20,50000}，{1,400}；

处理后：{3,4}，{2,6}，{1,5}；

这些处理都不改变数据之间的相对大小



### 为什么：

就拿下面的这个区间和的例子来说，我们规定的数轴的长度是（-10^9^，10^9^），然后本来这么长的数轴上是没有一个数的，现在在其中挑选10^5^个位置然后在这些位置上插入数据（==注意在挑选这10^5^个位置的时候也可能会两次选到同一个位置，注意只有这些插入位置上才有数据没有进行插入的位置是没有数据的==），然后给定你区间让你求这个区间内的数据的和。我们肯定想到前缀和，但是如果直接建立前缀和数组的话，那么该数组的下标范围就是（-10^9^，10^9^），真的需要这么大的数组吗？其实没必要，因为10^9^个位置，其中只有10^5^个位置上有数别的位置都为0，也就是说平均10^4^个位置上才有一个数，那么我们建立那么多的数组上面的位置都被浪费了啊，这里其实我们只要知道当给定一个子区间的时候我们只要知道这个子区间内有多少个位置上有数以及这些数都是多少就好了，没必要将原数组每个位置都了解清楚；所以综上我们只需要知道那10^5^个有数的位置它们之间的相对位置，以及后续需要查询的10^5^个子区间对应的左右下标和上述的10^5^个有数的位置它们之间的相对位置就好了。举例来说：

现在有一个数组如下图所示，它只有10号下标、80号下标、100号下标有数，别的位置都是0，然后现在给了你一个子区间的下标8，90，问你这个子区间内的区间元素和是多少，如果建立前缀和数组的话非得建立和原数组一样大内存空间的前缀和数组吗？当然不是，这里我们只需要知道这三个有数的位置下标(10，80，100)以及后面要查询的子区间的两个下标(8，90)总共五个下标的相对关系就行了，可以将它们转换成下图所示的相对位置关系，然后本来让求在原数组中位置下标8到位置下标90这个区间内的元素和，就相当于求后续数组中位置下标1到位置下标4这个区间内的元素和了，后续数组的空间大小那可就小多了啊

==正确解法：==

（1）首先用Pair记录一对对插入的数据x-c（这里的Pair是我们自定义的类型，目的就是为了记录在绝对位置x处插入了数值c），为什么要记录x-c数据对呢？因为这里的x代表绝对位置后续我们利用离散化将它们转化为相对位置坐标，但是每一个位置上要插入的数值还是需要一一对应的。

（2）接着将所有的绝对位置坐标x，l，r都放入集合中并进行排序和去重操作（==此时数值x，l，r在集合中的位置下标就代表着它在所有绝对位置坐标中的相对位置==）

（3）创建一个新的数组a[]（记录的是各个相对位置坐标上的数值），根据数值对x-c中的x找到它在集合中的下标index（此时它的下标就代表了它的相对位置，上面已经提到过了），将数组a[]中index位置处的元素值加上c（即设定a[index]+=c）

（4）创建一个新的数组s[]，用来记录数组a[]的前缀和数组

（5）根据询问时的绝对位置坐标l-r找到它们在集合中的相对位置index1-index2，然后进行s[index2]-s[index1-1]操作即可

```java
这题就用之前学过的前缀和来做，但是有一个问题，那就是这里的区间范围太大了为（-10^9,10^9），但是总共只有10^5个位置上有数，别的那么多位置上都是空的平均每10^4个位置上才有一个数，所以如果我们创建前缀和数组的话也是很浪费数组空间的，其实这里我们并不需要那么多的位置啊，好好想想我们是不是只需要知道各个数值之间的相对位置就好了，没必要知道他们的绝对位置，我们只要知道哪个数在哪个数左边还是右边以及最后的要查询的子区间的两个端点和这些下标的相对位置所以综上我们只要创建3*10^5个位置的数组就可以了，以防不够创建3*10^5+10个位置的数组（总共有10万个位置上面有数，然后又要询问10万个子区间，所以还得加上这10万个子区间的两个边界，所以总共是3*10^5个位置）

import java.util.List;
import java.util.ArrayList;
import java.util.Collections;
public class Main{
    public static final int N=300010;
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n,m;
        n=sc.nextInt();
        m=sc.nextInt();
        
        //用来存放x-c数据对的集合（针对给x下标插入数据c的过程）
        List<Pair> add=new ArrayList<>();
        //用来存放子区间l-r数据对的集合（针对查询下标l-r范围内的所有数据和的过程）
        List<Pair> query=new ArrayList<>();
        //用来存放所有用到的下标的集合（包括x,l,r）
        List<Integer> all=new ArrayList<>();
        
        for(int i=0;i<n;i++){
            int x,c;
            x=sc.nextInt();
            c=sc.nextInt();
            add.add(new Pair(x,c));
            all.add(x);//all集合将所有用到的x下标加入到集合中
        }
        for(int i=0;i<m;i++){
            int l,r;
            l=sc.nextInt();
            r=sc.nextInt();
            query.add(new Pair(l,r));
            all.add(l);//all集合将所有用到的l下标和r下标加入到集合中
            all.add(r);
        }
        
        //对all集合进行排序
        Collections.sort(all);
        //对all集合进行去重
        int end=unique(all);//这里的unique()是我们自定义的方法，该方法定义在下面
        //将去重后的all集合中位置[0,end)上的子集合重新取出来赋给集合all（end位置的元素取不到）
        all=all.subList(0,end);
        
        
        int[] a=new int[N];//用来存放元素相对位置上的数值的数组，这里的下标就已经改成了相对位置
        for(int i=0;i<add.size();i++){
            int x=add.get(i).first;//首先找到第i次插入时的位置下标x
            int index=find(x, all);//在all集合中找到插入的x-c中下标x对应的相对位置
            a[index]+=add.get(i).second;//这里对于同一个位置x可能会进行多次加c操作
        }
        
        int[] s=new int[N];//给相对位置创建前缀和数组
        for(int i=1;i<=all.size();i++){
            s[i]=s[i-1]+a[i];
        }
        
        for(int i=0;i<query.size();i++){
            int l=query.get(i).first;//第i次询问时的左边界数值是多少
            int r=query.get(i).second;//第i次询问时的右边界数值是多少
            int index1=find(l,all);//第i次询问时的左边界数值对应的相对位置是多少
            int index2=find(r,all);//第i次询问时的右边界数值对应的相对位置是多少
            System.out.println(s[index2]-s[index1-1]);
        }
    }
    
    /*
    定义集合去重的方法，该方法将排序后的集合中所有不重复的元素都放到集合前面的位置，
    然后返回集合中最后一个不重复的元素的后一个位置（在有序集合中利用双指针算法，一次
    遍历达到目的）
    */
    public static int unique(List<Integer> list){
        int k=0;
        for(int i=0;i<list.size();i++){
            if(i==0 || list.get(i)!=list.get(i-1)){
                //当排序后的集合中元素是第一个位置或者与前面位置的元素不同说明它是第一次出现，
                //就将它放入集合中前面的位置
                list.set(k++, list.get(i));
            }
        }
        return k;//返回的是集合中最后一个不重复的元素的后一个位置
    }
    
    
    /*
    在有序集合中利用二分法查找值key在集合all中出现时对应的位置，注意这里的
    位置不是下标，而是相对位置是第几个（从1开始而不是从0开始）
    */
    public static int find(int key,List<Integer> all){
        int l=0,r=all.size()-1;
        while(l<r){
            int mid=(l+r+1)/2;
            if(all.get(mid)<=key){
                l=mid;
            }else{
                r=mid-1;
            }
        }
        return l+1;//这里要返回的并不是下标而是相对位置第几个（从1开始的，所以要给下标加上1）
    }  
}

/*
因为后续要输入一对一对的数据，比如x-c和l-r，所以我们得定义这个结构（这里还不能
用HashMap，因为假如以l作为key的话后续可能会遇到查询两个子区间的时候，两个子区间
的左边界都是l，那么这时候就没法再用HashMap了），所以必须得定义这样的结构
*/
class Pair{
    public int first;
    public int second;
    
    public Pair(int first, int second){
        this.first=first;
        this.second=second;
    }
}
```

## 9、区间合并

### 是什么：

区间合并是指将一组区间如果它们产生了交集就将它们进行合并。通常情况下，区间合并问题的输入是一个由多个区间组成的集合，问题的输出是将这些区间进行合并后得到的新区间集合。

例如，假设输入为 [(1, 3), (2, 6), (8, 10), (15, 18)]，这里每个元素是一个区间，用 (a, b) 表示左端点为 a，右端点为 b。按照区间合并的规则，可以将区间 (1, 3) 和 (2, 6) 合并为 (1, 6)，(8, 10) 无法与前面的区间进行合并，因此我们将它单独作为一个区间，最后将 (15, 18) 也单独作为一个区间。因此，最终的输出是 [(1, 6), (8, 10), (15, 18)]，它们都是不重叠的区间。

### 怎么办：

### （803）区间合并

![1681200796894](%E7%AC%AC%E4%B8%80%E7%AB%A0%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95.assets/1681200796894.png)

解题思路：

这里的思路就是==利用贪心的思想==将一个个子区间放入集合中，然后再根据子区间的左边界将集合排序，依次查看上一个子区间是否会和当前的子区间产生交集，如果不产生交集就看当前遍历的子区间是否会和它的下一个元素子区间产生交集；如果产生交集那么就看产生交集以后的区间右边界到底是多少

这里需要同时输入多对区间的左右边界，而且这里的区间的左右下标是成对出现不能分散的，所以我们得定义一个类Pair来专门存储这里的一对下标，然后将该Pair类的对象存入集合中，最后再根据集合中的元素即Pair的左下标排序，所以我们在定义类Pair的时候就得实现comparable接口在里面重写compareTo()方法实现按照区间的左下标排序的功能

==这个方法只是完成总共有多少个区间然后进行计数的问题并没有完成区间的合并：==

```Java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        /*
        这里必须得一次性将n行l-r一起输入进来，然后进行相交的判断，不能一次输入一行l-r这样
        没法判断，又因为l-r是成对出现的，所以必须得定义一个数据结构同时包含这两个数据（这里
        不能使用HashMap结构，因为有可能两个l-r对中的l是相同的，这时候如果以l作为key值就会矛盾）
        */
        List<Pair> list=new ArrayList<>();
        for(int i=0;i<n;i++){
            int l,r;
            l=sc.nextInt();
            r=sc.nextInt();
            list.add(new Pair(l,r));
        }
        //将集合按照所有元素的l进行排序（这里在定义类Pair的时候就得让它
        //实现comparable接口并重写compareTo()方法定义比较规则）
        Collections.sort(list);
        
        //已经在集合中按照所有元素的l排过序了，接下来就是判断集合中的各个元素是否相交
        int count=1;
        int r=list.get(0).r;
        for(int i=0;i<list.size()-1;i++){
            int l=list.get(i+1).l;
            if(r<l){
                count++;
            }
            r=Math.max(r, list.get(i+1).r);
        }
        System.out.println(count);
    }
}

        this.l=l;
```

```Java
//注意上述的方法并没有将最后的区间完成合并，只是一直在计算有多少个区间，
//所以这里我们来完成一下区间的合并工作
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        /*
        这里必须得一次性将n行l-r一起输入进来，然后进行相交的判断，不能一次输入一行l-r这样
        没法判断又因为l-r是成对出现的，所以必须得定义一个数据结构同时包含这两个数据（这里
        不能使用HashMap结构，因为有可能两个l-r对中的l是相同的，这时候如果以l作为key值就会矛盾）
        */
        List<Pair> list=new ArrayList<>();
        for(int i=0;i<n;i++){
            int l,r;
            l=sc.nextInt();
            r=sc.nextInt();
            list.add(new Pair(l,r));
        }
        //将集合按照所有元素的l进行排序
        Collections.sort(list);
        
        
        /*
        注意之前的方法并没有将有交集的区间合并起来，只是一直在算到底有多少个区间，
        这里我们将区间合并起来
        */
        List<Pair> ans=new ArrayList<>();//用来存储所有合并后的区间的集合
        int l=(int)-2e9,r=(int)-2e9;
        //先设定左右边界的值最小，这里因为所给的边界值的范围为（-10^9，10^9）所以我们一开始将边界值
        //设定成-2e9一定比实际的边界值小
        for(int i=0;i<list.size();i++){
            if(r<list.get(i).l){
                if(r!=-2e9){
                    ans.add(new Pair(l,r));
                    /*
                    这里当我们更新到下一个子区间的时候才将上一个子区间加入到最后的集合中，
                    所以当面对最后一个子区间的时候我们是没法将它加入到集合中的，所以最后等出了
                    循环还得加上将最后的子区间加入集合的操作
                    */
                }
                l=list.get(i).l;
                r=list.get(i).r;
            }else{
                r=Math.max(r,list.get(i).r);
            }
        }
        if(r!=-2e9){//出了上述循环以后还得将最后的子区间加入集合
            ans.add(new Pair(l,r));
        }
        System.out.println(ans.size());
    }
}
```
