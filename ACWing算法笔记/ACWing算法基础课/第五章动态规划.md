# 第五章动态规划

## 1、背包问题

### 是什么：

这是一种经典的组合优化问题，其目标是在给定背包容量的情况下，选择一组物品放入背包，以最大化总价值。其中又可以根据每种物品的选择情况将背包问题细分为：01背包问题，完全背包问题，多重背包问题，分组背包问题等。

==01背包问题：==有N种物品和一个容量为V的背包，每种物品最多使用一次，第 i 种物品的体积为v~i~、价值为w~i~，将哪些物品装入背包可使这些物品的总体积不超过背包容量并且总价值最大（**这是最简单的背包问题，也是后续背包问题的基础**）。

==完全背包问题：==有N种物品和一个容量为V的背包，每种物品都有无限件可用，第 i 种物品的体积为v~i~、价值为w~i~，将哪些物品装入背包可使这些物品的总体积不超过背包容量并且总价值最大（**相对于01背包来说，这里的每种物品都有无限件可用，所以更复杂一些，但是要注意实际上每种物品根本不可能选取无限件因为有背包容量的限制**）。

==多重背包问题：==有N种物品和一个容量为V的背包，第 i 种物品最多有 s~i~ 件，第 i 种物品的体积为v~i~、价值为w~i~，将哪些物品装入背包可使这些物品的总体积不超过背包容量并且总价值最大（**相对于01背包来说，这里的每种物品有多种选取可能，但是每种物品的选择范围又不是无限的，它的选择范围不仅受到背包容量的限制还要受到自己本身件数的限制**）。

==分组背包问题：==有N组物品和一个容量为V的背包，每组物品有若干个，同一组内的物品最多只能选一个，每个物品的体积是v~ij~，价值是w~ij~，其中 i 是组号，j 是组内编号，将哪些物品装入背包可使这些物品的总体积不超过背包容量并且总价值最大（**相对于01背包来说，这里的每组物品有多种选取可能，但是每组物品内部之间又是互相排斥的**）。

==朴素解法：==就按照01背包问题的基本思路来解就可以了。

```Java
import java.util.*;
public class Main{
    static int N=1010,V=1010;
    static int[] v=new int[N];
    static int[] w=new int[N];
    static int[][] dp=new int[N][V];
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();//输入物品个数
        int m=sc.nextInt();//输入背包容量
        for(int i=1;i<=n;i++){
            v[i]=sc.nextInt();
            w[i]=sc.nextInt();
        }
        for(int i=1;i<=n;i++){
            for(int j=0;j<=m;j++){
                if(j>=v[i]){//背包装得下第i个物品
                    dp[i][j]=Math.max(dp[i-1][j],dp[i-1][j-v[i]]+w[i]);
                }else{//背包装不下第i个物品
                    dp[i][j]=dp[i-1][j];
                }
            }
        }
        System.out.println(dp[n][m]);
    }
}
```



==一维优化解法：==

观察上述01背包问题的状态转移方程中，每个状态dp[i] [j]只与前一行的状态 dp[i-1] [...] 相关，而与之前的行

dp[i-2] [...]、dp[i-3] [...]等无关。这个特性使得我们可以将二维数组优化为一维数组。

具体来说，**假设我们当前正在计算 dp[i] [j]，在这个过程中，我们只需要使用上一行的状态 dp[i-1] [...] ，不需要关心dp[i-2] [...]、dp[i-3] [...]等更早的状态（它们对当前计算没有直接影响）。因此，我们可以通过不断更新一维数组dp[j]，其中 dp[j] 表示在物品总体积 <=j 的情况下能够获得的最大价值。这种状态转移的优化降低了空间复杂度，将其从O(nm)（二维数组的大小）降低到O(m)（一维数组的大小），其中n是物品数量，m是背包容量**。

#### notes：在计算01背包的一维优化问题时，j必须得逆序

```java
//一维优化做法
import java.util.*;
public class Main{
    static int N=1010,V=1010;
    static int[] v=new int[N];
    static int[] w=new int[N];
    static int[] dp=new int[N];
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        for(int i=1;i<=n;i++){
            v[i]=sc.nextInt();
            w[i]=sc.nextInt();
        }
        for(int i=1;i<=n;i++){
            for(int j=m;j>=v[i];j--){
                /*
                为什么这里的j一定得逆序？
                因为观察上述01背包的二维求解过程我们发现（一维数组始终还是从二维数组优化得来的，
                二维更能反映中间的所有过程）：
                dp[i][j]=Math.max(dp[i-1][j],dp[i-1][j-v[i]]+w[i]);
                也就是说当计算第i层物品的时候用到的都是第i-1层的数据，如果这里我们让j顺序的话
                会有什么后果呢？
                for(int i=1;i<=n;i++){
                	for(int j=0;j<=m;j++){
                		if(j>=v[i]){
                			dp[j]=Math.max(dp[j],dp[j-v[i]]+w[i]);
                		}
                	}
                }
                我们发现上述过程当j顺序的话，那么对于dp[j]的更新顺序肯定是从小到大更新的，
                也就是说在我们更新dp[j]之前我们已经将dp[j-v[i]]更新过了（因为j是从0到m
                从小到大更新的），也就是说此时的dp[j-v[i]]已经是第i层的dp[j-v[i]]了，
                而我们需要的是第i-1层的dp[j-v[i]]啊。
                
                但是上述过程如果当j逆序的话，那么所有的矛盾迎刃而解了:
                当j逆序的话，那么对于dp[j]的更新顺序也是从大到小更新的，也就是说当我们更新dp[j]
                的时候此时dp[j-v[i]]还没有更新（因为j是从m到0从大到小更新的），也就是说此时的
                dp[j-v[i]]依然是第i-1层的dp[j-v[i]]了，而我们需要的就是第i-1层的
                dp[j-v[i]]啊。
                for(int i=1;i<=n;i++){
                	for(int j=m;j>=0;j--){
                		if(j>=v[i]){
                			dp[j]=Math.max(dp[j],dp[j-v[i]]+w[i]);
                		}
                	}
                }
                */
                dp[j]=Math.max(dp[j],dp[j-v[i]]+w[i]);
            }
        }
        System.out.println(dp[m]);
    }
}
```

==朴素做法：==

完全背包问题的解题思路和01背包差不多，唯一区别就是对于集合的划分情况，01背包问题的集合划分情况是：对于第 i 个物品取或者不取这两种情况；完全背包问题的集合划分情况是对于第 i 个物品选择取几个的情况（到底是取0个、1个、2个、、、还是k个）

```java
import java.util.*;
public class Main{
    static int N=1010,V=1010;
    static int[] v=new int[N];
    static int[] w=new int[N];
    static int[][] dp=new int[N][V];
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        for(int i=1;i<=n;i++){
            v[i]=sc.nextInt();
            w[i]=sc.nextInt();
        }
        for(int i=1;i<=n;i++){
            for(int j=0;j<=m;j++){
                for(int k=0;k*v[i]<=j;k++){
                    dp[i][j]=Math.max(dp[i][j],dp[i-1][j-k*v[i]]+k*w[i]);
                    /*
                    注意这里为什么不是：
                    dp[i][j]=Math.max(dp[i-1][j],dp[i-1][j-k*v[i]]+k*w[i]);
                    因为我们要找的是dp[i-1][j]，dp[i-1][j-v[i]]+w[i],
                    dp[i-1][j-2*v[i]]+2*w[i]，dp[i-1][j-3*v[i]]+3*w[i]，，，，
                    dp[i-1][j-k*v[i]]+k*w[i]这么多数中的最大值，
                    
                    而dp[i][j]=Math.max(dp[i-1][j],dp[i-1][j-k*v[i]]+k*w[i]);
                    这个操作每次都是将dp[i-1][j]与其余的所有项进行最大值比较然后将二者更大者
                    赋予dp[i][j]（举例子：假设在众多项中第k1项是最大值，当遍历到第k1项的时候
                    我们会将第k1项的值赋予dp[i][j]这都没有问题，接下来当遍历到第k2项的时候我们
                    会将dp[i-1][j]与第k2项进行大小值比较，将二者较大值赋予dp[i][j]，这个过程
                    是错误的）
                    归根结底这里就是求多个数中最大值的问题。
                    */
                }
            }
        }
        System.out.println(dp[n][m]);
    }
}
```

解题思路：

==朴素做法（会超时）：==因为这里问题的规模变大了，如果依然采用朴素做法的话会超时

分析朴素做法的时间复杂度：

三重循环，第一重 i 是关于N种物品的循环（0< N <=1000），第二重 j 是关于背包容量的循环（0< V <=2000），第三重 k 是关于第 i 个物品取多少件的循环（0< s[i] <=2000），所以总的时间复杂度为 O(4 * 10^9^)=O(10^9^)

#### notes：利用二进制分解将多重背包问题转换为01背包问题

==优化做法（采取二进制分解的优化）：==

分析一下上述朴素做法看看哪里还能优化？

关于N种物品的循环、关于背包容量的循环好像都不能优化了，那么唯一可以优化的就只有关于第 i 个物品取多少件的循环了，我们发现在上述问题中这个循环是一个个进行遍历的，就比如说现在第 i 个物品有50件，为了探寻第 i 个物品取多少件时取得最优解我们会一个个遍历这50件物品，但其实压根不用这么复杂，**我们可以将这50个物品放入几个盒子中，后续直接以盒子为单位来取物品（以盒子为单位来取物品的意思是盒子里面的小球不能再从盒子里取出来），此时就将这50个物品到底取多少个的多重背包问题转换为了几个盒子到底取或不取的01背包问题**，但是问题是假如我们要取0-50中的任何一个数量的物品光凭这几个盒子真的可以做到吗？

可以做到，这就是二进制分解的奥妙， 具体见下图示：

![1703683056887](%E7%AC%AC%E4%BA%94%E7%AB%A0%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92.assets/1703683056887.png)

再来分析一下二进制分解算法的时间复杂度：

总共有N种物品，每个物品有 s[i] 件，将这 s[i] 个物品进行二进制分解得到 logs[i] 个盒子，所以现在总共就相当于有 N*logs[i] 个盒子（注意每个盒子中的小球数量是不同的，相对的每个盒子的体积和价值也是不同的），后续对这些盒子进行依次遍历看看取或不取；

所以现在的时间复杂度为：

二重循环，第一重循环遍历 N*logs[i] 个盒子（O(N * logs[i])=O(1000 * log2000)<O(1000 * 11)），第二重循环遍历背包容量（O(V)=O(2000)），所以总共的时间复杂度为O(22 * 10^6^) =O(10^7^) ，相对于朴素做法会好两个数量级                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   

```Java
//采取二进制分解的优化算法
import java.util.*;
public class Main{
    static int N=12000,V=2010;
    /*
    这里的N=12000是怎么来的？
    总共有差不多11000个盒子，为了保险起见数组开大一点，取12000
    */
    static int[] v=new int[N];
    static int[] w=new int[N];
    static int[][] dp=new int[N][V];
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int cnt=1;//记录总共有多少个盒子
        for(int i=1;i<=n;i++){
            int a=sc.nextInt();//第i个物品的体积
            int b=sc.nextInt();//第i个物品的价值
            int s=sc.nextInt();//第i个物品的数量
            
            //对第i个物品的数量s进行二进制分解
            int k=1;//第1个分组的大小为1（后续分组的大小就是2，4，8，16，，，，）
            while(k<=s){
                v[cnt]=a*k;
                w[cnt]=b*k;
                s-=k;
                k*=2;
                cnt++;
            }
            if(s>0){//如果最后第i个物品的数量还剩下一些但是又不够前面一组的倍数就单独成立一组
                v[cnt]=a*s;
                w[cnt]=b*s;
                cnt++;
            }
        }
        n=cnt;//最后总共有cnt个盒子，我们要遍历所有的这些盒子
        for(int i=1;i<=n;i++){
```

## 2、线性DP

### 是什么：

"线性动态规划"（Linear Dynamic Programming，简称线性DP）通常是指在动态规划问题中，状态转移方程是线性的情况。 

### 为什么：

**线性DP和一般的DP问题有什么区别吗？**

线性DP和一般DP的主要区别在于状态转移方程的形式。在一般的动态规划中，状态转移方程可以是任意形式的函数，而在线性动态规划中，这个方程是线性的。 

==一般动态规划的例子：==

考虑一个经典的动态规划问题，求解斐波那契数列的第n项。状态转移方程为：

*F*(*n*)=*F*(*n*−1)+*F*(*n*−2)

这个方程是非线性的，因为涉及到了两个前一项的加和。

==线性动态规划的例子：==

①考虑一个线性动态规划问题，求解最长上升子序列。状态转移方程为：

*dp*[*i*]=max(*dp*[*j*]+1)其中*j*<*i*且*n**u**ms*[*j*]<*n**u**ms*[*i*]

这个方程是线性的，因为最长上升子序列的长度只与前面的状态有关，而且这个关系是通过线性函数表达的。

②考虑一个数字三角形的问题，求解从起点到最底层的某一点的路径最大值。状态转移方程为：

dp[*i*] [*j*]=max(dp[i-1] [j-1] +a[i] [j]，dp[i-1] [j] +a[i] [j])

这个方程也是线性的，虽然递推式子中涉及到前面两项但是是在前面两项中寻找max的操作，最终将较大的那一项用来计算dp[i] [j]，这个关系也是通过线性函数表达的。

```java
            a[i]=sc.nextInt();
```

```java
            while(l<r){
                int mid=(l+r+1)>>1;
                if(q[mid]<a[i]){
                    l=mid;
                }else{
                    r=mid-1;
                }
            }
            len=Math.max(len,r+1);
            q[r+1]=a[i];
        }

        int len=1;//用于记录最长上升子序列的长度
```

```java
        int len=height.length;
        int[] dp1=new int[len];//用于记录数组中i下标左侧所有元素的最大高度（包括nums[i]）
        int[] dp2=new int[len];//用于记录数组中i下标右侧所有元素的最大高度（包括nums[i]）
        dp1[0]=height[0];
        for(int i=1;i<len;i++){
            dp1[i]=Math.max(dp1[i-1],height[i]);
        }
        dp2[len-1]=height[len-1];
        for(int i=len-2;i>=0;i--){
            dp2[i]=Math.max(dp2[i+1],height[i]);
        }
        int sum=0;//用于记录接雨水的总数
        for(int i=0;i<len;i++){
            sum+=Math.min(dp1[i],dp2[i])-height[i];
        }
        return sum;
    }
}
```

```java
    //双指针算法
    public int trap(int[] height) {
        int leftMax=0;//用于记录数组中左指针左边的最大值(包括nums[left])
        int rightMax=0;//用于记录数组中右指针右边的最大值(包括nums[right])
        int left=0,right=height.length-1;
        int sum=0;//用于记录接雨水的总数
        while(left<right){
            leftMax=Math.max(leftMax,height[left]);
            rightMax=Math.max(rightMax,height[right]);
            if(height[left]<height[right]){
                sum+=leftMax-height[left];
                left++;
            }else{
                sum+=rightMax-height[right];
                right--;
            }
        }
        return sum;
    }
}
```

## 3、区间DP

### 是什么：

区间动态规划是动态规划算法的一种形式，主要应用于处理一些涉及区间的问题。在这类问题中，通常需要在给定的序列或数组中找到满足某种条件的子区间，或者计算某种属性在不同区间内的最优值。 

### 为什么：

区间动态规划通常涉及在序列或数组中找到满足某种条件的子区间，而一般动态规划可以涵盖更广泛的问题类型。让我们通过一个具体的实例来说明这两者之间的区别。 

==一般动态规划问题：最长递增子序列==

**问题描述：** 给定一个数组 `nums`，找到其中最长的递增子序列的长度。

1. **定义状态：** `dp[i]` 表示以位置 `i` 结尾的最长递增子序列的长度。
2. **状态转移方程：** `dp[i] = max(dp[j] + 1) for j < i and nums[j] < nums[i]`。即，当前位置的最长递增子序列长度取决于前面小于当前值的元素的最长递增子序列长度。
3. **边界条件：** 初始时，所有的 `dp[i]` 都设为1，因为单个元素就是一个递增子序列。
4. **计算顺序：** 从左到右逐个计算 `dp[i]`。
5. **解析结果：** 最终结果是 `max(dp)`。

这是一个一般的动态规划问题，状态只与单个位置有关，而不涉及到区间。

==区间动态规划问题：最大子段和==

**问题描述：** 给定一个数组 `nums`，找到连续子数组（至少包含一个元素），使其和最大。

1. **定义状态：** `dp[i][j]` 表示以位置 `i` 开始，位置 `j` 结束的连续子数组的和。
2. **状态转移方程：** `dp[i][j] = dp[i][j-1] + nums[j]`。即，当前位置的连续子数组和等于前一个位置的连续子数组和加上当前位置的值。
3. **边界条件：** 初始时，`dp[i][i] = nums[i]`，表示单个元素构成的连续子数组。
4. **计算顺序：** 通常按照区间长度递增的顺序计算，先计算长度为2的子数组，然后是长度为3的子数组，以此类推。
5. **解析结果：** 最终结果是 `max(dp)`。

这是一个典型的区间动态规划问题，因为状态涉及到了区间的起始和结束位置，而不仅仅是单个位置。

总体来说，一般动态规划更关注单个位置的状态，而区间动态规划更关注区间范围内的状态。这两者的设计思路在解决不同类型的问题时有所不同。

## 4、计数类DP

### 是什么：

计数类动态规划是动态规划的一种应用，主要用于解决计数问题。在计数问题中，我们通常关注的是对某个集合的元素进行组合或排列的方式数量，而不仅仅是找到一个解决方案。计数类DP通常涉及到构建一个二维数组（或者更多维），其中每个元素表示一种状态，并通过递推关系式来计算达到每个状态的方案数量。

在计数类DP中，常见的问题包括：

1. **排列问题（Permutation）：** 对一组元素进行排列，即确定元素的顺序。例如，有多少种不同的排列方式。
2. **组合问题（Combination）：** 对一组元素进行组合，即选择元素的子集。例如，有多少种不同的组合方式。
3. **子集和子序列问题：** 有多少种不同的子集或子序列。
4. **棋盘问题：** 在一个棋盘上放置棋子，有多少种合法的放置方式。
5. **数位DP：** 在数字的各个数位上进行操作，例如计算某个范围内满足某些条件的数字个数。

计数类DP的一般思路是定义状态，找到状态之间的转移关系，然后通过递推计算达到目标状态的方案数量。在计数问题中，递推关系通常与排列、组合、子集等相关。这种方法与传统的优化问题不同，因为我们关注的是方案的数量而非优化目标的最值。

具体问题的解决方法会涉及到一些组合数学的知识，例如排列组合公式。在解决计数类DP问题时，理解问题本质、定义清楚状态、找到递推关系是关键。

### 为什么：

计数类动态规划和一般动态规划的区别在于问题的性质。一般动态规划通常涉及最优化问题，即找到最优解或最小值，而计数类动态规划则侧重于计算满足某些条件的方案数量。以下是一个简单的比较和例子：

==一般动态规划==

**问题：** 最长递增子序列（Longest Increasing Subsequence）

**描述：** 给定一个整数数组，找到其中的一个最长递增子序列的长度。

**动态规划思路：**

- 定义状态：`dp[i]`表示以第`i`个元素结尾的最长递增子序列的长度。
- 找递推关系：`dp[i] = max(dp[j] + 1)`, 其中`j < i`且`nums[j] < nums[i]`。
- 最终结果：`max(dp[i])`，其中`0 <= i < n`。

==计数类动态规划==

**问题：** 子集的数量（Number of Subsets）

**描述：** 给定一个集合，计算其所有可能的子集的数量。

**动态规划思路：**

- 定义状态：`dp[i]`表示集合中前`i`个元素能够组成的子集的数量。
- 找递推关系：`dp[i] = 2 * dp[i-1]`，因为对于前`i-1`个元素的子集，加上第`i`个元素和不加第`i`个元素，可以得到包含第`i`个元素和不包含第`i`个元素的所有子集。
- 最终结果：`dp[n]`，其中`n`为集合中元素的个数。

这两个例子展示了一般动态规划通常涉及最优化问题，而计数类动态规划涉及计数问题。在一般动态规划中，我们关注的是最优解的值，而在计数类动态规划中，我们关注的是满足某些条件的方案数量。

## 5、数位统计DP

### 是什么：

"数位统计DP" 是一种动态规划（DP）的方法，通常用于解决与数字的性质和统计相关的问题。这种方法主要用于计算数字范围内满足某些条件的数字个数，或者计算数字的某些性质。

在数位统计DP中，问题的解决涉及到将数字的每一位拆分并进行状态转移。这种方法的基本思想是通过定义状态、状态转移方程和边界条件来建模问题，并使用动态规划的技巧来求解。

### 为什么：

数位统计 DP 和一般 DP 的主要区别在于其解决的问题类型和问题建模的方式。数位统计 DP 通常用于解决与数字的性质和统计相关的问题，而一般 DP 可以用于解决更广泛的问题，包括序列匹配、最短路径、背包问题等。

举个例子，假设我们要解决一个问题：计算在给定范围内，所有数字中含有特定数字（比如说 3）的数字的个数。

==一般 DP 的方法：==

在这个问题中，我们可以定义一个状态 dp[i]，表示数字 i 中含有数字 3 的个数。然后我们可以通过状态转移方程 dp[i] = dp[i - 1] + （i 中含有数字 3 的个数）来计算问题的解。这是一个典型的一般 DP 问题，与数字的具体性质关系不大。

==数位统计 DP 的方法：==

在数位统计 DP 中，我们可以通过拆分每个数字的每一位，并计算每一位上含有数字 3 的个数，然后通过动态规划的方式来计算问题的解。比如，对于一个数字 x，我们可以定义状态 dp[i] [j] 表示 x 的前 i 位中含有数字 3 的个数为 j。然后我们可以通过状态转移方程来更新 dp[i] [j]，最终得到问题的解。

这两种方法都可以解决问题，但数位统计 DP 更加专注于数字的性质和统计，而一般 DP 则更通用，适用于各种问题。选择使用哪种方法通常取决于问题的性质和要解决的具体情况。

（1）首先我们定义一个函数count(n,x)用于记录1-n之间的所有数字中x(0~9)的出现次数，则a和b之间的所有数字中 x(0~9)的出现次数就可以表示为count(b,x)-count(a-1,x)

（2）现在的问题转换为如何求1-n之间的所有数字中x(0~9)的出现次数？

令n=abcdefg，假设现在我们要求x=2在1-n之间的所有数字中出现的次数，该怎么求？

我们需要分别遍历x=2出现在n的每一位上的情况，比如：当x=2出现在第4位（从左往右数）上时，此时的数形为：yyy 2 zzz，接下来只要使得  yyy2zzz<=abcdefg 然后再计数这样的数有多少个就行了。此时就要分类讨论了：

​	①当2左侧的yyy<abc时，此时左侧yyy的取值范围是：000-（abc-1），此时右侧zzz的取值范围是：000-999，

所以此时满足条件的数总共有：abc*1000个

​	②当2左侧的yyy=abc时，此时就得对d 的取值范围进行讨论了：

- 当d<2时，此时满足条件的数有0个
- 当d=2时，此时右侧zzz的取值范围是：000-efg，此时满足条件的数总共有efg+1个
- 当d>2时，此时右侧zzz的取值范围是：000-999，此时满足条件的数总共有1000个

   ③当2左侧的yyy>abc时，此时满足条件的数有0个

（3）对于x=1-9的讨论都是如此，但是对于x=0的情况得另外讨论，为什么？

因为数字是不能有前导0的，比如说我们现在讨论x=0在第4位上的可能性的时候，则前三位不能为000，否则整个数的结构就形如：0000zzz，而数字是不能有前导0的，也就是说我们得把前面的四个0都得消掉。所以我们现在对于x=0出现在第4位上的情况进行讨论，此时的数形如：yyy0zzz

​	①当0左侧的yyy<abc时，此时左侧yyy的取值范围是：001-（abc-1），此时右侧zzz的取值范围是：000-999，

所以此时满足条件的数总共有：（abc-1）*1000个

​	②当0左侧的yyy=abc时，此时就得对d 的取值范围进行讨论了：

- 当d<0时，此时满足条件的数有0个
- 当d=0时，此时右侧zzz的取值范围是：000-efg，此时满足条件的数总共有efg+1个
- 当d>0时，此时右侧zzz的取值范围是：000-999，此时满足条件的数总共有1000个

​    ③当0左侧的yyy>abc时，此时满足条件的数有0个

（1）首先要能遍历n=abcdefg的每一位

## 6、状态压缩DP

### 是什么：

状态压缩动态规划是一种用于**优化动态规划问题的技巧**，它并不是一种新的动态规划的题型（类似线性DP这种），而是将复杂的状态表示用类似于二进制数来表示，主要应用于状态空间较大的问题。状态压缩的目标是通过采用二进制位等方式减少状态表示的难度从而提高算法效率。

一般而言，状态压缩 DP 主要用于解决集合或子集的问题，其中集合的大小可能很大。在这类问题中，集合的表示往往占用大量的空间，而状态压缩可以通过使用整数的二进制位来表示集合，从而显著减小状态的存储空间。

常见的状态压缩问题包括旅行商问题、子集生成问题、图的最短路径问题等。

### 为什么：

以下是一个简单的例子，说明状态压缩动态规划的基本思想：

假设有一个旅行商要经过 n 个城市，求解最短路径问题。如果直接使用状态表示法，需要表示每个城市是否已经访问，那么状态的数量将是 2^n，这是不切实际的。使用状态压缩，我们可以用n个二进制位表示这n个城市的访问情况。例如，如果二进制位 101 表示访问了第 1 和第 3 个城市，状态的数量依然是 2^n，但是状态的表示现在就不需要集合了而是n个二进制位，大大减小了状态空间。

==状态表示法：== 如果我们使用状态表示法，每个状态表示的是当前已访问的城市集合。由于每个城市可以选择访问或不访问，所以对于 n 个城市，总的状态数量是 2^n。例如，对于 n=3，状态可以是 {1}、{2}、{3}、{1,2}、{1,3}、{2,3}、{1,2,3}，总共 2^3 = 8 种状态。

==状态压缩法：== 如果使用状态压缩，我们用一个整数的二进制位表示城市的访问情况。例如，对于 n=3，状态可以是 000、001、010、011、100、101、110、111，每个状态对应于一个城市的访问情况，总的状态数量仍然是 2^n。

在这两种方法中，状态的数量并没有减小，但状态压缩法在实际实现中可能更容易处理，因为状态的编码和解码可能更为简单。状态压缩的优势通常在于其空间复杂度相对较低，而不是状态数量的减少。

## 7、树形DP

### 是什么：

树形动态规划（Tree DP）是一种动态规划（DP）算法的变体，通常用于解决树（Tree）结构上的问题。在树形DP中，问题的输入是一棵树，而算法的目标是在这个树结构上进行动态规划求解。

树形DP与传统的动态规划有一些区别，因为树结构具有一些特殊的性质。在树形DP中，==通常采用深度优先搜索（DFS）的方式遍历整棵树==，从树的叶子节点开始，逐步向上更新和计算状态。

典型的树形DP问题可能涉及到在树上计算某种最优值、最短路径、最长路径等。在处理每个节点时，树形DP算法会考虑节点本身的状态以及其子节点的状态，通过适当的状态转移方程来更新和计算最终的结果。

### 为什么：

树形DP与一般动态规划的区别主要在于问题的输入结构。一般动态规划通常处理线性序列（如数组或字符串）上的问题，而树形DP则专门用于树状结构。下面我将通过一个简单的例子来说明两者的区别。

假设我们有一个树，每个节点上都有一个权值，现在的问题是找到一条路径，使得路径上的节点权值之和最大。这个问题可以用树形DP来解决。

示例树结构：

![1705392383078](%E7%AC%AC%E4%BA%94%E7%AB%A0%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92.assets/1705392383078.png)

在这个例子中，我们希望找到一条从根节点到叶子节点的路径，使得路径上的节点权值之和最大。

树形DP的状态和状态转移方程可以设计如下：

- 状态 `dp[u]` 表示以节点 `u` 为根的子树中的最大路径和。
- 转移方程：`dp[u] = max(dp[v1], dp[v2], ...) + weight[u]`，其中 `v1, v2, ...` 是节点 `u` 的子节点。

与一般动态规划不同的是，树形DP需要通过深度优先搜索来遍历整个树，以更新每个节点的状态。在一般的动态规划中，状态之间的转移通常是相邻位置之间的转移。

```java
import java.util.*;
public class Main{
    static int N=6010,idx=0;
    static int[] h=new int[N];
    static int[] e=new int[N];
    static int[] ne=new int[N];
    static boolean[] has_father=new boolean[N];
    /*
    用于记录每个节点是否有父节点，后续我们是从根节点往下进行dfs搜索，
    所以得找到那个没有父节点的节点
    */
    static int[] happy=new int[N];
    static int[][] dp=new int[N][2];
    
    static void add(int a,int b){//添加一条由a指向b的边
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
    }
    
    static void dfs(int u){//定义从u节点进行深度优先搜索的方法
        dp[u][1]=happy[u];
        for(int i=h[u];i!=-1;i=ne[i]){
            int j=e[i];
            dfs(j);
            dp[u][0]+=Math.max(dp[j][0],dp[j][1]);
            dp[u][1]+=dp[j][0];
        }
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        for(int i=1;i<=n;i++){
            happy[i]=sc.nextInt();
        }
        
        for(int i=1;i<=n;i++){
            h[i]=-1;
        }
        for(int i=1;i<=n-1;i++){
            int l=sc.nextInt();
            int k=sc.nextInt();
            add(k,l);
            /*
            添加一条由k指向l的边（这里的边是从父节点指向子节点，
            方便后续从根节点进行遍历）
            */
            has_father[l]=true;
        }
        int root=1;//root用于记录根节点的编号
        while(has_father[root]==true){//用于寻找树的根节点
            root++;
        }
        dfs(root);
        System.out.println(Math.max(dp[root][0],dp[root][1]));
    }
}
```

## 8、记忆化搜索

### 是什么：

记忆化搜索是一种通过缓存已经计算过的结果来优化递归算法的技术。它通常用于解决具有重叠子问题性质的问题，其中相同的子问题被多次计算。通过记忆化搜索，可以避免重复计算，提高算法的效率。==记忆化搜索与一般递归的区别就在于记忆化搜索提供了一种缓存机制可以存储已经计算过的数值，这样当下次要用到该数值的时候可以直接从缓存中获取而单纯的递归机制当下次要用到该数值的时候依然需要重新计算==。可以发现记忆化搜索和动态规划类似，都是通过缓存来用空间换取时间避免重复计算的。

### 为什么：

记忆化搜索与动态规划之间有一定的联系，但也存在一些区别。它们都是用于解决重叠子问题的优化技术，但在实施上存在差异。

1. **递归 vs. 迭代**:
   - 记忆化搜索通常是递归的，通过递归调用来解决问题，并通过缓存已计算的结果来避免重复计算。
   - 动态规划则通常是用循环进行迭代的，通过迭代计算并填充一个表格或数组，以自底向上的方式解决问题。
2. **表格或数组**:
   - 记忆化搜索使用一个缓存（通常是字典或哈希表），用于存储已经计算过的子问题的解。
   - 动态规划使用一个表格或数组，其中每个元素表示一个子问题的解。这个表格通常按照某种顺序填充，以确保子问题的解在被需要时已经计算好。

下面通过一个例子来说明记忆化搜索与动态规划的区别，考虑斐波那契数列的问题：

**记忆化搜索实现（递归）**：

**记忆化搜索与一般递归的区别就在于提供了一种缓存机制可以存储已经计算过的值，这样当下次要用到该数值的时候直接从缓存中获取就可以了，避免了单纯递归的重复计算**

```java
import java.util.*;
public class Main{
    static int N=310,M=310,n,m;
    static int[][] h=new int[N][M];//用于记录矩阵中各个点的高度
    static int[][] dp=new int[N][M];//用于记录动态规划的状态
    static int[] dx={-1,1,0,0},dy={0,0,-1,1};//用于记录分别进行上下左右移动时的坐标变换
    
    
    static int f(int x,int y){//记录从(x,y)这个点出发滑雪的最大路径
        if(dp[x][y]!=-1){
            //如果从(x,y)这点出发滑雪的最大路径已经计算过了
            //则直接返回该最大路径就好，避免重复计算
            return dp[x][y];
        }
        dp[x][y]=1;//从(x,y)出发的路径至少也有1步，那就是当前这个区域
        for(int i=0;i<4;i++){
            int a=x+dx[i];//用于记录当前点分别进行上下左右移动后的坐标
            int b=y+dy[i];
            if(a>=1 && a<=n && b>=1 && b<=m && h[x][y]>h[a][b]){
                dp[x][y]=Math.max(dp[x][y],f(a,b)+1);
            }
        }
        return dp[x][y];
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                h[i][j]=sc.nextInt();
            }
        }
        for(int i=1;i<=n;i++){//初始时设置从(i,j)点出发滑雪的路径没有访问过
            for(int j=1;j<=m;j++){
                dp[i][j]=-1;
            }
        }
        int max=0;
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                max=Math.max(max,f(i,j));
            }
        }
        System.out.println(max);
    }
}
```

```java
    为什么代码会超时？就是因为这里存在重复计算：
```
