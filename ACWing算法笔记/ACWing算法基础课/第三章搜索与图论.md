# 第三章搜索与图论

## 1、DFS（深度优先搜索）

### 是什么：

深度优先搜索（DFS）是一种图遍历算法（树是一种特殊的图），在搜索过程中沿着一个路径尽可能深入地访问图中的结点，直到无法继续深入为止，然后回溯到前一个结点，寻找其他未访问的相邻结点。在实现上，DFS通常使用递归或栈来维护遍历过的结点序列。 

#### notes：深度优先搜索的实现是基于回溯的思想（因此一般用回溯法的题也可以用深度优先搜索解决）

### 为什么：

深度优先搜索可以解决以下一些问题：

（1）连通性问题：深度优先搜索可以用于判断一个无向图或有向图是否连通，或者得到无向图或有向图的各个连通分量。

（2）图的遍历问题：深度优先搜索可以用于遍历无向图或有向图的全部结点，或者找到从给定结点出发到达另一个给定结点的路径。

（3）拓扑排序问题：深度优先搜索可以用于拓扑排序，用于找到一个有向无环图中各个结点的合法顺序，使得每个结点都排在它的前驱结点之后。

（4）带权图的最短路径问题：可以利用深度优先搜索加上剪枝等技巧，得到带权图中某个结点到另一个结点的最短路径。



#### notes：需要注意的是，深度优先搜索不一定能够找到图的最优解

因为它可能会沿着比其他路径更长的路径进行搜索。对于某些问题，广度优先搜索或其他算法可能更适合找到最优解。



### 怎么办：

#### 数据结构上如何实现深度优先搜索呢？

在数据结构上深度优先搜索是使用栈来实现的，利用栈来存储从图的起点到终点的这条路径上的所有点，所以需要栈的大小为O(h)（其中h代表图的深度）

#### 算法上如何实现深度优先搜索呢（算法模板）？

在算法上是利用for循环嵌套递归函数来实现深度优先搜索的（for循环嵌套递归函数的结构和回溯法的结构是一模一样的），其中for循环用于遍历搜索树当前层的所有可能情况，递归函数用于遍历搜索树下一层的情况。

```java
public void dfs(){
    if(搜索结束条件){
        搜索结束要进行的操作
    }
    for(遍历搜索树当前层的所有可能情况){
        对当前层正在遍历的情况进行的操作；
        dfs();//对搜索树下一层进行遍历
        恢复现场（取消上述对于当前层正在遍历情况的操作）；
    }
}

/*
DFS模板说明
搜索结束条件：这通常是递归的基本情况，比如达到了搜索树的叶子节点，或者找到了一个有效的解决方案，或是遍历到了问题的边界条件。

遍历搜索树当前层的所有可能情况：这表示在搜索树当前层下，你可以采取的所有可能行动或选择。这一步是DFS的核心，因为它定义了从当前状态到达下一状态的所有可能路径。

对当前层正在遍历的情况进行的操作：对于每一种可能的行动或选择，执行必要的操作，这可能包括更新状态、记录解决方案的一部分等。

递归调用dfs()：通过递归调用自身来探索这个选择之后的所有路径。这一步将问题分解成更小的子问题，并且尝试找到子问题的解决方案。

恢复现场：在探索完当前层一个分支后，你需要撤销在这个分支上做的操作，以便在探索当前层下一个分支时能够回到当前层的原始状态。这一步是回溯算法的关键部分，它确保了每次递归调用都是从相同的状态开始。
*/
/*
如何理解上述的for循环中先是“对当前层正在遍历的情况进行的操作”，然后
又是“取消上述对于当前层正在遍历情况的操作”？

注意这两步操作不是紧挨着的，中间隔了一步对于下一层的递归。
要理解这个操作首先我们得明确搜索树的结构特点，就拿全排列问题的搜索树来说：
（1）首先理解全排列问题的搜索树结构：这里的层次很明显就是排列的是第几个位置的数，
（2）这里的搜索树当前层的所有节点是什么呢？就是当前排列的位置上有几个可选的数，
（3）搜索树下一层的所有节点是什么呢？就是当前位置选定一个数以后下一个位置有几个可选的数，
当我们在当前层中选定一个节点往下延伸的过程中，就意味着当前位置我们已经占用了一个数了
下一层就不能再占用这个数了，然后当下一层的递归回来以后我们会继续探索当前层的其他可能情况
这时候我们自然就要将当前层之前所占用的那个数进行释放然后去探索当前层的其他可能。

举例：
就拿下述对于数组{1，2，3}的全排列来说：
（1）首先在第一层搜索dfs(index=0)中假设选定第一个数是1，
（2）接着进行第二层搜索dfs(index=1)，假设选定第二个数是2，
（3）接着进行第三层搜索dfs(index=2)，只能选定第三个数是3（这时候得到第一个全排列{1，2，3}），
（4）这时候想要进行第四层搜索发现已经满足循环结束条件了所以回溯到第三层搜索dfs(index=2)中的“取消上述对于当前层的操作”即取消选定第三个数是3的操作，这里还没出第三层搜索的for循环接下来我们就要在for循环中看看第三个数还能有什么其他可能，但是因为前两个数已经被选取了，所以只剩下3可选，但是3已经取过一次了，所以对于第三个数已经没有其他可能了，所以第三层搜索就此结束，
（5）第三层搜索结束后我们退回到第二层搜索首先就是第二层搜索的“取消上述对于当前层的操作”即取消选定第二个数是2的操作，这时候还没有出第二层搜索的for循环接着我们就要在for循环中看看第二个数是否还有其他可能，发现是有的，因为之前第三层搜索已经把选定第三个数是3的操作给取消了，刚刚又取消了选定第二个数是2的操作，所以现在第二个数可选的范围有两个即2和3，但是因为第二个数为2我们已经取过了，所以这次我们选取第二个数为3，接着继续进行第二层搜索的for循环中的dfs()函数即进行第三层的搜索看看第三个数可以取什么，这时候可选的数只有2了，所以我们取第三个数为2（得到第二个全排列{1，3，2}），后续都是类似的过程。
*/
```

### （842）排列数字

![1684894513189](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1684894513189.png)

解题思路：

这题就是之前做过的典型的用回溯法解决的题目，现在用深度优先搜索来解决；其实思想都是一样的，都是回溯的思想，关键就在于如何实现回溯呢？

这里就是典型的模板：用for循环嵌套递归实现回溯，其中for循环用于遍历搜索树中当前层的所有情况，递归函数用于遍历搜索树下一层的情况；最后不要忘了一趟搜索完成后要记得恢复现场

```Java
import java.util.*;
public class Main{
    static int N=10,n;
    static int[] path=new int[N];//用于记录每一次数组全排列的情况
    static boolean[] state=new boolean[N];//用于记录每一次的全排列中每一个数字是否被使用过
    static void dfs(int u){//这里的u表示当前遍历的是全排列的第几个位置（u的取值范围为1~n）
        if(u>n){//dfs函数结束的条件(当遍历完全排列的n个位置以后dfs函数就结束了)
            for(int i=1;i<=n;i++){
                System.out.print(path[i]+" ");
            }
            System.out.println();
            return;
        }
        for(int i=1;i<=n;i++){//for循环用于遍历全排列过程中当前层的所有可能情况
            if(!state[i]){
                path[u]=i;
                state[i]=true;
                dfs(u+1);//递归函数用于遍历全排列过程中下一层的情况
                state[i]=false;//别忘了恢复现场
            }
        }
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        dfs(1);
    }
}
```



### （843）n皇后问题

![1684899113911](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1684899113911.png)

解题思路：

==思路一：按照行顺序遍历来实现n皇后问题==

（1）这里我们按照行的顺序先遍历第一行看看第一行有哪些位置可以放置皇后，在第一行放置完皇后以后遍历第二行看看第二行有哪些位置可以放置皇后（因为第一行已经放置了皇后所以她所在的列以及主对角线和次对角线就不能再放置皇后了），就这样n皇后问题的搜索树已经明朗了。

上述按照行顺序确实可以保证每一行只有一个皇后，但是仅仅如此没办法保证每一列、每一个斜线上只有一个皇后的条件啊，所以我们还需要用一个数组来记录每一列的皇后放置情况，当遍历到当前层的第j列的时候发现第j列已经放置了皇后那么当前层的第j列就不能放置皇后了；同理我们再用两个数组来记录棋盘上所有的主对角线和次对角线上的皇后放置情况，当遍历到当前层的第j列的时候发现第j列对应的主对角线上已经放置了皇后则当前层的第j列就不能再放置皇后了**（需要注意的是当数组长度为N时主对角线（次对角线）的数目为 ：N * 根号2 条，所以为了记录每一个主对角线我们需要开辟大小为2*N的数组）**

（2）这里还有一个问题，那就是所有的主对角线以及次对角线该如何表示？举例如下图所示：该如何表示这里的5条次对角线呢？

这里我们以红线为例：其中的（3，2）和（2，3）这两个点在同一个次对角线上，那么该怎么表示这两个点所在的对角线呢？

所有的次对角线所在的直线方程都是y=x+b的形式，**如果想表示在同一个次对角线上的点的话，我们知道肯定是满足y=x+b这个形式的，这里的区别就在于b的不同，不同的b代表了不同的直线，**如何表示不同的b呢？

y=x+b ---> b=y-x   就可以了所以我们可以根据横纵坐标的关系来判断两个点是否在同一条次对角线上，所以这里我们就可以用y-x的值作为下标来标注是哪一个次对角线，不过这里还有一个问题：那就是y-x的值有可能是负的，数组下标不能是负值，所以我们可以给y-x的值加上一个棋盘长度(或宽度)n，即：b=y-x+n，这样既可以确保下标为正数，同时也不会产生数组越界（因为这里为了表示每一根次对角线，我们给对角线方向设置的数组大小为 2*n），同时又可以保证不同的斜线对应的b值是不同的，就此可以完整表示每一个次对角线（主对角线也是同理：b=y+x）

![1685524390131](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1685524390131.png)

（3）按照行顺序遍历棋盘的时候，我们是不需要考虑n个皇后放不满的问题的但是在按格子顺序遍历的时候必须得考虑，为什么？

因为这里我们按照行顺序遍历的时候在每一行我们都尽可能找位置放皇后，必须把皇后放好了我们才进入到下一行，所以当遍历到第n+1行的时候本身就意味着我们在前n行将n个皇后放置好了否则它不会来到第n+1行这个位置

```Java
import java.util.*;
public class Main{
    static int N=10,n;
    static char[][] g=new char[N][N];//用于记录棋盘上的棋子摆放情况
    /*
    这里如何实现每一行、每一列、每一个斜线上不存在两个皇后呢？
    这里我们可以按照行顺序依次遍历每一行以此来实现每一行只有一个皇后，但是每一列、每一个斜线呢？
    这里我们可以用一个数组来记录每一列上是否放置了皇后，如果该列已经放置了皇后的话就不能再放了；
    再用两个数组分别记录所有主对角线、次对角线上是否放置了皇后，需要注意的是当棋盘长度为N时
    主对角线（次对角线）的数目为：N * 根号2 条，所以为了记录每一个主对角线我们需要开辟大小
    为2*N的数组
    */
    static boolean[] col=new boolean[N];//用于记录每一列是否放置了皇后
    static boolean[] dg=new boolean[2*N];//用于记录每一个主对角线上是否放置了皇后
    static boolean[] udg=new boolean[2*N];//用于记录每一个次对角线上是否放置了皇后
    
    static void dfs(int u){//这里的u代表当前遍历的是棋盘的第几行（u的取值范围为：1-n）
        if(u>n){//搜索结束条件（当遍历完棋盘的第n行就结束搜索）
            for(int i=1;i<=n;i++){
                for(int j=1;j<=n;j++){
                    System.out.print(g[i][j]);
                }
                System.out.println();
            }
            System.out.println();
            return;
        }
        /*
        注意这里为什么我们不用判断n个皇后放不满的情况，但是在按照格子顺序的时候就得考虑呢？
        因为这里我们按照行顺序遍历的时候在每一行我们都尽可能找位置放皇后，必须把皇后放好了
        我们才进入到下一行，所以当遍历到第n+1行的时候本身就意味着我们在前n行将n个皇后放置好了
        否则它不会来到第n+1行这个位置的
        */
        
        
        for(int j=1;j<=n;j++){//for循环用于遍历棋盘当前层的所有摆放位置
            if(!col[j] && !dg[j+u] && !udg[j-u+n]){
            /*
            如果当前层的第j列没有皇后，并且当前层第j列对应的主对角线上没有皇后，
            并且当前层第j列对应的次对角线上没有皇后，那么皇后就可以摆放在当前层的第j列的位置上
            */  
                g[u][j]='Q';
                col[j]=dg[j+u]=udg[j-u+n]=true;
                dfs(u+1);
                g[u][j]='.';//不要忘了恢复现场
                col[j]=dg[j+u]=udg[j-u+n]=false;
            }
        }
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        for(int i=1;i<=n;i++){
            for(int j=1;j<=n;j++){
                g[i][j]='.';
            }
        }
        dfs(1);
    }
}
```





==思路二：按照格子顺序遍历来实现n皇后问题==

（1）相对于行顺序遍历天然就可以排除每一行有两个皇后这种情况按照格子顺序遍历棋盘我们需要额外再开一个数组用来存储每一行是否放置了皇后

（2）按照格子顺序遍历的话，那么是如何遍历的呢？

我们按照每一个格子的坐标（i，j）去遍历，当要遍历下一个格子的时候固定i不变执行j++操作就行了。

（3）当我们到达了一行的末尾的时候该怎么办呢？

我们可以加上一个判断：j>n吗？如果j>n那么就代表已经遍历到了该行的末尾，此时我们执行j=1，然后令i=i+1即跳转到下一行第一个位置即可

（4）关于数组越界的问题，注意这里的数据n最大可以取到9，如果我们将数组大小设置成10然后从数组下标1处开始存储元素，那么刚好数组下标最后一个位置存储了元素，但是当我们想遍历下一个格子从而执行j++操作的时候就产生了数组越界；所以最好一开始我们就将数组下标定大一点

（5）另外还有一点需要注意，那就是这里按照格子顺序遍历的时候我们得考虑n个皇后放不满的问题。第一种方法按照行顺序遍历棋盘的时候我们没有考虑皇后放不满的情况，为什么这里要考虑呢？不考虑行不行？

因为第一种按照行顺序的时候我们是在每一行都要找机会放皇后，如果当前行没有放置皇后就没法进入下一行，所以如果已经遍历到了n+1行那就代表所有的n个皇后在前n行都已经被放置好了；但是这里按照格子顺序遍历的时候我们并没有说每个格子尽可能都要放置皇后，而是每个格子有两种选择：放置皇后、不放皇后。所以即使当前的格子不放皇后，也可以遍历到下一个格子，即使极端情况下前n行的所有格子都不放皇后，还是可以遍历到第n+1行，所以按照格子顺序遍历的时候我们得考虑皇后没有放满的情况

```Java
//n皇后问题的第二种遍历顺序：按照一个格子一个格子的顺序遍历
import java.util.*;
public class Main{
    static int N=10,n;
    static char[][] g=new char[N+1][N+1];
    /*
    用于记录棋盘上的棋子摆放情况，为什么要把数组大小设置为N+1呢？
    因为设置成N的话会产生数组越界，因为这里最多存在n=9个元素，而我们将N设置为10，
    所以如果我们将数组大小设置成N的话数组也就刚刚好比元素数目大一个，假如我们
    数组是从下标1位置开始存储元素的话那么就会产生数组最后一个元素刚好压界的情况；
    而下面递归函数dfs(int i,int j,int s)当遍历到下一个节点dfs(i,j+1,s)的时候就会
    产生越界了
    */
    /*
    这里当采用一个格子一个格子的顺序进行遍历的时候如何保证棋盘上每一行、每一列、每一个斜线上
    只有一个皇后呢？
    前面当我们采用按行顺序遍历的时候可以确保每一行有且仅有一个皇后，但是现在按照格子的顺序
    就没法保证每一行只有一个皇后了，必须采取别的手段来确保这个条件，我们采取的就是用一个数组
    来存储每一行摆放皇后的情况
    至于每一列、每一个斜线上有且仅有一个皇后就还是和前面的做法一样用数组表示：
    这里我们可以用一个数组来记录每一列上是否放置了皇后，如果该列已经放置了皇后的话就不能再放了；
    再用两个数组分别记录所有主对角线、次对角线上是否放置了皇后，需要注意的是当数组长度为N时
    主对角线（次对角线）的数目为根号N条，所以为了记录每一个主对角线我们需要开辟大小为2*N的数组
    */
    static boolean[] row=new boolean[N+1];//用于记录每一行是否放置了皇后
    static boolean[] col=new boolean[N+1];//用于记录每一列是否放置了皇后
    static boolean[] dg=new boolean[2*N];//用于记录每一个主对角线上是否放置了皇后
    static boolean[] udg=new boolean[2*N];//用于记录每一个次对角线上是否放置了皇后

    static void dfs(int i,int j,int s){
        //这里的i代表的是当前遍历的格子是第i行，这里的j代表当前遍历的格子是第j列，
        //这里的s代表当前已经放置了s个皇后了
        /*
        这部分是搜索结束条件：
        */
        if(i>n){//递归结束条件一：当遍历完n行以后不管n个皇后的位置有没有摆放好都结束搜索了
          return; 
        }
        if(s==n){//递归结束条件二：在第n行已经放置完了所有的n个皇后
            for(int u=1;u<=n;u++){
                for(int v=1;v<=n;v++){
                    System.out.print(g[u][v]);
                }
                System.out.println();
            }
            System.out.println();
            return;
        }
        /*
        第一种方法按照行顺序遍历棋盘的时候我们没有考虑皇后放不满的情况，为什么这里要考虑呢？
        不考虑行不行？
        因为第一种按照行顺序的时候我们是在每一行都要找机会放皇后，如果当前行没有放置皇后就没法
        进入下一行，所以如果已经遍历到了n+1行那就代表所有的n个皇后在前n行都已经被放置好了；
        但是这里按照格子顺序遍历的时候我们并没有说每个格子尽可能都要放置皇后，而是每个格子
        有两种选择：放置皇后、不放皇后。所以即使当前的格子不放皇后，也可以遍历到下一个格子，
        即使极端情况下前n行的所有格子都不放皇后，还是可以遍历到第n+1行，所以按照格子顺序遍历
        的时候我们得考虑皇后没有放满的情况
        */


        /*  
        这部分是对于搜索树当前层的所有可能情况的遍历（相当于原来的for循环的位置）
        这里本来应该是用for循环对于搜索树当前层的所有可能情况进行遍历，
        但是这里的所有可能情况也就只有两种：当前格子要么放皇后，要么不放皇后；
        所以我们就省去了for循环，直接对当前层遍历这两种情况
        */

        //这里因为是按照格子的顺序进行遍历，所以当遍历完一行的所有格子后需要进行处理
        if(j>n){//采用按格子顺序遍历时，当遍历完一行以后从第二行开头的格子接着遍历
            j=1;
            i++;
        }
        //当前位置不放皇后(则我们接着看下一个位置是否放皇后)
        g[i][j]='.';
        dfs(i,j+1,s);

        /*
        当前位置放皇后(当前位置怎么样才能放皇后呢？当前位置所在行、所在列、所在主对角线、
        次对角线都没有皇后那么当前位置才可以放置皇后)
        */
        if(!row[i] && !col[j] && !dg[j+i] && !udg[j-i+n]){
           g[i][j]='Q';
           row[i]=col[j]=dg[j+i]=udg[j-i+n]=true;
           dfs(i,j+1,s+1);//当前位置放置皇后以后继续遍历下一个位置
           g[i][j]='.';//记得恢复现场
           row[i]=col[j]=dg[j+i]=udg[j-i+n]=false;
        }
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        for(int i=1;i<=n;i++){
            for(int j=1;j<=n;j++){
                g[i][j]='.';
            }
        }
        dfs(1,1,0);
    }
}
```

### （力扣200）岛屿数量

解题思路：

这里我们的想法就是通过dfs来遍历这个二维数组，但是不像前面两题中有着明显的搜索树层次感，比如：在排列数字问题中的层次就是当前排列的是第几个位置的数字，而在n皇后问题中的层次就是当前排列的是第几行的皇后，而本题的层次是什么呢？

看不出来，但是借由n皇后问题中的第二种思路：按照格子顺序来遍历n皇后问题，我们可以得到启发，本题我们也可以按照二维数组的顺序来遍历每一个点即：dfs(int i，int j)（其中i，j是二维数组中的下标），按照这个顺序的话我们就可以看出此时的层次就是每次访问的点（==假如当前层表示正在访问(i，j)点，则搜索树的下一层就是代表访问(i，j)点的上下左右四个相邻节点==），按照dfs的模板同时借着这个思路我们往下做：

（1）for循环遍历搜索树当前层的所有可能情况：

这里搜索树当前层表示当前正在访问的节点（i，j），那么当前层有多少种可能情况呢？
其实就两种：要么当前节点是陆地节点，要么是海洋节点；这里总共就两种可能情况我们也没必要用for循环来遍历了，直接就用if-else分支来进行遍历就可以

（2）递归搜索树下一层的所有情况：

这里搜索树下一层的所有节点是：在二维数组中与当前节点相邻的上下左右四个节点，我们在for循环内部（前面已经说了这里不用for循环，那就在if-else分支内部）依次递归访问这四个节点

（3）恢复现场：

这里一定要理解的就是恢复现场的操作，在探索完当前层一个分支后，你需要撤销在这个分支上做的操作，以便在探索当前层下一个分支时能够回到当前层的原始状态。也就是说我们恢复现场是为了不耽误对当前层下一个分支的遍历。

```java
            }
        }

        for (int i = 0; i < grid.length; i++) {

                    count++; // 发现新岛屿
                }
            }
        }
        return count;

    我们观察这个dfs方法，它可以从一个点出发就将所有的节点遍历完整吗？
    答案是不能的，因为虽然我们可以从当前这个节点出发向上下左右四个方法延伸，

    所以最后我们只要统计dfs方法执行了多少次就行了

        if(!isLocation(grid,a,b) || visited[a][b]==true){
            /*

            */
            return;
        }
        
        /*
        遍历搜索树当前层的所有可能情况：
        当前层其实就两种情况：要么当前节点是陆地节点，要么是海洋节点，所以我们也没有
        必要用for循环来遍历搜索树当前层的所有可能情况，直接用if-else就能遍历所有可能情况

                遍历搜索树下一层的所有可能情况，这里要注意搜索树下一层同时有四种情况

                int y=b+dy[i];
                dfs(grid,x,y);

            因为恢复现场指的是在探索完当前层一个分支后，撤销对于该分支的操作，以免影响
            遍历当前层的其他分支。

            根本不用恢复现场，因为不会对另一个分支产生任何影响。
            */
        }
    }

            return true;
        }else{
            return false;
        }
    }
```

### （力扣463）岛屿的周长

![1708675264005](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1708675264005.png)

解题思路：

现在主要有以下几个问题：

（1）如何计算岛屿周长呢？

将岛屿外围每条边的长度相加

（2）如何计算岛屿外围每条边呢，==怎样会形成岛屿外围的一条边呢==？

==①当陆地节点与海洋节点相邻时会形成一条边==

==②当陆地节点位于边界时会形成一条边==

本题还是用dfs的思想，借由前面一题“岛屿数量”我们已经知道当由一个陆地节点进行延伸的时候它会延伸到所有与它相连的陆地节点（碰到边界或者是海洋节点就停止延伸），根据这个思想我们可以首先找到一个陆地节点然后在该节点处进行dfs搜索它会自动进行延伸，然后我们看它延伸的情况，当遇到海洋节点或者是边界时就进行长度加1的操作，最后统计这个长度就行了。

为什么一定得先找到一个陆地节点然后在该节点处进行dfs搜索？

因为并不是随便的一个海洋节点就能构成一条边，也并不是随便的一个位于边界上的节点就能构成一条边，一定得是由陆地节点延伸过去的。

```java
class Solution {
    static int[] dx=new int[]{-1,1,0,0};
    static int[] dy=new int[]{0,0,-1,1};
    public int islandPerimeter(int[][] grid) {
        int N=110;
        boolean[][] visited=new boolean[N][N];
        int ans=0;//用于记录岛屿周长
        for(int i=0;i<grid.length;i++){
            for(int j=0;j<grid[0].length;j++){
                if(grid[i][j]==1 && visited[i][j]==false){
                    ans=dfs(grid,visited,i,j);
                }
            }
        }
        return ans;
    }
    public int dfs(int[][] grid,boolean[][] visited,int a,int b){
        if(a<0 || a>=grid.length || b<0 || b>=grid[0].length || grid[a][b]==0){
            return 1;
        }
        if(visited[a][b]){
            return 0;
        }
        visited[a][b]=true;
        int count=0;
        for(int i=0;i<4;i++){
            int x=a+dx[i];
            int y=b+dy[i];
            count+=dfs(grid,visited,x,y);
        }
        return count;
    }
}
```

## notes：树和图是如何存储的？

树是一种特殊的图，无环连通图，所以我们只要了解关于图的存储就行了。



### 图的分类：

（1）有向图：有向图指图中的边是有方向的，比如一条a-->b的边，则只能从a走向b不能反过来走

（2）无向图：无向图是指图中的边是没有方向的，这点该如何实现呢？其实我们只要弄两个反方向的边就可以了。比如一条a--b的无向边意味着既能从a走向b又能从b走向a，所以我们弄一条a-->b的有向边，再弄一条b-->a的有向边就行了

综上，我们只要弄清楚有向图的存储就行了。



### 如何存储有向图？

（1）方式一：邻接矩阵（不好）

用一个n * n的二维矩阵来存储两个点直接是否连通（不过这种方式的空间复杂度高，为O(n^2)，所以如果不是密集矩阵的话用这种方式不划算）（这里的n为点的个数）

（2）方式二：邻接表（好）

用n个单链表来存储有向图，每个单链表存储的都是与该节点直接相连的节点（这里的n为点的个数）



### （846）树的重心

解题思路：

#### 树的重心

##### 是什么：

将树中每一个节点作为拆分点都能得到几个连通块，然后找到当前拆分节点对应的其中最大的那个连通块，对每个节点都进行上述操作找到每个节点对应的最大的连通块，然后在这么多最大的连通块中找到最小的那个，它所对应的节点就是树的重心（树的重心可能不止一个），举例如下图所示：

##### 如何计算树的重心呢？

利用dfs算法，对每个节点计算一次以它作为拆分点后得到的最大连通块的大小，然后所有节点对应的最大连通块的大小进行一次比较找出其中的最小值，它所对应的节点就是树的重心

```Java
        */

            add(b,a);
```

## 2、BFS（宽度优先搜索）

### 是什么：

宽度优先搜索（BFS）是一种图遍历算法（树是一种特殊的图），在搜索过程中按层次逐个访问与起始节点相邻的结点，即首先访问起始节点，然后访问与其距离为1的节点，然后是距离为2的节点，以此类推，直到遍历完所有与起始节点相连通的结点为止，每个节点只被访问一次。

### 为什么：

宽度优先搜索（BFS）可以解决以下一些问题：

（1）最短路径问题：BFS可以用于求解图中两个结点之间的最短路径，因为它能够按层次逐个遍历与起始节点相邻的结点，故能够获取起始节点到其他节点的所有不同路径，其中第一条到达目标节点的路径即为最短路径。

（2）最小生成树问题：BFS可以用于求解无向带权图的最小生成树，这时候可以将BFS队列约束为只存储与当前已访问节点集合距离为1的节点，从而逐层递进地发现与已访问节点集合距离为2的节点，以此类推。

（3）双向BFS问题：对于某些问题，可采用“双向BFS”的方式，即从起始节点和目标节点同时开始BFS遍历，直到两个遍历过程相遇。这种算法通常比单向BFS要快得多。

#### notes：BFS作用于最短路径时只适用于无权图或非负权图的最短路径问题



### 怎么办：

#### 数据结构上如何实现宽度优先搜索呢？

在数据结构上是利用队列来实现宽度优先搜索的，将图中位于同一层的所有节点入队，所以所需队列的大小就是O(2^h)（其中假设该图是二叉树，h为二叉树的高度）

#### 算法上如何实现宽度优先搜索？

在算法上也是利用while循环+队列来实现宽度优先搜索的

```Java
//宽度优先搜索模板
queue<--初始状态  //将初始状态入队
while(queue 不空){
    取队头;
    扩展队列;
}
```



### （844）走迷宫

![1685454443927](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1685454443927.png)

解题思路：

这题就是典型的宽度优先搜索的题目，每一次从当前点可以同时向上下左右四个方向移动，这四个移动后的点就是宽度优先搜索树中位于同一层的点，即先扩展距离当前点距离为1的点（它上下左右的四个点），再扩展距离当前点距离为2的点（即距离上一步扩展的点距离为1的点，注意每个点只能被访问一次，要不然同一个点经过不同的路径导致距离不同就不好了，这里利用宽度优先搜索我们得到的是每个点的最短路径）

（1）注意这里的迷宫问题，它什么时候会停止呢？

当遍历完迷宫中所有的节点以后就结束了。

（2）那么访问的最后一个节点一定是我们要访问的目的点即右下角的那个点吗？

当然不是，这取决于迷宫的具体构造，但是不管怎样，最终当搜索结束后，我们一定可以得到迷宫中所有点的距离，然后我们选择输出我们想要的目的点的距离就好了

```Java
/*
如何实现宽度优先搜索呢？
用while循环+队列实现，所以这里我们要创建一个队列用来存储各个节点，但是又没有现成的类可以表示节点
所以我们还得另外创建一个节点类
*/

import java.util.*;

//定义的节点类（里面的两个属性分别代表点的横纵坐标）
class Pair{
    int first;
    int second;
    public Pair(int first,int second){
        this.first=first;
        this.second=second;
    }
}


public class Main{
    
    static int N=110,n,m;
    //创建的节点队列（这里用数组来实现队列，这里最多只有n*m个节点入队）
    static Pair[] q=new Pair[N*N];
    static int head=1,tail=0;//队首指针、队尾指针
    static int[][] g=new int[N][N];//用来存储迷宫的二维数组
    
    /*
    用来存储迷宫中每个点到起点的距离，这里的距离不是直线距离，而是采用宽度优先
    搜索时的路径长度（初始时设置每个点的距离都是-1）
    */
    static int[][] dist=new int[N][N];
    
    /*
    定义节点上下左右移动时的坐标向量变化情况，比如当向上移动时横坐标不变纵坐标减1，
    当向下移动时横坐标不变纵坐标加1（这里以水平方向向右为x轴正向，竖直方向向下为y轴正向）
    */
    static int[] dx={0,0,-1,1};
    static int[] dy={-1,1,0,0};
    
    static void bfs(){
        while(head<=tail){//当队列不空时
            Pair t=q[head++];//取队头
            for(int i=0;i<4;i++){
                int x=t.first+dx[i];//队头元素所对应的位置向上下左右移动
                int y=t.second+dy[i];
                /*
                如果队头元素向上下左右移动后没有出界，而且移动后的位置不是墙可以走，
                而且之前没有走过，就可以走过去
                */
                if(x>=1 && x<=n && y>=1 && y<=m && g[x][y]==0 && dist[x][y]==-1){
                    dist[x][y]=dist[t.first][t.second]+1;
                    /*
                    队头元素移动一个位置到达现在的位置所以现在的位置距离出发点的距离
                    就是队头元素的距离加1
                    */
                    q[++tail]=new Pair(x,y);//扩展队列
                }
            }
        }
        System.out.println(dist[n][m]);
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        //进行一些初始化的工作
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                dist[i][j]=-1;
            }
        }
        dist[1][1]=0;
        q[++tail]=new Pair(1,1);
        
        for(int i=1;i<=n;i++){
            for(int j=1;j<=m;j++){
                g[i][j]=sc.nextInt();
            }
        }
        bfs();
    } 
}
```

### （848）有向图的拓扑序列

解题思路：

拓扑排序的本质就是宽度优先搜索，每一轮搜索都会将入度为0的顶点入队，然后与它们相连的顶点的入度就减少1，就这样每一轮搜索都是将入度为0的顶点入队

![1686916609468](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1686916609468.png)

```Java
/*
拓扑排序本质就是bfs，每一轮宽度优先搜索都会将入度为0的顶点入队，
然后与它们相连的顶点的入度就减少1，就这样每一轮搜索都是将入度
为0的顶点入队
*/
import java.util.*;
public class Main{
    static int N=100010,n,m,idx,head=1,tail=0;
    static int[] e=new int[N];//用于存储各个节点序号对应的编号
    static int[] ne=new int[N];//用于存储各个节点序号的next指针
    static int[] h=new int[N];//邻接表
    static int[] queue=new int[N];
    static int[] d=new int[N];//用于存储各个编号的顶点的入度
    
    static void add(int a,int b){//增加一条由a指向b的边，由此b的入度加1
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
        d[b]++;
    }
    static boolean topsort(){
        for(int i=1;i<=n;i++){//将初始情况入队（即将所有入度为0的点入队）
            if(d[i]==0){
                queue[++tail]=i;
            }
        }
        while(head<=tail){//当队列不空时
            int i=queue[head++];//取队头
            /*
            这里出队的过程仅仅只有队头指针的移动，元素依然存在于数组中
            */
            
            for(int j=h[i];j!=-1;j=ne[j]){//扩展队头
                int k=e[j];
                //这里的h[]数组中存储的是节点的序号而d[]数组中存储的
                //是节点的编号，所以得将节点序号转变为编号
                
                d[k]--;
                if(d[k]==0){
                    queue[++tail]=k;
                }
            }
        }
        if(tail==n){
            //如果图中没有环的话那么所有顶点都会入队，否则会有顶点没有入队的，
            //此时不存在拓扑序列
            return true;
        }
        return false;
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        for(int i=1;i<=n;i++){
            h[i]=-1;
        }
        for(int i=1;i<=m;i++){
            int x,y;
            x=sc.nextInt();
            y=sc.nextInt();
            add(x,y);
        }
        if(topsort()){
            for(int i=1;i<=n;i++){
                //上述元素出队的过程中只有队头指针的移动，元素依然存在于数组之中
                System.out.print(queue[i]+" ");
            }
        }else{
            System.out.println(-1);
        }
    }
}
```

## 3、Dijkstra算法（用于求单源最短路且无负权边的问题）

### note：0x3f3f3f3f是什么

#### 这里如何表示集合s呢？

我们得明确这里的集合s是什么？是我们已经确定了该节点距离1号节点的最短路径的节点就将它加入集合s中，所以我们完全可以用一个boolean[]类型的数组来充当这里的集合s，如果我们已经明确了当前节点距离1号节点的最短路径那么就将当前节点对应的boolean[]类型的数组元素值置为true表示将当前节点加入集合s中



#### 这里的图存在重边该如何处理？

重边是什么？重边指的是两个节点之间存在多条边，如下图所示，面对这种情况对于两点之间的距离我们只要选取两个点之间最短的那条边就好

#### 这里的图存在自环该如何处理？

自环是什么？指的是某个点有一条自己指向自己的边，如下图所示，对于自环我们不需要任何处理，为什么？

因为假设我们现在从1号节点开始依次寻找最短边，先找到节点i后找到节点j，节点j存在自环，那么来回顾一下dijkstra算法的求解步骤：

（1）首先在所有节点中寻找距离1号节点最近的节点，找到就是1号节点本身（距离1号节点距离为0），将1号节点加入集合s，用1号节点更新其他节点到1号节点的距离

（2）接着在剩下的节点中寻找距离1号节点最近的那个节点，假设找到的就是节点i，将i号节点加入集合s，用i号节点更新其他节点到1号节点的距离

（3）接着在剩下的节点中寻找距离1号节点最近的那个节点，假设找到的就是节点j，将j号节点加入集合s，用j号节点更新其他节点到1号节点的距离（dist[k]=Math.min(dist[k]，dist[j]+g[j] [k])，**也只有在这一步才会用上节点j的出度，但是用上的也是j号节点指向k号节点的边的长度而不是j号节点指向自身的那条边的长度**）（这里的k泛指所有其他非j号节点，g[j] [k]就是节点j指向节点k的边的长度）

### （849）Dijkstra求最短路I（朴素算法）

![1687358558955](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1687358558955.png)

解题思路：

注意这里的图是一个稠密图（m~n^2），所以对于稠密图我们使用邻接矩阵来存储，同时使用朴素版dijkstra算法来进行求解

```Java
import java.util.*;
public class Main{
    static int N=510,n,m,max=0x3f3f3f3f;//0x3f3f3f3f用于表示无穷大的值
    static int[][] g=new int[N][N];//用邻接矩阵来表示图（对于稠密图用邻接矩阵比邻接表更好）
    static int[] dist=new int[N];
    //记录各个点距离初始点(也就是1号点)的最短距离，数组元素初始化为无穷大
    static boolean[] st=new boolean[N];//用于记录每个点是否找到距离初始点的最短距离(充当集合s)
    
    static int dijkstra(){
        //（1）初始化距离
        Arrays.fill(dist,max);
        dist[1]=0;
        
        //（2）进行n次迭代，每次将一个不在集合s中的距离初始点最近的点加入集合
        for(int i=1;i<=n;i++){//这里的i表示循环的次数
            int t=-1;//这里的t表示每次找到的不在集合中且距离初始点最近的那个点
            for(int j=1;j<=n;j++){//这里的j表示节点编号，每次都要在这些节点当中寻找满足要求的的节点
                if(!st[j] && (t==-1 || dist[t]>dist[j])){
                    t=j;
                }
            }
            st[t]=true;//将节点t加入集合s中
            for(int k=1;k<=n;k++){//用节点t更新其他节点的距离
                dist[k]=Math.min(dist[k],dist[t]+g[t][k]);
            }
        }
        if(dist[n]!=max){
            return dist[n];
        }else{
            return -1;
        }
    } 
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        
        //一些初始情况的设定：将邻接矩阵中的边值设定为无穷大
        for(int i=1;i<N;i++){
            Arrays.fill(g[i],max);
        }
        
        for(int i=1;i<=m;i++){
            int x,y,z;
            x=sc.nextInt();
            y=sc.nextInt();
            z=sc.nextInt();
            g[x][y]=Math.min(g[x][y],z);
            //因为图中可能存在重边，那么此时两点之间的距离就是重边中的最小值
        }
        System.out.println(dijkstra());
    }
}
```



### （850）Dijkstra求最短路II（堆优化算法）

![1687527120616](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1687527120616.png)

解题思路：

#### 是什么：

在朴素版dijkstra算法的基础上加入了小根堆来进行优化从而提高了算法的效率



#### 为什么：

当边的数目达到10^5级别的时候如果再用朴素版dijkstra算法那么算法的时间复杂度就会是10^10级别造成超时，所以得用堆优化版dijkstra算法



#### 怎么办：

（1）为什么堆优化dijkstra算法可以提高算法效率？

因为朴素dijkstra算法需要经过n次循环，每次需要在n个点中找到不在集合s中的且距离1号节点距离最近的点，时间复杂度为O(n^2)；而堆优化dijkstra算法将所有节点放入小根堆中然后每次从小根堆中取出不在集合s中且距离1号节点最近的点就行了，时间复杂度为O(nlogn)即构建小根堆的时间复杂度

（2）本题的图是稀疏图，所以用邻接表来表示这里的图，但是这里的各个边的权值该如何表示呢？

重新令一个数组w[]来存储各个边的权值即可

（3）这里的小根堆里装的是什么？

是节点到1号节点的距离还是节点的编号呢？

答案是两者都得装，装距离是因为小根堆中需要用到距离进行排序，装编号是因为需要知道每个距离对应的是哪个编号的节点；所以我们得创建一个类，将节点距离1号节点的距离以及该节点的编号作为属性存储在该类中

（4）这里存在重边和自环有影响吗？

没有影响，因为所有的重边都被加入到小根堆中，小根堆会进行排序筛选出距离最近的那个，对于自环也是同样的道理。

这里为什么不人为对重边进行处理一下呢？就像在朴素算法中那样，对于重边人为进行一次筛选，选出距离最短的那条边？

一是没法做到，因为朴素算法中用的是邻接矩阵存储图，其中二维数组g[i] [j]专门用来存储由节点i指向节点j的边的权值；但是对于本题用邻接表来存储图缺乏一个专门用来存储由节点i指向节点j的边的权值的结构，虽然我们可以创建一个数组w[]来存储每条边的权值但是它存储的是边的序号对应的权值（比如第一条边的权值w[1]），它并没有指定每条边的起点和终点，所以可能上一秒还在说由节点i指向节点j的边，下一秒就在说由节点j指向节点k的边，然后又在说由节点i指向节点j的边，总而言之你并不知道由节点i指向节点j的边存储在哪里

二是没有必要去做，因为一股脑将所有的重边加入小根堆，小根堆会进行排序筛选出距离最近的那个点，不过这样也确实会造成小根堆中存储数据冗余

```Java
import java.util.*;
//定义一个类Pair来存储节点编号以及对应的距离初始节点的最短距离
class Pair implements Comparable<Pair>{
    public int first;//表示当前节点距离初始节点的最短距离
    public int second;//表示当前节点的编号
    
    public Pair(int first,int second){
        this.first=first;
        this.second=second;
    }
    @Override
    public int compareTo(Pair o){
        return Integer.compare(first,o.first);
    }
}
public class Main{
    static int N=150010,n,m,idx,max=0x3f3f3f3f;
    static int[] h=new int[N];//用来表示邻接表
    static int[] e=new int[N];//用来表示节点序号对应的节点编号
    static int[] ne=new int[N];//用来表示节点的next指针
    static int[] w=new int[N];//用来表示每个边的权值
    static int[] dist=new int[N];//用来记录每个点距离初始节点的最短距离
    static boolean[] st=new boolean[N];//用来记录每个点是否找到距离初始节点的最短距离
    
    static void add(int a,int b,int c){//定义一条由节点编号a指向节点编号b的有向边，边的权值为c
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
        w[idx]=c;
    }
    static int dijkstra(){
        PriorityQueue<Pair> heap=new PriorityQueue<>();//创建小根堆
        //(1)初始化距离
        Arrays.fill(dist,max);
        dist[1]=0;
        heap.add(new Pair(0,1));
        //(2)每次将不在集合s中的距离最近的点加入集合
        while(!heap.isEmpty()){
            Pair p=heap.poll();//小根堆中每次取的堆顶元素都是距离最小的元素
            int distance=p.first;
            int index=p.second;
            if(st[index]){
                continue;
            }
            st[index]=true;
            for(int i=h[index];i!=-1;i=ne[i]){
                int j=e[i];
                dist[j]=Math.min(dist[j],distance+w[i]);
                //这里有重边的话也不影响，因为小根堆会根据距离进行排序，只是会在小根堆中
                //存储冗余数据罢了
                heap.add(new Pair(dist[j],j));
            }
        }
        if(dist[n]==max){
            return -1;
        }else{
            return dist[n];
        }
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        //一些初始情况的设定
        Arrays.fill(h,-1);
        for(int i=1;i<=m;i++){
            int x,y,z;
            x=sc.nextInt();
            y=sc.nextInt();
            z=sc.nextInt();
            add(x,y,z);
        }
        System.out.println(dijkstra());
    }
}
```





## 4、Bellman-Ford算法（适用于带有负权边的单源最短路问题，且是唯一适用于有边数限制的最短路问题）

### 是什么：

是一种用于求解单源最短路且有负权边的情况，且是唯一适用于有边数限制的最短路问题的解决办法。什么叫做有边数限制？例如：要求从源点到n号点最多经过k条边的最短距离，这里的最多k条边就是边数限制



### 为什么：

dijkstra算法无法适用于有负权边的情况，且后续介绍的最短路算法也无法解决有边数限制的问题，所以引入Bellman-Ford算法



### 怎么办：

#### Bellman-Ford算法的思路

（1）初始化距离，将源点到源点本身的距离设置为0，其他点距离源点的距离设置为无穷大

（2）第1轮循环找到距离源点距离为1条边（这里的1条边仅仅指代物理上的1条边不在乎这条边的权值）的所有节点，并利用源点更新他们到源点的距离

（3）第2轮循环找到距离源点距离为2条边的所有节点，并利用上一轮的节点更新当前这一轮节点到源点的距离

。。。



#### Bellman-Ford算法的一般步骤

```Java
static void bellman_ford(){
    //(1)初始化距离
    Arrays.fill(dist,max);
    dist[1]=0;
	//(2)经过k次循环（k表示对于边数的限制）
	for k次 //k表示对于边数的限制
    	//(3)每次循环中用上一轮的距离更新这一轮所有的边的距离
    	for 所有边（a,b,w） //这里a表示边的起点，b表示边的终点，w表示边的权值
        	dist[b]=Math.min(dist[b],backup[a]+w);//其中backup[]表示上一轮的距离
}

```

#### 如何理解上述Bellman-Ford算法？

（1）如何理解外层的k次循环？

这里的k表示对于边数的限制，当k=1时表示从源点经过1条边可以到达的节点，当k=2时表示从源点经过2条边可以到达的节点，，，当k=k时表示从源点经过k条边可以到达的节点

（2）如何理解内层的更新所有边的操作？

比如说上一轮我们找到了与源点相距k条边的节点i的距离，那么这一轮借由节点i的距离以及一条由i指向j的边那么我们就可以得到与源点相距k+1条边的节点j的距离。特别要注意的是，这里说的更新所有边是真的是所有的边，哪怕上一轮某个点的距离已经更新过了，这一轮同样需要更新（当然这一轮更新后该点的距离不变是最好，假如变得更短的话那么就证明了必须得更新），这一点是与dijkstra算法不同的



#### Bellman-Ford算法与Dijkstra算法的区别

以下图为例，dijkstra算法的步骤是这样的：

（1）初始化距离，将节点1的距离设置为0其他点的距离设置为无穷

（2）在当前所有点中找到距离节点1最近的点就是节点1本身，将它加入集合s，然后用它去更新剩下点（2、3、4号节点）的距离，这里因为1号节点只与2号节点直接相连所以也只能更新2号节点的距离（dist[2]=1）

（3）在剩下的点中找到距离节点1最近的点就是节点2，将它加入集合s，然后用节点2去更新剩下点（3、4号节点）的距离，这里因为2号节点与3号节点、4号节点直接相连所以可以更新3号、4号节点的距离（dist[3]=6，dist[4]=3）

（4）在剩下的点中找到距离节点1最近的点就是节点4，将它加入集合s，然后用节点4去更新剩下点（3号节点）的距离，这里因为没有从4号节点指向3号节点的边所以3号节点的距离没有更新

（5）在剩下的点中找到距离节点1最近的点就是节点3，将它加入集合s，至此所有节点都加入集合s，算法执行完毕（完全没有用到从节点3出发到达节点4的这条负权边）

由上述算法可以得到4号节点到1号节点的最短距离是3（路径是节点1->2->4），但其实根本不对，4号节点到1号节点的最短距离应该是1（路径是节点1->2->3->4）,造成上述错误的原因就是这里存在负权边



还是以下图为例，用bellman-ford算法的求解步骤是这样的：

（1）初始化距离，将节点1的距离设置为0其他点的距离设置为无穷

（2）利用节点1的距离以及从节点1出发的边更新其他点的距离，得到节点2到节点1的距离为1

（3）利用节点2的距离以及从节点2出发的边更新其他点的距离，得到节点4到节点1的距离为3，节点3到节点1的距离为6

（4）利用节点4的距离以及从节点4出发的边更新其他点的距离，发现没有一条边从节点4出发所以没法用节点4去更新其他点的距离；利用节点3的距离以及从节点3出发的边更新其他点的距离得到节点4的距离为1

由上述算法可以得到4号节点到1号节点的最短距离是1（路径是节点1->2->3->4），这是正确答案。

回顾上述算法与dijkstra算法的差异在哪？

无非就是dijkstra算法中存在有一个集合s，而一旦某个节点加入了集合s那么后续就没法再对它的距离进行更新了，而bellman-ford算法中没有这个限制，每次都是更新所有的边

### （853）有边数限制的最短路

![1688696704536](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1688696704536.png)

解题思路：

典型的bellman-ford算法，注意在bellman-ford算法中对于图的表示没有必要再用邻接表或邻接矩阵了，随便用一个类，然后将边的起点、终点、权值放入类中作为属性即可

值得注意的有以下几点：

#### （1）在更新距离的时候为什么要复制上一轮的距离？

因为上一轮代表着从源点经过k条边到达的节点，这一轮代表着从源点经过k+1条边到达的节点；假设现在有一条由i指向j的边，上一轮得到节点i到源点的距离为dist1，这一轮我们应该由这个dist1来更新节点j的距离，但是好巧不巧的是这一轮发现了一条负权边通往节点i导致节点i到源点的距离变得更近了为dist2（但是节点i到源点的边数变成了k+1条），那难道我们这一轮可以用dist2去更新节点j到源点的距离吗？当然不行，因为规定了这一轮是源点经过k+1条边可以到达的节点，如果我们用dist2的话那么就势必会走过那条负权边所在的路，那么节点j到源点的边数就是k+2条边了。图示如下：

1、当k=2时意味着从源点经过2条边可以到达的节点，此时dist[4]=3，dist[5]=无穷大

2、当k=3时意味着从源点经过3条边可以到达的节点，此时dist[4]=1，dist[5]=5(路径为节点1->2->4->5)（也就是在这里发现了一条通往节点4的负权边，路径为节点1->2->3->4，但是此时我们不能用本轮的dist[4]去更新dist[5]，因为那样的话就会造成通往节点5的路径为节点1->2->3->4->5即从源点经过4条边才能到达节点5）

3、当k=4时意味着从源点经过4条边可以到达的节点，此时dist[4]=1，dist[5]=3

![1688718240286](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1688718240286.png)

#### （2）为什么最后的判断语句是dist[n]>max/2，而不是dist[n]==max呢？

一开始我们会设置除了源点外的所有节点的dist为max后续会对所有的边的距离进行更新，即使是那些从源点不可达的节点也会进行更新，现在假设节点j和n不可达的话，并且有一条由j指向n的负权边，那么后续依然会更新节点n的距离使得dist[n]!=max，但是不管怎么更新它依然是属于max这个数量级的但是dist[n]已经不等于原来的max了

![1688718836848](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1688718836848.png)

```Java
import java.util.*;
class Edge{
    //创建一个类用来表示边，这里的三个属性的意思如下：
    //a:边的起点
    //b:边的终点
    //w:边的权值
    int a,b,w;
    public Edge(int a,int b,int w){
        this.a=a;
        this.b=b;
        this.w=w;
    }
}
public class Main{
    static int N=510,M=10010,n,m,k,max=0x3f3f3f3f;
    static int[] dist=new int[N];
    static int[] backup=new int[N];//用来存储上一轮的dist数组
    static Edge[] edges=new Edge[M];//用来存储所有边的Edge类数组
    
    static void bellman_ford(){
        //（1）初始化距离
        Arrays.fill(dist,max);
        dist[1]=0;
        /*
        （2）进行k次迭代（k表示对于边数的限制，k=1表示单源经过1条边能到达的节点，
        k=2表示单源经过2条边能到达的节点，，，）
        */
        for(int i=1;i<=k;i++){
            backup=Arrays.copyOf(dist,n+1);
            /*
            复制上一轮的距离（为什么这里是n+1呢？）
            这里的dist表示要复制的数组，这里的n+1表示复制的数组的长度为n+1，
            即将数组dist中从0开始的n+1长度范围内的数组进行复制。
            为什么要这么做呢？
            因为我们使用dist数组时是从dist[1]开始存储数据的，一直存储到dist[n]，
            现在要复制dist数组必须从dist[0]开始复制而且必须得将dist[n]复制过来，
            所以长度就是n+1
            
            为什么要复制上一轮的距离呢？
            因为上一轮代表着从源点经过k条边到达的节点，这一轮代表着从源点经过
            k+1条边到达的节点；假设现在有一条由i指向j的边，上一轮得到节点i
            到源点的距离为dist1，这一轮我们应该由这个dist1来更新节点j的距离，
            但是好巧不巧的是这一轮发现了一条负权边通往节点i导致节点i到源点
            的距离变得更近了为dist2，那难道我们这一轮可以用dist2去更新节点j
            到源点的距离吗？当然不行，因为规定了这一轮是源点经过k+1条边可以
            到达的节点
            */
            
            //（3）用上一轮的距离更新所有边
            for(int j=1;j<=m;j++){
                Edge p=edges[j];
                int a=p.a;
                int b=p.b;
                int w=p.w;
                dist[b]=Math.min(dist[b],backup[a]+w);
            }
        }
        if(dist[n]>max/2){
            /*
            为什么这里是dist[n]>max/2，而不是dist[n]==max呢？
            因为假设节点j和n不可达的话，并且有一条由j指向n的负权边，那么
            后续依然会更新节点n的距离使得dist[n]!=max，但是不管怎么更新
            它依然是属于max这个数量级的
            */
            System.out.println("impossible");
        }else{
            System.out.println(dist[n]);
        }
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        k=sc.nextInt();
        for(int i=1;i<=m;i++){
            int x,y,z;
            x=sc.nextInt();
            y=sc.nextInt();
            z=sc.nextInt();
            edges[i]=new Edge(x,y,z);
        }
        bellman_ford();
    }
}
```





## 5、spfa算法（适用于带有负权边的单源最短路问题，且算法效率一般情况下要比dijkstra，bellman_ford算法高）

### 是什么：

一种适用于带有负权边的单源最短路算法



### 为什么：

该算法的效率一般情况下要比dijkstra，bellman-ford算法高



### 怎么办：

#### 如何理解spfa算法？

spfa算法是在bellman-ford算法的基础上提出了优化，bellman-ford算法是在每次循环中更新所有的边，但其实这个过程是没有必要的，因为并不是所有的边每次都会被更新，所有边的长度始终都是确定的，那么就只有当边的起点距离被更新的时候该条边对应的终点距离才会被更新，所以我们可以弄一个队列将那些当前更新了距离的点加入队列，然后找出那些以队列中的点作为起点的边继续更新该条边对应的终点的距离然后继续将终点加入队列，重复上述过程



### （851）spfa求最短路

![1688871845743](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1688871845743.png)

解题思路：

就是典型的spfa算法

```Java
import java.util.*;
public class Main{
    static int N=100010,n,m,idx,max=0x3f3f3f3f,head=1,tail=0;
    /*
    这里的head,tail作为全局变量被赋值会出现数组下标越界的问题，具体原因见下述
    */
    static int[] e=new int[N];
    static int[] ne=new int[N];
    static int[] w=new int[N];
    static boolean[] st=new boolean[N];//用来标记每个顶点是否加入队列中
    static int[] dist=new int[N];
    static int[] h=new int[N];
    static int[] q=new int[N];//将更新了距离的顶点编号加入队列
    
    static void add(int a,int b,int c){
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
        w[idx]=c;
    }
    
    static int spfa(){
        head=1;
        tail=0;
        /*
        为什么要在这里给head,tail赋值？在外面全局变量的时候赋值不行吗？
        不行，因为注意看本题在main()方法中我们总共调用了两次spfa()算法，
        第一次调用spfa()算法是判断是否spfa()==max，这里调用了一次spfa()算法；
        然后发现它不等于max然后这时候接着第二次调用spfa()算法，想通过这次调用
        求出该算法的结果，但是因为是共用一个全局变量head,tail，因为上次调用
        过head,tail的缘故没有归位所以造成了这次的数组下标越界
        */
        //初始化距离
        Arrays.fill(dist,max);
        dist[1]=0;
        
        //将更新了距离的点加入队列
        q[++tail]=1;
        st[1]=true;//标记顶点加入队列
        
        while(head<=tail){//当队列不空的时候
            int i=q[head++];//取队头
            st[i]=false;//标记顶点出队列
            for(int j=h[i];j!=-1;j=ne[j]){//更新所有以当前顶点作为起点的边
                int k=e[j];
                if(dist[k]>dist[i]+w[j]){
                    dist[k]=dist[i]+w[j];
                    if(!st[k]){
                    //这里的if(!st[k])语句必须嵌套在上述if(dist[k]>dist[i]+w[j])语句内部
                        q[++tail]=k;
                        st[k]=true;
                    }
                }
                /*
                if(!st[k]){
                    要将这个if(!st[k])语句写在上面的if(dist[k]>dist[i]+w[j])语句内部，
                    为什么？
                    因为只有一个顶点的距离更新了我们才将它加入队列中，而不是随便看到
                    一个顶点发现它没有加入队列我们就将它加入队列，这样的话假如存在回路
                    那么就会产生死循环，将一个点加入队列然后取出来顺带将它出度的边的
                    终点加入队列，然后该终点出队列顺带又将它出度的边的终点加入队列
                    q[++tail]=k;
                    st[k]=true;
                }
                */
            }
        }
        return dist[n];
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        Arrays.fill(h,-1);
        for(int i=1;i<=m;i++){
            int x,y,z;
            x=sc.nextInt();
            y=sc.nextInt();
            z=sc.nextInt();
            add(x,y,z);
        }
        //这里总共会调用两次spfa()算法
        if(spfa()==max){//第一次调用spfa()算法
            System.out.println("impossible");
        }else{
            System.out.println(spfa());//第二次调用spfa()算法
        }
    }
}
```





### （852）spfa判断负环

![1689044987458](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689044987458.png)

解题思路：

#### 怎么办：

#### 如何用spfa算法判断一个图中是否存在负环？

spfa算法的基本思想就是将更新了距离（这里的距离特指到起点的距离）的顶点入队，然后找到以这些顶点作为起点的边再去更新对应终点的距离，然后再将这些终点入队，重复上述过程直到所有顶点的距离都完成更新。注意在这个过程中图中是不能存在负环的，因为假如存在负环的话那么绕负环一圈某个点的距离就减少一点，那么该点的距离会一直更新下去永无止尽直到该点的距离为负无穷，图示如下：

![1689047156406](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689047156406.png)



#### 这里如何规定图的起点以及如何理解这里的距离呢？

与上述求单源最短路问题不同的是上述问题规定了起点就是1号节点，然后求1号节点到n号节点的最短路径；这里我们并没有给出图的起点，要求的是图中是否存在负环，因为该图可能是不连通的而且所有点都可能是起点。而且之前我们规定了每个点的距离特指的是到起点的距离，那么现在的这个距离到底指的是什么呢，从图中并没有看到一个明确的起点啊？

这里我们可以想象一个虚拟的0号节点作为起点，它和每个节点都存在一条虚拟的权值为0的边，现在要求每个节点到0号节点的最短距离（其实问题还是原来的问题但是因为加上了0号节点所以变得容易理解了）

```Java
//解法一：用数组实现队列，注意会有数组下标越界的问题
import java.util.*;
public class Main{
    static int N=2010,M=10010,n,m,idx,head=1,tail=0;
    /*
    这里的head,tail作为全局变量被赋值会出现数组下标越界的问题，具体原因见下述
    */
    static int[] e=new int[M];
    static int[] ne=new int[M];
    static int[] w=new int[M];
    static boolean[] st=new boolean[N];//用来标记每个顶点是否加入队列中
    static int[] dist=new int[N];//用来记录每个点的最短路径距离是多少
    static int[] cnt=new int[N];//用来记录每个点的最短路径经过多少条边
    static int[] h=new int[N];
    //static int[] q=new int[N];//将更新了距离的顶点编号加入队列
    /*
    这里会产生数组下标越界的问题，因为这里用数组模拟队列，数组的大小是固定的，
    后续虽然将元素移除队列但是这种移除是通过移动队列的head指针实现的，该元素
    依然处于数组之中占据着数组的位置，这里如何判断存在负环？就是通过判断是否
    存在一个点的最短距离需要经过n条边（需要经过n条边就意味着经过n+1个点，因为
    总共只有n个点所以一定会有两个点重合即是同一个点，即存在环；而又因为这里的是
    最短距离所以该环一定是负环，否则假如是正环的话那么平白无故绕一圈会导致距离
    增加）
    这里的情况就是存在负环但是该负环位于路径的后端且需要绕好多趟才能保证一个点
    的最短距离经过n条边而此时已经造成数组下标越界了

        ne[idx]=h[a];
```

## 6、Floyd算法（适用于求多源最短路问题）

### 是什么：

适用于求解多源最短路问题的算法



### 怎么办：

#### 如何理解floyd算法？

从任意节点i到任意节点j的最短路径不外乎两种可能：一是直接从i到j，二是从i经过若干个节点k到j。所以，我们假设d(i,j)为节点i到节点j的最短路径的距离（d(i,j)一开始初始化就是由i到j这条边的长度），对于每一个节点k，我们检查d(i,k) + d(k,j) < d(i,j)是否成立，如果成立，证明从i到k再到j的路径比i直接到j的路径短，我们便设置d(i,j) = d(i,k) + d(k,j)，这样一来，当我们遍历完所有节点k，d(i,j)中记录的便是i到j的最短路径的距离（注意这里的d(i,k)并不是一成不变的，而是我们也会不断探究d(i,k)是否具有更短的路径长度的，比如说d(i,k)>d(i,u)+d(u,k)则我们更新d(i,k)=d(i,u)+d(u,k)，后续当我们探究节点i和节点j之间距离的时候用到的d(i,k)都是更新后的d(i,k)）。

```Java
import java.util.*;
public class Main{
    //这里是稠密图再加上要求的是多源最短路，所以用邻接矩阵来存储图
    static int N=210,M=20010,n,m,k,max=0x3f3f3f3f;
    static int[][] g=new int[N][N];//用邻接矩阵来表示图
    
    /*
    floyd算法是针对多源最短路问题的算法，它的原理就是利用二维数组来存储图，一开始
    二维数组d[i][j]存储的是由节点i指向节点j这条边的距离，后来经过更新d[i][j]存储的
    就是节点i指向节点j的最短路径了。
    
    如何理解这里的k？
    可以理解成从节点i走向节点j中间只经过1~k这些节点时的最短路径，因为这里的k也是会
    不断变化的，所以就相当于将从节点i走向节点j中间所有可能经过的点都尝试过一遍然后
    找到那个距离最短的一条路径
    */
    static void floyd(){
        for(int k=1;k<=n;k++){//从节点i走到节点j中间只经过1~k这些节点
            for(int i=1;i<=n;i++){
                for(int j=1;j<=n;j++){
                    g[i][j]=Math.min(g[i][j],g[i][k]+g[k][j]);
                }
            }
        }
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        k=sc.nextInt();
        //初始化距离
        for(int i=1;i<=n;i++){
            for(int j=1;j<=n;j++){
                if(i==j){
                    g[i][j]=0;
                }else{
                    g[i][j]=max;
                }
            }
        }
        for(int i=1;i<=m;i++){
            int x,y,z;
            x=sc.nextInt();
            y=sc.nextInt();
            z=sc.nextInt();
            g[x][y]=Math.min(g[x][y],z);
        }
        floyd();
        for(int i=1;i<=k;i++){
            int x,y;
            x=sc.nextInt();
            y=sc.nextInt();
            if(g[x][y]>max/2){
                /*
                为什么这里是g[x][y]>max/2，而不是g[x][y]==max呢？
                g[i][j]=min(g[i][j],g[i][k]+g[k][j])，
                这里假设节点i没法到达节点k和节点j即g[i][k]=0x3f、g[i][j]=0x3f
                而且g[k][j]为负边，那么g[i][j]还是会被更新为0x3f加上g[k][j]这条
                负边的长度，虽然只更新了一点但它已经不再是0x3f了
                */
                System.out.println("impossible");
            }else{
                System.out.println(g[x][y]);
            }
        }
    }
}
```

## 7、Prim算法

### 是什么：

Prim算法是一种用于解决无向图的最小生成树问题的算法。最小生成树是指在一个加权无向连通图中，找到一个树，使得树中的所有边的权重之和最小，同时保证图中的所有顶点都被连接到该树中。 



### 怎么办：

#### prim算法的基本思路

从图中一个初始顶点开始，逐步扩展生成树（注意不能形成环），直到生成树中包含图中所有顶点

（1）选择图中一个顶点作为起始点（这个顶点是谁都无所谓，反正最后所有的点都会加入生成树中），将其加入生成树中

（2）从生成树中的顶点出发，选择当前生成树外距离生成树最近的点，将其加入生成树中（注意当生成树中有多个顶点的时候要寻找以所有这些顶点作为起点的边，找到终点在生成树外面且权重最小的那条边，将其加入生成树中）

（3）重复上述步骤，直到图中所有顶点都被加入到生成树中



#### prim算法的步骤（算法思想和dijkstra算法很像）

```Java
static void prim(){
    //(1)初始化距离
    Arrays.fill(dist,INF);
    //(2)进行n次迭代
    for(int i=1;i<=n;i++){
        t<-找到集合外距离集合最近的点//每次找到集合外最近的点
        st[t]=true;//将其加入集合
        //用t更新其他点到集合的距离
        for(int j=1;j<=n;j++){
            dist[j]=Math.min(dist[j],g[t][j]);
        }
    }
}
```



#### 如何表示生成树外一个节点j到生成树的距离呢？

节点j与当前生成树内部的多个节点有边相连，找到其中最短的那条边作为生成树外节点j到当前生成树的距离



#### 如何表示将顶点加入生成树中呢？

用一个状态数组st[]，其中st[i]=true表示将i号节点加入到生成树中



#### 当生成树中有多个节点的时候每次寻找生成树外距离当前生成树最近的点的时候都需要遍历当前生成树的所有节点对应的边吗？

当然不是，我们用一个数组dist[j]来记录生成树外的节点j到当前生成树的距离，这样每次新加入一个顶点进入生成树时只要用当前新加入的顶点去更新其他节点的距离就可以了



### （858）Prim算法求最小生成树

```Java
import java.util.*;
public class Main{
    static int N=510,n,m,INF=0x3f3f3f3f;
    static int[][] g=new int[N][N];
    static int[] dist=new int[N];
    /*
    用于表示每个点到集合的距离（注意是到集合的距离不是到某一个顶点的距离），
    什么叫做点到集合的距离呢？
    就是一个点与集合内的多个顶点有多条边相连，取其中最短的那条边称作该点
    到集合的距离
    */
    static boolean[] st=new boolean[N];//用于记录每个顶点是否加入集合中
    
    static int prim(){
        int ans=0;//用于记录最小生成树的树边权重之和
        
        //(1)初始化距离
        Arrays.fill(dist,INF);
        //(2)进行n次迭代，每次找到集合外距离最近的点，将其加入集合并用它更新其他点到集合的距离
        for(int i=1;i<=n;i++){
            int t=-1;//用于记录集合外距离最近的点的编号
            for(int j=1;j<=n;j++){
                if(!st[j] && (t==-1 || dist[t]>dist[j])){
                    t=j;
                }
            }
            st[t]=true;
            if(i!=1 && dist[t]==INF){
                return INF;
                /*
                为什么要加上这一步？
                这里存在图不连通的情况，上述for循环不管怎样每次都会找到一个集合外距离最近的点，
                哪怕该点与集合不连通也是会被找到的，所以这里我们得排除这种情况。
                
                那为什么这里的判断条件还得加上i!=1呢？
                因为这里初始化的时候我们是将所有节点与集合的距离设置为INF的，所以第一次迭代找到
                的集合外最近的点它的距离一定是INF，然后将该点加入集合接着用该点去更新其他节点到
                集合的距离，注意第二次包括以后所有点的距离都不应该是无穷大了（如果是无穷大的话
                就意味着该点与集合不连通）
                
                这里为什么不能去掉这一步特判然后同样还是将该距离加入到最后的返回结果当中去，
                最后通过判断该返回结果是否大于INF/2来进行判断该图不连通呢？
                因为即使该图连通的话这里最小生成树的所有边权之和也可能就是大于INF/2的。
                */
            }
            if(i!=1){
            /*
            初始化时所有点到集合的距离都是无穷大，因此我们将第一个点
            加入集合的时候直接加入该点就行不用加上它的距离
            */
                ans+=dist[t]; 
            }
            for(int j=1;j<=n;j++){
                dist[j]=Math.min(dist[j],g[t][j]);
            }
        }
        return ans;
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        for(int i=1;i<=n;i++){
            Arrays.fill(g[i],INF);
        }
        for(int i=1;i<=m;i++){
            int u,v,w;
            u=sc.nextInt();
            v=sc.nextInt();
            w=sc.nextInt();
            g[u][v]=g[v][u]=Math.min(g[u][v],w);
        }
        int t=prim();
        if(t==INF){
            System.out.println("impossible");
        }else{
            System.out.println(t);
        }
    }
}
```

## 8、Kruskal算法

### 是什么：

Kruskal算法是一种用于解决无向图最小生成树问题的算法。

 

### 为什么：

与prim算法不同的是，kruskal算法适用于稀疏图



### 怎么办：

#### kruskal算法的基本思路

Kruskal算法的基本思想是逐步选择图中权重最小的边，并将其加入最小生成树中（注意不能形成环），直到最小生成树中包含了图中的所有顶点为止。 

（1）将图中的所有边按照权重从小到大进行排序。

（2）初始化一个空的最小生成树。

（3）依次遍历排序后的边，对于每一条边，判断是否会形成环路。如果边的两个端点不在同一个连通分量中（即加入边后不会形成环路），则将该边加入最小生成树中，并将边的两个端点合并到同一个连通分量中。

（4）重复步骤3，直到最小生成树包含了图中的所有顶点。



#### 当后续遍历所有边的时候如何判断边的两个端点是否在同一个连通分量中？

用到前述的并查集的概念



#### 如何确保不会形成环路？

只要用到并查集就不会形成环路



#### kruskal算法的步骤

```Java
static void kruskal(){
    //(1)将所有边按权重从小到大排序
    Arrays.sort(edges,1,m+1);//其中edges表示存储所有边长的数组
    /*
    Arrays.sort(int[] a, int fromIndex, int toIndex)
    这种形式是对数组部分排序，也就是对数组a的下标从fromIndex到toIndex-1的元素排序
    */
    //(2)枚举每条边
    for(int i=1;i<=m;i++){
        int a=edges[i].a;//每条边对应的一个端点
        int b=edges[i].b;//每条边对应的另一个端点
        if(find(a)!=find(b)){//如果边的端点a,b不在一个连通分量中则将它们加到一个连通分量中
            p[find(a)]=find(b);//p[]数组表示并查集中的祖先节点的数组
        }
    }
}
```



### （859）Kruskal算法求最小生成树

![1689494855054](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689494855054.png)

解题思路：

典型的kruskal算法，本题有以下几个注意点：

（1）注意这里的边是如何表示的

（2）如何给边进行排序

（3）调用现成的函数给数组元素进行排序时注意函数各个参数的意义

```Java
import java.util.*;
class Edge implements Comparable<Edge>{
    int a;//记录边的起点
    int b;//记录边的终点
    int w;//记录边的权值
    public Edge(int a,int b,int w){
        this.a=a;
        this.b=b;
        this.w=w;
    }
    
    @Override
    public int compareTo(Edge e){
        return Integer.compare(w,e.w);
    }
}
public class Main{
    static int N=100010,M=200010,n,m;
    static Edge[] edges=new Edge[M];
    static int[] p=new int[N];//并查集中的概念，记录每个节点的父亲节点是谁
    
    static int find(int x){//寻找节点x的祖先节点，在中间加上路径压缩的过程
        if(x!=p[x]){
            p[x]=find(p[x]);
        }
        return p[x];
    }
    
    static void kruskal(){
        int ans=0;//记录生成树的各边权重之和
        int cnt=0;//记录生成树总共有多少条边
        
        //（1）将所有边按权重大小从小到大排序
        Arrays.sort(edges,1,m+1);
        /*
        Arrays.sort(int[] a, int fromIndex, int toIndex)
        这种形式是对数组部分排序，也就是对数组a的下标从fromIndex到toIndex-1的元素排序
        */
        
        //（2）在排序后枚举每条边（a,b,w），如果a,b不连通将这条边加入集合中
        for(int i=1;i<=m;i++){
            int a=edges[i].a;
            int b=edges[i].b;
            if(find(a)!=find(b)){
                p[find(a)]=find(b);
                ans+=edges[i].w;
                cnt++;
            }
        }
        if(cnt<n-1){
            System.out.println("impossible");
        }else{
            System.out.println(ans);
        }
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        for(int i=1;i<=n;i++){
            p[i]=i;
        }
        for(int i=1;i<=m;i++){
            int u,v,w;
            u=sc.nextInt();
            v=sc.nextInt();
            w=sc.nextInt();
            edges[i]=new Edge(u,v,w);
        }
        kruskal();
    }
}
```





## 9、染色法

### 是什么：

染色法是一种图论算法，用于解决图的着色问题，图的着色问题是指为图的顶点分配颜色，使得相邻的顶点具有不同的颜色。



### 怎么办：

#### 染色法的基本思想

从图的某个顶点开始，逐个对顶点进行染色，并保证相邻顶点具有不同的颜色。

#### 如何实现染色法？

利用深度优先搜索（或宽度优先搜索）遍历图中所有节点，实现相邻节点是不同颜色的染色过程，每次给当前节点染色时注意是否与相邻节点的颜色矛盾。

当然不是，如果此时节点j还与节点k相邻并且节点k就是白色，那么此时节点j也就没法染成白色了，具体见下面的奇数环。

所以在给每个节点染色之前得先检查看看是否能染色成功。

解题思路：

#### 什么是二分图？

二分图指一个图中的节点可以被分为互不相交的两个子集，使得同一个子集内部的节点之间没有边相连，不同子集的节点之间有边相连。

注意：下面这是充要条件（证明不会）

二分图<--->没有奇数环

#### 如何利用染色法判定二分图？

染色法是给图中所有顶点染色并满足相邻节点的颜色不同，我们发现：如果满足染色法的话就是二分图了，否则就不是二分图



典型的染色法的题目，一些注意点如下：

（1）注意这里可能存在图不连通的情况注意该如何处理

（2）注意如果一个节点当前没有染色，千万不要以为随便给它染色都能成功，还要留意它的相邻节点的染色情况

```Java
import java.util.*;
public class Main{
    static int N=100010,M=2*N,n,m,idx;
    static int[] e=new int[M];
    static int[] ne=new int[M];
    static int[] h=new int[N];
    static int[] color=new int[N];//记录各个节点的染色情况
    static void add(int a,int b){
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
    }
    
    //深度优先搜索算法（用于遍历所有节点），当前算法的功能是给i号节点染上c号颜色
    //（这里染色只有两种颜色要么黑要么白，用1表示黑色用2表示白色）
    static boolean dfs(int i,int c){
        color[i]=c;
        for(int j=h[i];j!=-1;j=ne[j]){
            int k=e[j];
            if(color[k]==0){
                if(!dfs(k,3-c)){
                    //千万要注意这里，不能因为节点k当前没有染色然后就以为随便给它染色都可以成功
                    /*
                    这里的3-c是什么意思？
                    当规定给i号节点染上1号（2号）颜色以后那么与i号节点相邻的k号节点
                    只能染上2号（1号）颜色，二者颜色之间遵循一个3-c的关系
                    */
                    return false;
                }
            }else if(color[k]==c){
                return false;
            }
        }
        return true;
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        Arrays.fill(h,-1);
        for(int i=1;i<=m;i++){
            int u,v;
            u=sc.nextInt();
            v=sc.nextInt();
            add(u,v);
            add(v,u);
        }
        boolean flag=true;
        for(int i=1;i<=n;i++){//这里是对图不连通情况的处理
            if(color[i]==0){
                flag=dfs(i,1);
                if(!flag){
                    break;
                }
            }
        }
        if(!flag){
            System.out.println("No");
        }else{
            System.out.println("Yes");
        }
    }
}
```





## 10、匈牙利算法

### 是什么：

匈牙利算法是一种解决二分图最大匹配问题的经典算法。 

什么叫做二分图的最大匹配问题？

现在有两个集合：男生集合，女生集合；现在要求男生去找匹配的女生（要求一男一女匹配，不能有一男多女、一女多男的情况），所得到的最大匹配数就是二分图的最大匹配。



### 怎么办：

#### 如何得到二分图的最大匹配数呢？

如下图所示：

![1689583575815](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689583575815.png)

为了得到最大匹配数，我们遍历男生集合，

（1）遍历1号男生，让1号男生去找对象，他可以找1号女生和2号女生，这里假定他找1号女生，这里就完成了1个匹配了

![1689583752806](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689583752806.png)



（2）接着遍历2号男生，让2号男生去找对象，他也喜欢1号女生，但是1号女生已经和1号男生匹配了，这该咋办？因为这里1号男生还有一个备胎即2号女生，所以我们让1号男生放弃1号女生转而去找2号女生，这样2号男生就可以乘虚而入去找1号女生了。

为什么要这么做？

因为我们这里的目的是求二分图的最大匹配数，所以当1号男生的对象被别人看上的时候而且1号男生有备胎的时候我们让他放弃当前的对象转而去找备胎，这样不仅自己能和备胎配对而且之前的对象因为自己的放手也能和别人配对，这样就有了两个配对了（**人类幸福最大化**）

![1689584127454](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689584127454.png)



（3）接着遍历3号男生，让3号男生去找对象，他也喜欢2号女生，但是2号女生已经和1号男生匹配了，这该咋办？还是重复上述的步骤，我们看看能不能让1号男生放手去找他的备胎，但是这里发现1号男生已经没有备胎了，所以1号男生也不愿意放弃当前的对象，没办法3号男生只能去找另一个心动对象即3号女生，发现3号女生没有匹配所以3号男生和3号女生完成匹配

![1689584629547](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689584629547.png)



上述过程体现的就是匈牙利算法，可以得到二分图的最大匹配数。



### notes：关于匈牙利算法的总结

我们发现在上述过程中，先遍历的男生始终处于被动地位，因为好不容易他找到了一个对象，如果后续他的对象被后来的男生看中了，那么他就得放弃现在的对象转而去找备胎（为了人类幸福最大化），如果找不到备胎才作罢。换言之，对于后来的男生来说他无论看上哪个女生都是有机会的，即使该女生有对象我们也可以去求该女生的对象放手（如果该女生的对象也找不到备胎了那就没办法）

总而言之一句话体现匈牙利算法的思路：

#### 待字闺中，据为己有；名花有主，求他放手



### （861）二分图的最大匹配

![1689495008863](%E7%AC%AC%E4%B8%89%E7%AB%A0%E6%90%9C%E7%B4%A2%E4%B8%8E%E5%9B%BE%E8%AE%BA.assets/1689495008863.png)

解题思路：

思路就像上图所示的那样

```Java
import java.util.*;
public class Main{
    static int N=510,M=100010,n1,n2,m,idx;
    static int[] e=new int[M];
    static int[] ne=new int[M];
    static int[] h=new int[N];
    static boolean[] st=new boolean[N];//用于标记右半部女生集合中的每个女生是否匹配
    static int[] match=new int[N];
    //用于标记右半部女生集合中的每个女生所匹配的是左边集合中的哪一个男生
    
    static void add(int a,int b){
        e[++idx]=b;
        ne[idx]=h[a];
        h[a]=idx;
    }
    //用于查询编号为x的男生是否能找到对象
    static boolean find(int x){
        for(int i=h[x];i!=-1;i=ne[i]){
            int j=e[i];
            if(!st[j]){
                st[j]=true;
                if(match[j]==0 || find(match[j])){
                    /*
                    如果j号女生当前没有匹配对象或者j号女生的匹配对象可以去找备胎，
                    那么x号男生就可以乘虚而入匹配j号女生
                    */
                    match[j]=x;
                    return true;
                }
            }
        }
        return false;
    }
    
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n1=sc.nextInt();
        n2=sc.nextInt();
        m=sc.nextInt();
        Arrays.fill(h,-1);
        for(int i=1;i<=m;i++){
            int u,v;
            u=sc.nextInt();
            v=sc.nextInt();
            add(u,v);
        }
        int res=0;//用于记录匹配数
        for(int i=1;i<=n1;i++){
            Arrays.fill(st,false);
            /*
            这里为什么在遍历男生集合的时候要将st[]数组置为false?
            对于后来的男生来说，不管他看中哪个女生都是有机会的，即使该女生有对象我们也可以求该女生
            的对象放手，如果该女生的对象实在找不到备胎了那么也没有办法
            */
            if(find(i)){
                res++;
            }
        }
        System.out.println(res);
    }
}
```
