![1683206633455](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683206633455.png)

解题思路：

这题的想法很简单，先将整个字符串输入进来，然后以空格作为分界将各个单词存储在字符串数组中，然后统计字符串数组中最后一个元素的长度就可以了。

但是想普及一个知识：

##### notes：Java中next()方法和nextLine()方法的区别

在Java中next()方法是用来输入一个单词的，以空格作为分隔符（即遇到空格就开始下一次输入）；

nextLine()方法是用来输入一整行的，包括空格也被输入进来（即遇到空格将它作为整个字符串的一个成员）。

```Java
import java.util.*;

    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String str=sc.nextLine();
        String[] s=str.split(" ");
        int length=s[s.length-1].length();

        System.out.println(length);
    }
```

### （HJ2）计算某字符出现次数

![1683209813963](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683209813963.png)

解题思路：

##### notes：Java中是没法输入一个字符的，只能输入一个字符串，若是想得到一个字符，我们就从该字符串中取出字符

注意这题的关键就在于这里的字母是不区分大小写的，在ASCII码中'A'的编号是65，'a'的编号是97，相同的英文字母大小写之间相差32而不是26，但是如果我们仅仅凭借两个字符之间编号相等或者是编号相差32就判定这两个字符相等（不区分大小写因此相差32的大小写英文字符可以认为是相等的）的这种看法是错误的，因为假如一个有一个非英文的字符然后还有一个非英文的字符这两个字符很明显不相等但是编号差了32那么按照上述说法我们就将它们看作相等，这样的想法显然不对；

那么这里我们可以怎么做？

先将字符串中所有的字符转换成小写字母，然后再去依次比较两个字符就可以了

### （HJ3）明明的随机数

![1683208507521](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683208507521.png)

解题思路：

##### notes：在哈希表HashMap中有现成的办法get(key)可以取出指定key值对应的value值，但是没有现成的办法可以取出哈希表中的key值

我们利用哈希表来解决这道题，在哈希表中有现成的方法get(key)可以取出指定key值对应的value值，但是没有现成的办法可以取出哈希表中的key值，所以该怎么办呢？我们可以先将所有的key值取出来单独形成一个集合（用HashMap.keySet()方法），然后在这个新的集合中就可以取出key值来了

```Java
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        HashMap<Integer,Integer> map=new HashMap<>();
        while(n>0){
            n--;
            int num=sc.nextInt();
            if(map.containsKey(num)){
                continue;
            }else{
                map.put(num,1);
            }
        }
        int[] arr=new int[map.size()];
        int i=0;
        for(Integer key:map.keySet()){
            arr[i++]=key;
        }
        Arrays.sort(arr);
        for(int key:arr){
            System.out.println(key);
        }
    }
}
```





### （HJ4）字符串分隔

![1683256046811](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683256046811.png)

解题思路：

就是先根据字符串的长度然后求出每8个长度进行一次划分的话该字符串会被划分成多少个子串（最后不足8个长度的部分补上0），然后将这些新的子串放进字符串数组中，最后输出这些字符串数组

```Java
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String str=sc.next();
        int len=str.length();//首先求出字符串的长度
        int mod=len%8;//字符串长度除以8后的余数
        len/=8;//根据字符串长度除以8看看会划分成几个新的字符串
        if(mod!=0){
            len+=1;
        }
        String[] s=new String[len];
        int j=0;
        for(int i=0;i<str.length();i+=8){
            if((i+8)<=str.length()){
                s[j++]=str.substring(i,i+8);
            }else{
                int num=8-(str.length()-i);//当最后的字符串长度不足8的时候看看要补几个0
                StringBuffer sb=new StringBuffer(str.substring(i,str.length()));
                for(;num>0;num--){
                    sb.append(0);
                }
                s[j]=sb.toString();
            }
        }
        for(int i=0;i<s.length;i++){
            System.out.println(s[i]);
        }
    }
}
```

### （HJ6）质数因子

![1683272926264](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683272926264.png)

解题思路：

最暴力的思路：

给定一个整数n，我们首先将小于等于它的所有的质数（为什么还有等于？因为我们不能排除给定的这个整数n本身就是一个超大的质数这种情况啊）全部求出来放入一个数组中，然后我们再从这个数组中取值看看它的因子是多少（这个思路肯定是对的，但是时间复杂度太高了，假如给定一个超大的质数那么我们光是求有哪些小于等于它的质数这个操作就很麻烦，比如数64577就是一个超大的质数，我们得从2到64577遍历这么多数看看它们是否是质数）

##### notes：当判断一个数n是否是质数的时候我们遍历一个数i让n去除以i，i的上限为什么是根号n？

因为如果一个数n可以被整除的话它一定可以分解成n=a*b，其中a和b一大一小，如果我们仅仅是为了判定该数是否是质数的话只要把i的上限设置成根号n就可以了

```Java
//这个方法是对的，但是时间复杂度太高了

import java.util.*;
public class Main{
    /*
    解题思路：
    给定一个数n先将小于它的左右的质数求出来，然后再拿这些质数作为因子取做商
    */
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        List<Integer> list=new ArrayList<>();//用来存储质数的集合
        List<Integer> ans=new ArrayList<>();//用来存储最后答案的集合
        for(int i=2;i<=n;i++){//判断i是不是质数
            boolean flag=true;//记录i是不是质数
            for(int j=2;j*j<=i;j++){
                if(i%j==0){
                    flag=false;
                    break;
                }
            }
            if(flag){
                list.add(i);
            }
        }
        int len=list.size();
        int[] nums=new int[len];
        for(int i=0;i<len;i++){
            nums[i]=list.get(i);
        }
        while(n!=1){
            for(int i=0;i<len;i++){
                if(n%nums[i]==0){
                    n/=nums[i];
                    ans.add(nums[i]);
                    break;
                }
            }
        }
        for(int i=0;i<ans.size();i++){
            System.out.print(ans.get(i)+" ");
        }
    }
}
```



有没有更好的办法呢？

当然是有的，我们从i=2开始遍历如果n能被i整除就输出i同时更新n/=i，然后遍历当前的i看看还能不能继续整除更新后的n，如果不能则更新i=i+1；

这里有个问题，这样的操作只能保证n能被i整除如何保证i本身是质数呢？

问得好，假如说i本身不是质数比如说它是4但是因为我们的i是从2开始往上遍历的，如果n在这里能被4整除则它之前一定能被2整除，然后发现已经没法被2整除了我们这时候才更新i=3，对于其余的合数也是同样的道理，只要我们发现数n能被一个数i整除然后我们就往死了一直除以i直到没法整除这才放过i，只要我们执行上述的操作就不用担心后续会遇到被合数整除的情况；

还有一个问题，那就是这里我们设置的i的上限是根号n，那么用n来除以i然后更新n的值为n/=i以后最后n一定能被这些小于根号n的数整除最后n变成1吗？

其实是不一定的，假如n本身就是由两个很大的质数相乘得来，比如n=101*107，那么此时的根号n=103.95，那么最后n是等于107的，要注意这一点

```java 
            }

        System.out.print(n==1? "":n);
```

### （HJ8）合并表记录

![1683453168273](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683453168273.png)

解题思路：

在哈希表中我们没有现成的办法可以取出哈希表中的key值，但是这里又需要对于其中的key值进行排序处理，我们该怎么办呢？

办法就是先将哈希表中的key值集合先单独取出来：Map.keySet();  然后将其中的内容放入数组中接着对此数组进行排序就间接完成了对于哈希表中的key值排序的任务

##### notes：注意在哈希表中是没法直接将集合Set转换成数组的：int[] nums=set.toArray();该方法是行不通的，只能先创建一个数组然后依次将集合中的元素塞进数组中

```Java
import java.util.*;
public class Main{
    static HashMap<Integer,Integer> map=new HashMap<>();
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n;
        n=sc.nextInt();
        while(n>0){
            n--;
            int k,v;
            k=sc.nextInt();
            v=sc.nextInt();
            if(map.containsKey(k)){
                map.put(k,map.get(k)+v);
            }else{
                map.put(k,v);
            }
        }
        Set<Integer> set=map.keySet();
        int[] keys=new int[set.size()];
        int i=0;
        for(int key:set){
            keys[i++]=key;
        }
        Arrays.sort(keys);
        for(int j=0;j<keys.length;j++){
            System.out.println(keys[j]+" "+ map.get(keys[j]));
        }
    }
}
```



### （HJ9）提取不重复的整数

![1683464422560](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683464422560.png)

解题思路：

既然题目中提到不重复所以我们理所应当的想到哈希表，利用哈希表来达到元素不可重复的目的，我们首先利用除10取余将最后一位元素看看集合中是否存在该元素，如果不存在就将它放入集合、如果存在就不去管它，最后当结束了以后我们按顺序将存入集合的元素读取出来就行了（**这种想法是错误的，不是思路的错误，而是哈希表是无顺序的也就是说你将元素存进哈希表的顺序到时候你读取的时候不是按照这个顺序的**）

##### notes：不管是HashMap还是HashSet集合里面的元素都是没有顺序的，你不要指望先将元素存入集合中然后按照存入的顺序读取出来，没错你确实可以读取出来每一个元素不过已经不是刚开始进去的顺序了

那么这题该怎么办，既然没办法用哈希表的顺序的话那我们就另外用一个整型变量来记录那些不重复的值就是了

```Java
//错误方法：因为哈希表是没有顺序的
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int num;
        num=sc.nextInt();

            int mod=num%10;
            if(!map.containsKey(mod)){
                map.put(mod,1);
            }
            num/=10;
        }
        Set<Integer> set=map.keySet();
        for(int i:set){//哈希表是没有顺序的，不能指望它按照当初输入的顺序进行输出
        	System.out.print(i);
        }
    }
}
```

### （HJ14）字符串排序

![1683467355747](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683467355747.png)

解题思路：

如何实现给字符串按照字典序排序呢？需要我们自己去重新实现comparator接口吗？不需要这么麻烦的，直接调用Arrays.sort()方法就可以了，不过这里需要注意的是为了防止数组下标越界我特意将数组开大了一点，而存储的时候是从下标1处开始存储的，所以像下标0处这样的地方我们是没有给它们赋值的，所以它的地址是空的，如果我们对这些位置上的元素也进行排序的话就会出现空指针异常，所以我们得避开这些位置，好在Arrays.sort()方法可以让我们选择数组的一部分进行排序

##### notes：利用Arrays.sort()方法给数组进行排序的时候要避开数组中为空的那部分，否则会出现空指针异常

```Java
import java.util.*;

            strs[i]=sc.next();
        }
        Arrays.sort(strs,1,n+1);
```

### （HJ20）密码验证合格程序

![1683515009818](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683515009818.png)

解题思路：

本题算是一个字符串问题的大杂烩了，既牵扯到字符串的长度又牵扯到字符的种类又牵扯到重复子串的问题，那就针对这三个问题分别进行求解，

（1）针对字符串的长度，这没什么好说的

（2）针对字符串中字符的种类要大于等于三种，我们用哈希表来记录该字符串中出现了几种字符，这里有一点需要注意的是比如说：大写英文字母'A'-'Z'虽然是26个字母但是它们都是同一种类型的字符所以不能重复计算种类，所以为了避免重复计算种类我们可以将属于同一类的字符用一个代表来表示，比如就用 'A' 来代表所有的大写英文字符（对于小写英文字符、数字字符、其他字符等也是同理用一个代表来表示）

（3）针对字符串中不能有长度大于等于3的重复的子串，这里的重复子串的长度到底是多少也是不确定的，可能是4也可能是5，但是不管怎么样，假如存在长度为5的重复子串那么一定存在长度为3的重复子串，所以这里我们就去找是否存在长度为3的重复子串就可以了（**另外还有一点需要注意的是，这里所谓的重复子串是没有相交的部分的，比如说一个子串下标范围是0-3它和另一个下标范围是1-4的子串重复的这种情况是不存在的**）。

（4）最后还有一点这里会输入多组数据，不是仅仅输入一组数据就结束了我们得利用hasNext()方法或hasNextLine()方法来判断是否从控制台还会有其他数据的输入



##### notes：Java中的next()方法、nextLine()方法、hasNext()方法、hasNextLine()方法各自的作用

next()方法：用于读取下一个输入的文本（以空格作为分隔符）。

 hasNext()方法：用于判断是否还有下一个token（默认以空格为分隔符），如果有返回true，否则返回false。 

 nextLine()方法：用于读取输入的下一行文本（包括空格符也被当做字符串的一部分）。

 hasNextLine()方法：用于判断是否还有下一行输入（不以空格作为分隔符），如果有返回true，否则返回false。 

```Java
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        while(sc.hasNext()){//这里会进行多组数据的输入
            String s=sc.next();
            boolean flag=true;//记录该字符串是否是符合要求的密码
            int len=s.length();
            HashMap<Character,Integer> map=new HashMap<>();
            if(len<=8){
                flag=false;
            }else{
                int num=0;//记录字符串中有多少种字符
```

### （HJ48）从单向链表中删除指定值的节点

![1683555226167](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683555226167.png)

解题思路：

本题就是利用数组来实现单链表的题目

```Java
//用数组来实现单链表
import java.util.*;
public class Main{
    static int N=1010;
    static int[] e=new int[N];
    static int[] ne=new int[N];
    static int idx=0;
    //定义在链表中第k个位置的后面插入数值x的方法
    static void insert(int x,int k){
        ++idx;
        e[idx]=x;
        ne[idx]=ne[k];
        ne[k]=idx;
    }
    static void remove(int k){//删除链表中第k个插入的节点（第k个插入的节点对应的下标为k）
        /*
        ne[k-1]=ne[k];
        这里有个问题，第k个插入的节点它前面的节点下标一定是k-1吗？
        当然不是的，因为后续可能在第k个插入的节点前面再插入节点（本题与ACwing那题
        模拟链表的区别，那题是要删除第k个插入链表中的节点后面的一个节点，
        而本题是要删除第k个插入的节点所以我们还得找到第k个节点的前面一个节点是谁）
         */
        int x=ne[0];//x初始指向头节点
        while(ne[x]!=k){
            x=ne[x];
        }
        //找到第k个插入的节点它的前面一个节点
        ne[x]=ne[ne[x]];
    }
    static int find(int x){//定义在链表中找到数值为x的节点对应的下标的方法
        int k=ne[0];//k指向链表的头节点，然后顺着链表往后寻找值x对应的下标
        while(e[k]!=x){
            k=ne[k];
        }
        return k;
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();//总共得插入n个节点
        int head=sc.nextInt();//头节点的值
        insert(head,0);//插入头节点（这里已经插入1个节点了，后续还得插入n-1个节点）
        while(n>1){
            //这里为什么是n>1？因为前面已经插入一个节点了，所以这里只要再插入n-1个节点就行了
            n--;
            int val,r;
            val=sc.nextInt();
            r=sc.nextInt();

            这里的r代表链表中某个节点的数值，我们需要在该数值对应的节点后面插入
            新的节点，但是我们定义的方法是在某个下标位置处的后面插入新的节点，所以
            这里我们得根据数值找到对应的链表下标
            */
            r=find(r);
            insert(val,r);
        }
        int k=sc.nextInt();//这里一开始输出的k对应的是数值，我们得找到它在链表中对应的下标
        k=find(k);

        for(int i=ne[0];i!=0;i=ne[i]){
            System.out.print(e[i]+" ");
        }
    }
```

### （HJ50）四则运算

![1683618901001](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683618901001.png)

解题思路：

本题就是输入一个字符串，字符串的内容是一个数学表达式，然后用栈来实现计算该数学表达式的结果，不过这里有一个需要注意的问题就是这里的 '-' 的存在有两种意义：一是代表负号，二是代表减号；我们要注意判断它代表哪种意义。

##### notes：注意 '-' 到底是负号还是减号的判断

真实的负号情况是：
                    （1）若'-'出现在字符串第一个位置则代表它一定是负号
                    （2）若'-'前面一个位置是'('则代表它一定是负号
                    （3）若'-'前面一个位置是数字则代表它一定是减号
                    （4）若'-'前面一个位置是')'则代表它一定是减号

```Java
import java.util.*;
public class Main {
    static Stack<Character> op = new Stack<>(); //用来存储操作符的栈
    static Stack<Integer> num = new Stack<>(); //用来存储数字的栈
    /*
    这里有一个需要注意的地方就是这里的'-'，它到底是作为负号存在的还是
    作为减号存在的二者的意义是不同的
    */
    static void eval(Stack<Integer> num, Stack<Character> op) {
        int b = num.pop();
        int a = num.pop();
        char c = op.pop();
        if (c == '+') {
            num.push(a + b);
        } else if (c == '-') {
            num.push(a - b);
        } else if (c == '*') {
            num.push(a * b);
        } else {
            num.push(a / b);
        }
    }
    public static void main(String[] args) {
        HashMap<Character, Integer> map = new
        HashMap<>(); //用来存储各个操作符及对应的优先级
        map.put('+', 1);
        map.put('-', 1);
        map.put('*', 2);
        map.put('/', 2);
        Scanner sc = new Scanner(System.in);
        String str = sc.next();
        boolean flag=true;//记录当前的数到底是正数还是负数
        for (int i = 0; i < str.length(); i++) {
            char c = str.charAt(i);
            if (Character.isDigit(c)) {
                int x = 0, j = i;
                while (j<str.length() && Character.isDigit(str.charAt(j))) {
                    x = x * 10 + str.charAt(j) - '0';
                    j++;
                }
                if(flag){
                    num.push(x);
                }else{
                    num.push(-x);
                    flag=true;
                }
                i=j-1;
            } else if (c == '(' || c == '[' || c == '{') {
                op.push(c);
            } else if (c == ')') {
                while (op.peek() != '(') {
                    eval(num, op);
                }
                op.pop();
            } else if (c == ']') {
                while (op.peek() != '[') {
                    eval(num, op);
                }
                op.pop();
            } else if (c == '}') {
                while (op.peek() != '{') {
                    eval(num, op);
                }
                op.pop();
            } else { //对于'-'得单独处理，判断它到底是负号还是减号
                if (c != '-') {
                    while (!op.empty() && op.peek() != '(' && op.peek() != '['
                            && op.peek() != '{'
                            && map.get(op.peek()) >= map.get(c) ) {
                        eval(num, op);
                    }
                    op.push(c);
                } else {
                    /*
                    这里关于负号的判断出现了问题：
                     if (i == 0 || !Character.isDigit(str.charAt(i - 1))) {
                        //可以确定这里的'-'代表负号
                        flag=false;
                    } 
                    真实的负号情况是：
                    （1）若'-'出现在字符串第一个位置则代表它一定是负号
                    （2）若'-'前面一个位置是'('则代表它一定是负号
                    （3）若'-'前面一个位置是数字则代表它一定是减号
                    （4）若'-'前面一个位置是')'则代表它一定是减号
                    */
                    if(i==0 || str.charAt(i-1)=='(' || str.charAt(i-1)=='[' 
                        || str.charAt(i-1)=='{'){
                            //可以确定这里的'-'代表负号
                            flag=false;
                    }else {
                        //可以确定这里的'-'代表减号，普通处理就行
                        while (!op.empty() && op.peek() != '(' && op.peek() != '['
                                && op.peek() != '{'
                                && map.get(op.peek()) >= map.get(c) ) {
                            eval(num, op);
                        }
                        op.push(c);
                    }
                }
            }
        }
        while (!op.empty()) {
            eval(num, op);
        }
        System.out.println(num.peek());
    }
}
```

解题思路：

这里规定了对于字符串的操作只有插入一个字符、删除一个字符、修改一个字符这三种操作，现在我们要求将一个字符串完全修改成另一个字符串的样子需要执行最少几次操作。

我们令dp[i] [j]表示将第一个字符数组a的前i个字符完全修改成第二个字符数组b的前j个字符所需要的最少操作的次数，则这里可以分为两种情况：

（1）**a数组的第i个字符等于b数组的第j个字符即a[i-1]=b[j-1]（因为这里的数组下标是从0开始的，所以a数组的第i个字符对应的数组下标就是a[i-1]）**，此时dp[i] [j]=dp[i-1] [j-1]

（2）a数组的第i个字符不等于b数组的第j个字符即a[i-1]!=b[j-1]，这时候为了使两个字符数组相等又可以对a数组的最后一位进行插入、删除、修改三种操作：

①在a数组的末尾插入b[j-1]字符，这样就使得此时的a数组的最后一个字符等于b数组的最后一个字符了，然后只要我们再将a数组的前i个字符转换为b数组的前j-1个字符就行了（为什么不用管b数组的第j个字符了呢？因为此时a数组的后来补上的最后一个字符已经等于b数组的第j个字符了啊）。即：dp[i] [j]=dp[i] [j-1]+1（这里的 +1代表a数组的末尾进行了一次插入字符的操作）

②在b数组的末尾插入a[i-1]字符，这样就使得此时的a数组的最后一个字符等于b数组的最后一个字符了，然后只要我们再将a数组的前i-1个字符（为什么不用管a数组的第i个字符了呢？因为此时a数组的第i个字符已经等于b数组后来补上的最后一个字符了）转换为b数组的前j个字符就行了。即：dp[i] [j]=dp[i-1] [j]+1（这里的 +1代表b数组的末尾进行了一次插入字符的操作）**（在b数组插入字符就相当于在a数组删除字符）**

③将a数组末尾的字符修改为b数组末尾的字符，这样就使得此时的a数组的最后一个字符等于b数组的最后一个字符了，然后只要我们再将a数组的前i-1个字符转换为b数组的前j-1个字符就行了。即：dp[i] [j]=dp[i-1] [j-1]+1（这里的 +1代表a数组的末尾进行了一次修改字符的操作）

所以在a数组的第i个字符不等于b数组的第j个字符的情况下为了使得a数组的前i个字符完全转换为b数组的前j个字符所需要的最少操作次数是上述三种情况中的最小值，即：

dp[i] [j]=min(dp[i] [j-1]+1, dp[i-1] [j]+1, dp[i-1] [j-1]+1)

```Java
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        while(sc.hasNext()){
            String A=sc.next();
            char[] a=A.toCharArray();
            String B=sc.next();
            char[] b=B.toCharArray();
            /*
            这题用动态规划来做，用dp[i][j]来表示字符数组a中前i个字符转换到字符数组b中
            前j个字符所需要的编辑距离，那么存在如下递推关系：
            （1）假如a[i]==b[j]，那么dp[i][j]=dp[i-1][j-1]
            （2）假如a[i]!=b[j]，那么为了使得字符数组a中的前i个字符转换到字符数组b中的
                 前j个字符分为三种情况：
                 ①字符数组b中插入一个字符：对应的情况为dp[i][j]=dp[i-1][j]+1
                 ②字符数组b中删除一个字符：对应的情况为dp[i][j]=dp[i][j-1]+1
                 ③字符数组b中修改一个字符：对应的情况为dp[i][j]=dp[i-1][j-1]+1
            */
            int[][] dp=new int[a.length+1][b.length+1];
            for(int i=1;i<=a.length;i++){
                dp[i][0]=i;
            }
            for(int j=1;j<=b.length;j++){
                dp[0][j]=j;
            }
            dp[0][0]=0;
            for(int i=1;i<=a.length;i++){
                for(int j=1;j<=b.length;j++){
                    if(a[i-1]==b[j-1]){
                        dp[i][j]=dp[i-1][j-1];
                    }else{
                        dp[i][j]=Math.min(dp[i-1][j]+1,
                                          Math.min(dp[i][j-1]+1,dp[i-1][j-1]+1));
                    }
                }
            }
            System.out.println(dp[a.length][b.length]);
        }
    }
}
```





### （HJ106）字符逆序

![1683710174125](%E7%89%9B%E5%AE%A2%E7%AE%97%E6%B3%95%E9%A2%98.assets/1683710174125.png)

解题思路：

本题与之前的第13的句子逆序的区别就在于本题不光要将字符串数组中的字符串的排列顺序颠倒而且还要将每一个字符串中的字符的顺序进行颠倒。

##### notes：字符数组char[]的toString()方法返回的不是对应的字符串而是对应的地址，如果我们想要获得字符数组对应的字符串的话可以将该字符数组作为字符串构造器的参数，即new String(char[] ch);

```Java
import java.util.*;
public class Main{
    static void swap(String[] s){
        int i=0,j=s.length-1;
        while(i<j){
            String tmp=s[i];
            s[i]=s[j];
            s[j]=tmp;
            i++;
            j--;
        }
    }
    static void exchange(char[] ch){
        int i=0,j=ch.length-1;
        while(i<j){
            char tmp=ch[i];
            ch[i]=ch[j];
            ch[j]=tmp;
            i++;
            j--;
        }
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String str=sc.nextLine();
        String[] s=str.split(" ");
        swap(s);
        for(int i=0;i<s.length;i++){
            char[] ch=s[i].toCharArray();
            exchange(ch);
            s[i]=new String(ch);
        }
        for(int i=0;i<s.length;i++){
            System.out.print(s[i]+" ");
        }
    }
}
```

### （HJ108）求最小公倍数

解题思路：

以往我们手动求两个数的最小公倍数是咋求的？是不是两个数同除以一个数然后就这样一直往下除直到没法再除，但是这样的过程用编程实现起来很困难；所以这里我们换个思路，这里要求最小公倍数，假设这两个数分别是a、b,那么它们的最小公倍数一定可以写成k*a的形式，这代表啥意思呢？由k个a累加起来的数就是a和b的最小公倍数，就是这里的k是不确定的，所以这里我们就是要找这个最小的k，不管k为多少 k *a一定是能被a整除的，接下来就是要满足 k *a能被b整除就可以了
